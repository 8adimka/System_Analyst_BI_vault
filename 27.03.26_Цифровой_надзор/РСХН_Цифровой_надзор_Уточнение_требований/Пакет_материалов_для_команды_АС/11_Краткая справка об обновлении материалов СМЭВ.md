# Краткая справка об обновлении материалов СМЭВ

Дата обновления: 05.10.2026.

В папку проекта добавлены актуальные материалы СМЭВ по взаимодействию с ЕРВК. Старые материалы перенесены в подпапку `old`.

## Что добавлено

1. По получению информации из реестра объектов контроля ЕРВК:
   - руководство пользователя;
   - XSD-схема;
   - эталонные XML запроса и ответа;
   - URI вида сведений: `urn://rostelekom.ru/ControlObjectsList/1.0.6`.

2. По внесению информации в реестр объектов контроля ЕРВК:
   - руководство пользователя;
   - XSD-схема;
   - эталонные XML запроса и ответа;
   - URI вида сведений: `urn://rostelekom.ru/AddControlObjects/1.0.5`.

## Что изменилось в выводах

Ранее в материалах был риск, что отсутствуют примеры XML-сообщений. После обновления этот риск снят: эталонные XML теперь есть.

Остаются вопросы не по наличию материалов, а по процессу:

1. Какие сценарии ЕРВК действительно входят в объем работ АС.
2. Нужно ли только получение сведений или также внесение сведений.
3. Нужны ли действия `ADD`, `EDIT`, `DELETE` или только часть из них.
4. Кто формирует XML: АС или ИВИС.
5. Какие идентификаторы ЕРВК должна хранить АС.
6. Какие ошибки и статусы нужно показывать пользователю.

## Какие документы обновлены

В папке `Пакет материалов для команды АС` обновлены:

1. `01_Пакет для установочной встречи по оценке работ.md`.
2. `04_Матрица оценки работ команды АС.xlsx`.
3. `05_Реестр интеграций и данных.xlsx`.
4. `07_Реестр открытых вопросов и зависимостей.xlsx`.
5. `08_Карта открытых решений для оценки работ.md`.
6. `09_Разбор материалов СМЭВ ЕРВК.md`.
7. `10_Сервис категоризации объектов - анализ для решения по зоне ответственности АС.md`.

Также синхронизированы дубли соответствующих файлов в корне проекта, чтобы не осталось разных версий.

## Практический вывод для команды АС

Материалы СМЭВ по ЕРВК теперь достаточны для предварительной оценки интеграционного блока на уровне анализа схем, маппинга, подготовки запросов, обработки ответов, ошибок и статусов.

При этом для точной оценки все еще нужно управленческое решение: какие операции с ЕРВК выполняет АС, а какие остаются во ФГИС ПГС или на стороне ИВИС.
