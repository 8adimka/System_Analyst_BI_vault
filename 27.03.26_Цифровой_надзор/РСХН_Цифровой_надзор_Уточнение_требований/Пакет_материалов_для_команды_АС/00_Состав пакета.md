# Состав пакета материалов для команды АС

Папка содержит актуальный комплект материалов для передачи команде Аналитической системы по проекту "Цифровой надзор".

Рекомендуемый порядок работы соответствует нумерации файлов:

1. 01_Пакет для установочной встречи по оценке работ.md
2. 02_Устав проекта Цифровой надзор.docx
3. 03_Материал для предварительной оценки работ команды АС.docx
4. 04_Матрица оценки работ команды АС.xlsx
5. 05_Реестр интеграций и данных.xlsx
6. 06_Схема информационного взаимодействия и границы ответственности.docx
7. 07_Реестр открытых вопросов и зависимостей.xlsx
8. 08_Карта открытых решений для оценки работ.md
9. 09_Разбор материалов СМЭВ ЕРВК.md
10. 10_Сервис категоризации объектов - анализ для решения по зоне ответственности АС.md
11. 11_Краткая справка об обновлении материалов СМЭВ.md

Быстрый маршрут для разработчиков АС: 01, 03, 04, 05, 06, 07, 08, 10.

Для руководства: 02, 08, 10 и итоговая сводка после заполнения матрицы оценки.

Файл 09 нужен как техническое приложение по материалам СМЭВ/ЕРВК.

Файл 10 нужен для отдельного решения по сервису категоризации: делать ли его силами команды АС, ограничиться интеграцией и отображением результата, или выделить расширенный расчетный сценарий.

Файл 11 нужен как краткая справка о том, что изменилось после обновления материалов СМЭВ.
