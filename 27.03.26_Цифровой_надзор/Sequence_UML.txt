@startuml
title "Цифровой надзор" Россельхознадзора — АРМ ↔ ИВИС ↔ ГосТех

autonumber
hide footbox
skinparam shadowing false
skinparam responseMessageBelowArrow true
skinparam sequenceMessageAlign center

actor "Инспектор" as INS
participant "Аналитическая система РСХН\n(Основная платформа)" as AS_RSHN
participant "АРМ инспектора\n(Новый сервис)" as ARM
participant "ФГИС ИВИС" as IVIS
participant "Сервис сбора\nдоказательной базы\n(ГосТех)" as EDB
participant "Сервис LLM\n(ГосТех)" as LLM
participant "Основной сервис\nГосТех" as GT
database "Хранилище файлов\nАРМ" as FS
database "Журнал\nинтеграции" as LOG

== 0. Авторизация и инициализация ==
INS -> AS_RSHN : Вход и авторизация в системе
AS_RSHN --> INS : Успешно (установка единых Cookie)

AS_RSHN -> AS_RSHN : Автоматический расчёт\nиндикаторов риска (данные из ETL)
AS_RSHN -> INS : Индикатор отображён на дашборде

INS -> ARM : Клик по индикатору
ARM -> ARM : Проверка валидности сессии\n(чтение общих Cookie)

note right of ARM
Инициализация АРМ:
- загрузка карточки индикатора
- получение стартовых данных
end note

ARM --> INS : Карточка индикатора открыта

== 1. Подтверждение / отклонение ==
INS -> ARM : Подтвердить/отклонить\n+ выбрать НПА

break Индикатор отклонён
  ARM -> ARM : Статус = "Отклонён"
  ARM -> LOG : Лог решения
end

ARM -> ARM : Обновить статус (Подтверждён)
ARM -> LOG : Лог решения

== 2. Сбор доказательной базы ==
INS -> ARM : Запросить доказательную базу

ARM -> IVIS : SOAP запрос
IVIS -> EDB : Передать

alt Успех
  EDB --> IVIS : Ответ + файлы
  IVIS --> ARM : Файлы

  ARM -> FS : Сохранить файлы
  ARM -> LOG : Лог
  ARM -> INS : Файлы доступны
else Ошибка
  IVIS --> ARM : Ошибка
  ARM -> LOG : Лог ошибки
end

== 3. Генерация LLM ==
INS -> ARM : Сформировать документы

ARM -> IVIS : SOAP (XML индикатора + НПА + доказательная база)
IVIS -> LLM : Генерация
LLM --> IVIS : Документы
IVIS --> ARM : Исходная версия

ARM -> FS : Сохранить исходную версию
ARM -> LOG : Лог
ARM -> INS : Файлы доступны

note right of FS
Храним только:
1) исходную версию
2) последнюю итоговую
end note

== 4. Редактирование ==
loop Редактирование и загрузка
  INS -> ARM : Upload итоговой версии
  ARM -> FS : Сохранить итоговую версию
  note right of FS
  Перезапись файла.
  Версионирование не требуется,
  сохраняется только последняя версия.
  end note
  ARM -> LOG : Лог
end

== 5. Итоговая отправка (параллельно) ==
INS -> ARM : Инициировать итоговую отправку материалов
ARM -> ARM : Разблокировка отправки

par Обратная связь LLM
  INS -> ARM : Указать оценку
  ARM -> ARM : Сохранить оценку
  ARM -> LOG : Лог
  ARM -> IVIS : SOAP (исходная + итоговая + оценка)
  IVIS -> LLM : Передать
  LLM --> IVIS : ACK
  IVIS --> ARM : OK
  ARM -> LOG : Лог отправки оценки
else Финальный пакет в ГосТех
  INS -> ARM : Инициация контрольных надзорных мероприятий (КНМ)
  ARM -> IVIS : Финальный пакет (без исходной версии)
  note right of ARM
  Лимит 50-100 Мб.
  Исходная версия LLM
  НЕ отправляется
  end note
  IVIS -> GT : Передать
  GT --> IVIS : ACK
  IVIS --> ARM : Отправлено
  ARM -> LOG : Лог отправки
end

== 6. Статус КНМ ==
alt Webhook
  GT --> IVIS : Статус
  IVIS --> ARM : Обновление
else Polling
  ARM -> IVIS : Запрос статуса
  IVIS -> GT : Polling
  GT --> IVIS : Ответ
  IVIS --> ARM : Обновление
end

ARM -> LOG : Финальный статус

== 7. Обновление Аналитической системы ==
ARM -> AS_RSHN : Передача результатов обработки\nи итоговых статусов КНМ

@enduml
