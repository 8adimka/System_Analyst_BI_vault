@startuml
title "Цифровой надзор" Россельхознадзора — сквозной процесс Modus BI ↔ ИВИС ↔ ГосТех

autonumber
hide footbox
skinparam shadowing false
skinparam responseMessageBelowArrow true
skinparam sequenceMessageAlign center

actor "Инспектор" as INS
participant "Аналитическая модель\n(РСХН)" as AI
participant "АРМ инспектора\n(Modus BI)" as ARM
participant "ФГИС ИВИС" as IVIS
participant "Сервис сбора\nдоказательной базы\n(ГосТех)" as EDB
participant "Сервис LLM\n(ГосТех)" as LLM
participant "Основной сервис\nГосТех" as GT
database "Хранилище файлов\nModus BI" as FS
database "Журнал\nинтеграций" as LOG
database "Витрины /\nдашборды" as DWH

== 0. Расчёт индикатора ==
AI -> ARM : Автоматический расчёт\nиндикаторов риска
note right of ARM
Создаются:
- карточка индикатора
- записи в "Идентификаторы"
- записи в "Расчеты"
end note

ARM -> INS : Индикатор отображён

== 1. Подтверждение / отклонение ==
INS -> ARM : Подтвердить/отклонить\n+ выбрать НПА

alt Индикатор подтверждён
  ARM -> ARM : Обновить статус
  ARM -> LOG : Лог решения

  == 2. Сбор доказательной базы ==
  INS -> ARM : Запросить доказательную базу

  ARM -> IVIS : SOAP запрос
  IVIS -> EDB : Передать

  alt Успех
    EDB --> IVIS : Ответ + файлы
    IVIS --> ARM : Файлы

    ARM -> FS : Сохранить файлы
    ARM -> LOG : Лог
    ARM -> INS : Файлы доступны
  else Ошибка
    IVIS --> ARM : Ошибка
    ARM -> LOG : Лог ошибки
  end

  == 3. Генерация LLM ==
  INS -> ARM : Сформировать документы

  ARM -> IVIS : SOAP (XML индикатора + НПА + доказательная база)
  IVIS -> LLM : Генерация
  LLM --> IVIS : Документы
  IVIS --> ARM : Исходная версия

  ARM -> FS : Сохранить исходную версию
  ARM -> LOG : Лог

  note right of FS
  Храним только:
  1) исходную версию
  2) последнюю итоговую
  end note

  == 4. Редактирование ==
  loop Редактирование и загрузка
    INS -> ARM : Upload итоговой версии
    ARM -> FS : Сохранить итоговую версию
    note right of FS
    Перезапись файла.
    Версионирование не требуется,
    сохраняется только последняя версия.
    end note
    ARM -> LOG : Лог
  end

  == 5. Оценка ==
  INS -> ARM : Указать оценку
  ARM -> ARM : Сохранить оценку
  ARM -> LOG : Лог

  == 6. Итоговая отправка (параллельно) ==
  INS -> ARM : Инициировать итоговую отправку материалов
  ARM -> ARM : Разблокировка отправки

  par Обратная связь LLM
    ARM -> IVIS : SOAP (исходная + итоговая + оценка)
    IVIS -> LLM : Передать
    LLM --> IVIS : ACK
    IVIS --> ARM : OK
  else Финальный пакет в ГосТех
    ARM -> IVIS : Финальный пакет (без исходной версии)
    note right of ARM
    Лимит 50-100 Мб.
    Исходная версия LLM
    НЕ отправляется
    end note
    IVIS -> GT : Передать
    GT --> IVIS : ACK
    IVIS --> ARM : Отправлено
    ARM -> LOG : Лог отправки
  end

  == 7. Статус КНМ ==
  alt Webhook
    GT --> IVIS : Статус
    IVIS --> ARM : Обновление
  else Polling
    ARM -> IVIS : Запрос статуса
    IVIS -> GT : Polling
    GT --> IVIS : Ответ
    IVIS --> ARM : Обновление
  end

  ARM -> LOG : Финальный статус

  == 8. Дашборды ==
  ARM -> DWH : Обновление витрин
  DWH --> ARM : Дашборды актуальны

else Индикатор отклонён
  ARM -> ARM : Статус = "Отклонён"
  ARM -> LOG : Лог решения
end

@enduml
