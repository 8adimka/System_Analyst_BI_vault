Основная идея: при включении настройки «Поиск без лимита» с фронта передаётся только одно поле (как и было раньше), но теперь благодаря интерфейсным доработкам пользователь может сам задать какое поле передавать для осуществления поиска. 

На фронтенда в поле для поиска у нас добавляется выпадающий список, который позволяет выбрать одно из доступных полей, по которому будет происходить поиск. Дополнительный интерфейс внедряется согласно макету. 

Цель текущей доработки дать пользователю возможность выбрать поле, по которому будет происходить поиск без необходимости проводить поиск сразу по нескольким полям, что уменьшает требуемые бэкендовые доработки и даём пользователю самому задавать верное поле для поиска из доступных на данный момент в визуализации. Т.е. набор полей по которому может (и должен) происходить поиск у нас не меняет, а проводить поиск по всем полям сразу мы не можем (на данный момент) по техническим причинам, поэтому мы даём пользователю возможность самому задать целевое поле для проведения поиска.

Требуется:
* Реализовать поддержку опции «Поиск без лимита» для активации серверного поиска для иерархических структур, без существенных доработок бэкенда.
* При включении опции «Поиск без лимита» в иерархическов фильтре, для поля поиска добавить новый элемент - выпадающий список (согластно макету) для выбора целевого поля для проведения серверного поиска.

User Story:
Как аналитик, я хочу иметь возможность включать серверный поиск в иерархическом фильтре, чтобы пользователи могли искать значения по всему справочнику на любом уровне вложенности иерархии по всему объему данных, не ограничиваясь первоначально загруженным пулом записей. Пользователи должны иметь возможность выбрать целевой уровень вложенности по которому будет происходить серверный поиск.

Изучи во вложении Текущий вид поля поиска для элемента Иерархичнский фильтр на нашем портале - "Текущий_вид_поля_поиска_Иерархичнский_фильтр.png",

Также изучи референс нового элемента "выпадающий список" для этого поля поиска - Пример_референс.png

Опция "Искать везде" пока будет недоступна, доступные поля для поиска в этом фильтре:
Город, Категория, Подкатегория.

Выбор поля для поиска выводится пользователю в виде "Искать в <Наименование Поля с полки 'Фильтры' данного Иерархического фильтра>".

После выбора пользователем одного из полей, именного это поле становится целевым для поиска совпадений после ввода пользователем поисковой фразы или слова в поле поиска. Как результаты выводятся все уровни иерархии в которых было найдено совпадение на целевом уровне (в выбранном поле).

Как опытный дизайнер интерфейсов изучи предоставленные материалы и составь макет удобного и рационального интерфейса обеспечивающего пользователю возможность искать на выбранном уровне в Иерархическом фильтре, органично добавь новый настраиваемый параметр в текущий интрерфейс и не меняй в нём больше ничего, не добавляй ничего нового, кроме того, что уже есть на макете и нового выпадающего списка для выбора поля поиска. Выпадающий список прямо под параметром (как на референсе).
