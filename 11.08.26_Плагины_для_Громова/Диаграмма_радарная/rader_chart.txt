h3. 1. Контекст и проблематика.

Требуется реализовать «Радарную диаграмму» (Radar Chart) *как подключаемый плагин* конструктора отчётов для сравнения нескольких характеристик одного или нескольких объектов.

h4. Коротко: принцип радарной диаграммы.
# *Критерии* → превращаются в оси.
# *Значения* → откладываются от центра к краю.
# *Точки* → соединяются линиями.
# *Линии* → образуют профиль объекта.
# *Несколько профилей* → позволяют сравнивать объекты между собой.

Радарная диаграмма — это визуальный способ ответить на вопрос:
«В чём этот объект силён, в чём слаб и чем его профиль отличается от других объектов?»

h4. Подробно: радарная диаграмма.

{panel:title=Что это |borderStyle=solid|borderColor=#0052CC|bgColor=#DEEBFF}
Радарная диаграмма (*Radar Chart*) — это способ визуализации *нескольких характеристик* одного или нескольких объектов *на одной диаграмме*.

Каждый анализируемый показатель представлен отдельной осью, исходящей из *общего центра*. Значение показателя откладывается на соответствующей оси, после чего полученные точки соединяются линиями.

В результате образуется многоугольник, форма которого представляет собой своеобразный *«профиль» объекта*.

Главная идея радарной диаграммы - не просто показать отдельные числа, а дать возможность одним взглядом увидеть соотношение нескольких характеристик одного объекта, а также сравнить профили нескольких таких объектов.
{panel}


{panel:title=Как работает |borderStyle=dashed|borderColor=#0052CC|bgColor=#F0F4FF}
Каждый показатель откладывается по отдельной оси:

# одна ось — один критерий;
# все оси начинаются из общего центра;
# значение увеличивается по мере движения от центра к краю;
# точки на соседних осях соединяются линиями;
# полученная фигура показывает общий профиль объекта.

*1. Каждая ось — отдельный критерий или метрика*

Например:

* Скорость
* Качество
* Стоимость
* Надёжность
* Удобство
* Инновации

*2. Для каждой оси задаётся шкала, начало каждой оси от общего центра*

Например:

{code}
0 — минимальное значение
1
2
3
4
5 — максимальное значение
{code}

* Чем ближе точка к центру — тем меньше значение.
* Чем ближе точка к внешней границе — тем больше значение.
* *Важно понимать*, что исследуемые показатели могут быть представлены различными единицами измерения и диапазонами значений. Положение точки на каждой оси рассчитывается независимо для каждого показателя относительно его собственного диапазона {{min–max}}.
** Одинаковое расстояние от центра, для значений разных показателей, означает одинаковое относительное положение показателя внутри его собственной шкалы, а не одинаковое абсолютное значение.

*3. Значения объекта наносятся на соответствующие оси*

Например:

||Критерий||Значение||
|Скорость|4|
|Качество|5|
|Стоимость|3|
|Надёжность|4|
|Удобство|4|
|Инновации|3|

*4. Полученные точки соединяются линиями*

* После соединения образуется многоугольник.
* Именно его форма позволяет визуально оценивать профиль объекта.

*5. На одну диаграмму можно нанести несколько объектов*

Например:

* Объект A — синяя фигура;
* Объект B — оранжевая фигура.

После наложения фигур становится видно, по каким критериям один объект сильнее или слабее другого.

Вместо шести отдельных графиков мы получаем одну фигуру, по которой можно быстро понять сильные и слабые стороны исследуемого объекта, также сравнить несколько таких объектов.
{panel}

*Основные элементы радарной диаграммы:*
* *Оси*
** Каждая ось соответствует отдельному критерию или показателю.
*** Например, ось «Качество» отвечает только за значение качества.
* *Шкала*
** Показывает диапазон допустимых значений.
Например:
{code}
1 → очень низкое значение
2 → низкое
3 → среднее
4 → высокое
5 → очень высокое
{code}
* *Точки*
** На каждой оси ставится точка, соответствующая значению объекта.
* *Многоугольник*
** Точки соединяются линиями.
** Получившаяся фигура отображает профиль объекта.
* *Легенда*
** Используется при сравнении нескольких объектов.
Например:
{code}
● Объект A
● Объект B
{code}
** По легенде пользователь понимает, какая линия или область относится к какому объекту.

h4. Минимальные настройки визуализации.

Настройки визуализации выполняются в стандартном стиле нашей платформы и включают все основные и минимально-необходимые разделы в правой боковой панеле настроек: "Общие настройки", "Подписи данных — включить/выключить", "Всплывающая подсказка — включить/выключить",  "Легенда — включить/выключить", "Основной стиль", "Стиль элементов", "Режим фильтра — включить/выключить", "Настройки клика", "Инфо — включить/выключить".

Важные настройки, которые нужно подсветить:
# Два режима определения диапазона {{min/max}} каждой оси:
#* Автоматически - min/max определяются системой отдельно для каждой оси по значениям соответствующего показателя в результирующей выборке после применения фильтрации,
#* Вручную - min/max задаются пользователем для показателя.
# Легенда с возможностью скрыть/показать профиль:
#* То есть клик по элементу легенды временно скрывает/возвращает категорию.
# Отсечки — реализуются, аналогично другим визуализациям, через особый тип "Отсечка" для пилюли на полке "Значения". Позволяет задать относительное пороговое значение для всех исследуемых и сравниваемых величин в формате: 1) от 0 до 1; или 2) от 0% до 100%. Один относительный порог для всех осей - например, при обозначении "50%" можно слегка затонировать область:
#* 0–50 %   → ниже порога;
#* 50–100 % → выше порога.
#* Например:
#** Качество: 1–10 (50 % диапазона ≈ 5,5),
#** Продажи: 560 000–4 500 000 (50 % диапазона = 2 530 000).
#* То есть круг 50% означает одинаковое относительное положение внутри диапазона, а не среднее статистическое значение показателей.
# Подсказки (Tooltip) - при наведении на точку пользователь должен видеть исходное значение, а не внутреннюю относительную координату и дополнительные, выбранные в настройках, данные - название параметра, название исследуемого объекта.
#* Пример выводимой подсказки: "Продажи: 600 000 ₽" или
"Магазин 1
Продажи: 600 000 ₽".
# Настройка "Стиль элементов" (линий, точек, заливки по каждой категории):
Наверху располагается выпадающий список "Объект данных:" - по аналогии с функциональностью других визуализаций, он содержит все уникальные категории из пилюли, выбранной на полке "Категории". Далее располагается стандартный набор настроек визуала, включая:
#* Цвет категории,
#* Толщина линии,
#* Показывать точки: Да / Нет,
#* Прозрачность заливки,
#* Показывать заливку: Да / Нет.
