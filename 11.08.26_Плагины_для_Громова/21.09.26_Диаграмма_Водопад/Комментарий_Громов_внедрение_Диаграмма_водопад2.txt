h3. 1. Данные и режимы обработки.

Числовой показатель передаёт готовые дельты; по ним рассчитывается накопленный уровень. Штатные агрегации, фильтры и сортировка сохраняются, включая сортировку по другому полю. Другие режимы обработки иных структур входных данных в данной реализации не вводятся.

Полка «Значения» содержит типы «Значение», «Отсечка», «Цвет», «Подзаголовок», «Подсказка». Рекомендуемая замена «Цвета» тремя цветовыми типами описана в разделе 4.

* В режиме «Первое» обрабатывается только первая физическая пилюля полки. Каскад строится, только если она имеет тип «Значение» и передаёт числовой показатель. При вспомогательном типе используется штатное состояние недостаточной конфигурации, даже если далее размещено «Значение».
* В режиме «Все» обрабатываются все пилюли по своим типам. Геометрию задаёт первое по порядку «Значение». Следующие «Значения» не создают дополнительных этапов или каскадов. Для «Подзаголовка», «Подсказки» и «Цвета» используется только первая пилюля каждого типа; после разделения цветов — первая каждого из трёх цветовых типов независимо.
* Все обрабатываемые «Отсечки» формируют опорные линии, включая отсечки в начале полки. Ограничение первой пилюлей своего типа к ним не применяется; фиксированного количественного лимита нет. Отсечки числовой показатель не заменяют.

При заполненных «Категориях» и выключенных либо пустых «Сериях» этапы определяет первая пилюля «Категорий». При пустых «Категориях» используется первая пилюля включённых «Серий»: один каскад без разбивки по сериям. Выключенные «Серии» не участвуют, содержимое полки сохраняется. При создании новой визуализации по-умолчанию «Серии» включены.

При двух заполненных активных полках категории образуют группы, серии — последовательные вклады отдельных серий. Сумма категории повторно не прибавляется. По умолчанию после группы показан накопленный подытог с общим и индивидуальным управлением показом. Без используемого измерения этапов или числового показателя каскад не строится; при обеих пустых полках измерений показывается «нет данных», остальные состояния оформляются штатно. Это уточняет обязательную конфигурацию разделов 3.1–3.2 исходной постановки.

«Первый столбец как подытог» определяет роль первого отображаемого столбца: начальный итог либо изменение, оба от нуля. Включение заполненных «Серий» автоматически выключает данную настройку; отключение или опустошение «Серий» при заполненных «Категориях» может включать её обратно. Пользователь может изменить настройку вручную: меняется роль первого вклада без создания дополнительного столбца. Первые вклады следующих категорий итогами не становятся. Конечный итог может отдельно скрываться, показываться и переименовываться без изменения расчёта.

«Ограничить число серий на шаг» включает Top-N по модулю независимо для каждой категории после фильтрации и агрегации; N — положительное целое, по умолчанию 5. Остальные вклады объединяются в «Прочие» арифметическим сложением с учётом знаков; без остальных группа отсутствует. Выключение ограничения показывает доступные вклады без объединения, сохраняя N. Общие лимиты платформы действуют. Детализация не должна менять суммарное значение категории; это уточняет раздел 3.3 и AC.9 исходной постановки.

h3. 2. Подытоги.

Вместо замены исходной дельты подытог добавляется отдельным столбцом сразу после выбранного этапа: от нуля до накопленного уровня с учётом этой дельты. Исходная дельта остаётся; повторного сложения или сброса уровня нет. Для 100, +40, −25 подытог после −25 равен 115. Это заменяет противоречащие правила разделов 3.4, 4.3 и AC.6 исходной постановки.

* Общий тумблер «Подытоги» скрывает промежуточные итоги, сохраняя настройки.
* Список «После выбранного столбца» содержит значения измерения этапов; при разбивке по сериям отдельно доступны категории и отображаемые серии.
* Индивидуальный тумблер включает подытог элемента; подчинённые параметры — имя «{Название} (подытог)» по умолчанию и необязательный статический цвет.
* Повторный выбор открывает существующую настройку без дубликата; настройки разных элементов независимы.

Категория задаёт подытог после всей группы. Серия — после каждого отображаемого вхождения в разных категориях: имя и статический цвет общие, накопленные уровни разные. Одноимённые категория и серия настраиваются независимо. Серия внутри «Прочих» не получает отдельного столбца под своим именем.

Сортировка и фильтры пересчитывают позиции и значения подытогов; привязка следует за значением, не позицией. Временное отсутствие значения сохраняет настройку и не переносит подытог к другому этапу; при возвращении значения настройка применяется снова.

h3. 3. Настройки и подписи.

Порядок разделов правой панели соответствует макету 16; применимые элементы управления адаптируются из «Диаграммы столбчатой».

|| Разделы || Состав ||
| Общие настройки | Заголовки, ориентация, Zoom-детализация, дополнительная ось значений, фон, отступы, точность чисел/процентов, суффиксы единиц измерения, формат даты. |
| Водопад | Первый столбец как подытог; показ и название конечного итога; соединительные линии. |
| Данные | Лимиты запроса, показа строк/серий, экспорта; дополнение пустых категорий/серий; анимация, интервальное обновление. |
| Ось «Категории»; Ось «Значения» | Заголовки, сетка, шкала, подписи, форматирование; скроллбар категории, числовой диапазон, нулевая линия. |
| Серии | При включённой заполненной полке: ограничение числа вкладов и подчинённый максимум. |
| Подписи данных | Шаблоны дельты и итогов; положение, цвет, размер, наклон, точность, прореживание, суффиксы и плюс для увеличения. |
| Всплывающая подсказка; Легенда | Штатные настройки показа, шаблона и оформления подсказки; положения, реверса, текстов и оформления легенды. |
| Основной стиль | Три базовых цвета, ширина столбцов; цвет, толщина и тип соединительных линий. |
| Стиль элементов; Подытоги | Подпись и индивидуальный цвет категории либо серии при разбивке по сериям; управление подытогами по разделу 2. |
| Режим фильтра; Настройки клика; Дрилл; Инфо; Рамка компонента | Штатные возможности фильтрации, переходов, выбора, детализации, описания и рамки. |

Независимые «Шаблон дельты» и «Шаблон итогов» применяются соответственно к изменениям и к начальному, промежуточным и конечному итогам. Для изменений доступны число изменения, накопленный уровень, изменение вместе с уровнем, процент либо изменение вместе с процентом; для итогов — числовые варианты без процентной дельты. «Авто» показывает изменение либо итоговый уровень соответственно.

Процент равен дельте / накопленный уровень непосредственно перед изменением × 100%; при разбивке по сериям база определяется перед каждым вкладом. Знак знаменателя сохраняется: +20 после −100 даёт −20%. При нулевой/отсутствующей базе процент отсутствует; фиктивный 0%, NaN и бесконечность не выводятся.

Число и процент показываются отдельно или совместно, включая читаемый двухстрочный вариант. Точность, суффиксы и плюс настраиваются; минус сохраняется, нулевая дельта отображается как 0. Форматирование не влияет на расчёт.

Отдельного блока «Дельты» и самостоятельных меток у соединителей нет: это заменяет соответствующие положения разделов 4.5–4.6 и AC.12–AC.15. Подписи независимы от всплывающей подсказки; соединители независимы от подписей. Исходный вопрос максимума отсечек и проверка превышения максимума в AC.16 заменяются проверкой нескольких линий без фиксированного лимита. Остальные требования к отсечкам сохраняются. Сохранение, повторное открытие и копирование воспроизводят настройки комментария.

h3. 4. Рекомендуемое расширение динамической раскраски.

Рекомендуется переименовать тип «Цвет» в «Цвет увеличения» и добавить «Цвет уменьшения» и «Цвет итога». Это типы пилюль полки «Значения». В этом варианте:

|| Тип пилюли || Область применения || Переопределяемый параметр «Основного стиля» ||
| Цвет увеличения | Динамический цвет обычных столбцов положительного изменения, включая положительные Вклады отдельных серий. | Увеличение |
| Цвет уменьшения | Динамический цвет обычных столбцов отрицательного изменения, включая отрицательные Вклады отдельных серий. | Уменьшение |
| Цвет итога | Динамический цвет начального, промежуточных и конечного итогов независимо от знака накопленного уровня. | Итог и подытоги |

Область определяется ролью столбца и знаком изменения, а не знаком накопленного уровня. Цветовые пилюли не формируют этапов и не влияют на накопление; обрабатываются по правилам раздела 1. Цветовые типы добавляются в меню пилюли без дополнительных разделов правой панели.

Для конкретного столбца действует приоритет: индивидуальный статический цвет из «Стиля элементов» либо «Подытогов» → допустимый динамический цвет подходящего типа пилюли → соответствующий групповой цвет «Основного стиля» → базовые цвета отчёта. Без переопределений увеличение синее, уменьшение зелёное, итоги серые. Легенда отражает применённую раскраску.

Пилюля возвращает готовый допустимый цвет в формате, поддерживаемом порталом; вычисляемое поле допустимо. При отсутствии индивидуального цвета пустой или недопустимый динамический цвет ведёт к групповому цвету «Основного стиля», далее — к базовым цветам отчёта. Получение единственного цвета расчётного итога остаётся открытым вопросом раздела 6.

h3. 5. Критерии приёмки (AC):

AC.1 — *Режимы и вспомогательные типы:*
* *Дано:* первая пилюля — «Отсечка», далее два «Значения»; всего шесть валидных отсечек и по две пилюли остальных вспомогательных типов;
* *Когда:* переключают «Первое»/«Все», проверяют первым каждый вспомогательный тип и меняют влияющий фильтр;
* *Тогда:* в «Первое» каскада нет; перенос «Значения» в начало разрешает построение. В «Все» каскад задаёт первое «Значение»; используются первые пилюли остальных вспомогательных типов и все отсечки, линии пересчитываются. Шесть — пример, не максимум.

AC.2 — *Подытоги и жизненный цикл:*
* *Дано:* 100, +40, −25, +10; подытог после −25 переименован и окрашен;
* *Когда:* повторяют выбор, переключают общий показ, сохраняют, открывают, копируют, сортируют и временно исключают −25 фильтром;
* *Тогда:* исходные уровни подытога и конечного итога — 115 и 125; дубликата нет, имя и цвет воспроизводятся. При сортировке подытог следует за −25 и пересчитывается; фильтрация не переносит настройку, возвращение значения восстанавливает её применение.

AC.3 — *Полки и серии:*
* *Дано:* SUM; А: X=100, Y=−20; Б: X=40, Y=−10; включён подытог серии X;
* *Когда:* включают заполненные «Серии», вручную меняют роль первого столбца, затем отключают и отдельно опустошают «Серии»;
* *Тогда:* переключение роли соответствует разделу 1, дополнительного стартового столбца нет. Подытоги X — 100 и 120, конечный уровень — 110; без детализации этапы — 80 и 30. Единственные активные «Серии» также задают каскад; их выключение прекращает построение.

AC.4 — *Ограничение, проценты и подписи:*
* *Дано:* SUM; вклады категории +100, −80, +30, −10; N=2;
* *Когда:* переключают ограничение, меняют шаблоны, подписи, соединители и подсказку;
* *Тогда:* показаны +100, −80, «Прочие» +20 либо четыре вклада; итог — 40. Шаблоны независимы, совместная подпись читаема; отключение подписей сохраняет подсказку и соединители. Для первого вклада процент отсутствует, для второго равен −80%; отдельно +20 после −100 даёт −20%. Форматирование расчёт не меняет.

AC.5 — *Рекомендуемая раскраска:*
* *Дано:* реализован вариант раздела 4; заданы различимые индивидуальные, динамические и групповые цвета, вторые пилюли цветовых типов;
* *Когда:* в режиме «Все» показывают изменения и Вклады отдельных серий, включая +20 после −100; для конкретного столбца снимают индивидуальный цвет, затем проверяют отсутствие/недопустимость динамического;
* *Тогда:* при одновременно заданных цветах виден индивидуальный из «Стиля элементов» либо «Подытогов»; без него — допустимый динамический, без допустимого динамического — соответствующий групповой цвет «Основного стиля». Для +20 применяется тип «Цвет увеличения», для отрицательных изменений — «Цвет уменьшения»; последующие пилюли того же типа не обрабатываются. Легенда соответствует раскраске. Итоги обоих знаков относятся к «Цвету итога»; проверка получения их цвета дополняется после решения открытого вопроса.

* Какие агрегации и выражения поддерживать при разбивке по сериям и как реагировать на несовместимые AVG/MIN/MAX/COUNTD/выражения? Плагин ограничивает детализацию SUM/COUNT, а сложение агрегатов серий не гарантирует сохранения значения категории; ответ определит допустимые конфигурации и числовые AC.
