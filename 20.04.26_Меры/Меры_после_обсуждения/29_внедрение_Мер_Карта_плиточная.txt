Вот пример настроек визуализации "Карта плиточная" в режиме отладки ./Настройки_Карта_плиточная_в_режиме_отладки.txt

При работе с визуализацией "Карта плиточная" нам доступна стандартная левая боковая панель (как и во всех других визуализациях). Ранее на левой боковой панеле располагались только пилюли, которые формировались из колонок набора данных, а также отдельная пилюля "Вычисляемое поле", а теперь должна появиться дополнительная секция "Меры". Пилюли из левой боковой панели мы можем располагать на полках настраиваемой визуализации. Левая боковая панель в данной визуализации переиспользует уже реализованный компонент в соответствии с его текущей реализацией.

Для размещения полей, вычисляемых полей и Мер в визуализации "Карта плиточная" доступны полки:
# Полка "Значения",
# Полка "Категории",
# Полка "Тренд",
# Полка "Фильтры".

Полка "Тренд" *активна* только если её тумблер (Вкл/Выкл) находится в положении *"Вкл"* и на ней размещена хотя бы одна пилюля. Иначе полка *неактивна*.

Полка "Тренд" используется для построения тренда изменений как дополнительной информации к визуализации, однако, сейчас не удалось установить точное поведение визуализации при использовании полки "Тренд". 
Поэтому предлагаю полку "Тренд", связанные с ней настройки из правой боковой панели и их поведение - перенести в раздел "Открытые вопросы" для дальнейшего доизучения. Основная суть, которую необходимо передать в постановке - после введения Мер дополнительной функциональности не вводится поведение не меняется, но визуализация должна функционировать корректно и должна быть возможность протестировать Меры во всех возможных сценариях их применения.

На данный момент можно зафиксировать следующее поведение полок визуализации:
# Полка "Значения" - на данной полке можно разместить поля набора данных, вычисляемые поля или Меры, полученные из них значения используются для визуализации распределения этих значений по карте (категориям - визуализируемые категории получаем из первой пилюли, размещенной на полке "Категории"), полученные значения из первой пилюли, размещённой на полке "Значения", визуализируются показывая распределение значений по категориям (разница в значениях визуализируется цветом). Значения остальных пилюль, размещённых на полке "Значения", отображаются во всплывающей подсказке.
Для пилюль, размещённых на полке "Значения", можно выбрать тип ("Значение", "Подзаголовок", "Подсказка" -> последние два типа - вспомогательные). Допускается размещение нескольких пилюль, но количество обрабатываемых пилюль определяется выбранным режимом "Первое"/"Все":
#* "Первое" - тогда визуализация обрабатывает только первую пилюлю, размещённую на данной полке. Если для первой пилюли на полке "Значения" назначен вспомогательный тип "Подсказка" или "Подзаголовок", визуализируются значения получаемые из первой пилюли, даже при наличие других необрабатываемых пилюль типа "Значение" на этой полке (то есть первая пилюля обрабатывается как тип "Значение", независимо от выбранного для неё типа).
#* "Все" - при активном режиме "Все" визуализация может обрабатывать все пилюли, размещенные на этой полке, но для визуализации значений используется только первая пилюля, размещённая на полке "Значения" - при выборе для неё типов "Подсказка" или "Подзаголовок", визуализируются значения получаемые из этой пилюли (то есть первая пилюля обрабатывается как тип "Значение", независимо от выбранного для неё типа). Остальные пилюли обрабатываются в соответствии с их выбранным типом, включая вспомогательные пилюли типа "Значение" - их значения отображаются во всплывающей подсказке как дополнительная информация. 
# Полка "Категории" - визуализация активно обрабатывает только первую пилюлю, размещённую на данной полке. Активная пилюля, размещённая на полке "Категории", используется для распределения значений по категориям.
# Полка "Тренд" - визуализация активно обрабатывает только первую пилюлю, размещённую на данной полке. Активная пилюля, размещённая на полке "Тренд", используется для вычисления изменения тренда (дельту прироста или уменьшения. Например, на сколько изменилось значение) по получаемому целевому значению.
# Полка "Фильтры" - позволяет задать как будет происходить фильтрация данных. Общая функциональность полки без изменений.

Не нужно описывать это поведение так подробно, но важно зафиксировать, что введение механизма Мер не меняет стандартного поведения визуализации. Доработка поведения визуализации не входит в скоп задач по данной Истории. Мы фокусируемся на введении механизма Мер и полноценного использования Мер в рамках данной визуализации (на равне в обычными и вычисляемыми полями) в различных сценариях.

Важно учитывать:
1) на данный момент решено отображать пилюли с мерами на полках визуалиаций светло-синим цветом (#3491F7) для всех полок за исключением полки "Фильтры" (там пилюли отображаются в стандартном, для полки "Фильтры", салатовом цвете).
2) новые секции в левой боковой панеле визуализации реализуются в соответствии с уже готовой текущей реализацией.
3) все переиспользуемые компоненты, уже реализованные в других визуализациях, переиспользуются как есть, отдельная реализация именно для этой визуализации не выполняется.

Использование Мер допускается везде, где допускается использование вычисляемых полей.

В правой боковой панеле, в данной визуализации, Меры могут использоваться в следующих селекторах:
* Раздел "Плитки", селектор "Объект данных:",
* Раздел "Тренд", селектор "Поле тренда".

# В правой боковой панеле в разделе "Плитки" в селекторе "Объект данных:" можно выбрать одну из пилюль с полки "Значения" и настроить следующие настройки отображения для неё:
#* Максимальная длина,
#* Размер текста,
#* Точность.
# В правой боковой панеле в разделе «Тренд» можно настроить вывод тренда по определенным значениям (из пилюль с полки "Значения"). В этом разделе настроек есть следующие поля:
#* «Поле тренда» — выберите поле с полки "Значения", по которому будет выполнен расчет. В данном поле могут быть выбраны Меры текущего набора данных, размещённые на полке "Значения";
#* «В процентах» — при включении переключателя будет вывод тренда в процентном значении;
«Максимальная длина» — установите максимальную длину строки выводимого значения. Длина варьируется от 2 до 10 символов;
#* «Размер текста» — установите значение размера текста, принимает значение от 1 до 20 px;
#* «Точность» — установите длину числового значения после точки. Варьируется от 0 до 5 символов;
#* «Цвет увеличения тренда» и «Цвет уменьшения тренда» — в данных полях настраивается цвет плитки. Если значение по тренду увеличивается, то плитка окрашивается в цвет, указанный в «Цвет увеличения тренда». А при уменьшении в цвет поля «Цвет уменьшения тренда».

Поведение текущих настроек визуализации не меняется от добавления мехнизма Мер в рамках этой визуализации.

В целом, использование Мер в данной визуализации согласуется с уже описанными общими механизмами использования мер.
