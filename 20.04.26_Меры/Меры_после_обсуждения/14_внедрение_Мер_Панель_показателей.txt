При работе с визуализацией "Панель показателей" нам также доступна стандартная левая боковая панель (как и во всех других визуализациях) в которой должна появится дополнительная секция "Меры".
Для размещения полей, вычисляемых полей и Мер в данной диаграмме доступны полки:
# Значения - позволяет выбрать значения, которые будут визуализироваться на панеле. -> На полке есть настройка-тумблер с двумя положениями: 
#* "Первое" - тогда для отображения на визуализации используется только первая пилюля, размещенная на этой полке.
#* "Все" - при включении настройки в положение "Все", будут использоваться несколько пилюль размещённых на полке "Значения", однако основной отображаемый параметр на панеле также отображается только один, вторая пилюля влияет на основной отображаемый параметр, а также может влиять на отображаемое значение "Тренда".
# Категории - позволяет задать по каким категориям дробить значения для отображения, а также может влиять на отображаемое значение "Тренда" (активно используется только первая пилюля, размещённая на этой полке).
# Фильтры - полка "Фильтры" позволяет задать как будет происходить фильтрация данных для отображения в визуализации.

Важно учитывать последние согласования и уточнения:
1) на данный момент решено отображать пилюли с мерами на полках визуалиаций светло-синим цветом (#3491F7) для всех полок за исключением полки "Фильтры" (там пилюли отображаются в стандартном, для полки "Фильтры", салатовом цвете).
2) новые секции в левой боковой панеле визуализации пока делаем не сворачиваемыми (отображаем развёрнутыми, без аккордеона).
3) Селектор, в котором могут использоваться поля или меры - это вкладка настроек "Стиль элементов" из правой боковой панели визуализации "Диаграммы площади", на этой вкладке есть селектор "Объект данных" - данный селектор доступен только если для полки визуализации "Серии" тумблер находится в положении "Выкл" или если пилюли на данной полке отсутствуют, т.е. серии не задействованы для отображения в диаграмме. Если для полки визуализации "Серии" тумблер находится в положении "Вкл" и пилюли на данной полке размещены (и задействованы для отображения в диаграмме) - этот селектор недоступен.

В данной визуализации (за исключением стандартных полок визуализации) нет дополнительных селекторов в настройках, где мы можем выбрать обычное поле, вычисляемое поле или Меру - это важно отметить для разработчиков, чтобы точно определить скоуп внедрения мер в данной визуализации.

Использование Мер допускается везде, где допускается использование вычисляемых полей, но, в текущем сценарии, это только стандартные полки визуализации. 

В целом, использование Мер в данной визуализации согласуется с уже описанными общими механизмами использования мер.
