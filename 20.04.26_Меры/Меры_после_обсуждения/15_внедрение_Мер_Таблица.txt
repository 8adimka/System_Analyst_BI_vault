При работе с визуализацией "Таблица" нам также доступна стандартная левая боковая панель (как и во всех других визуализациях) в которой должна появится дополнительная секция "Меры".

Для размещения полей, вычисляемых полей и Мер в данной визуализации доступны полки:
# Значения - позволяет выбрать значения, которые будут визуализироваться в колонках в таблице. -> На полке есть настройка-тумблер с двумя положениями: 
#* "Первое" - тогда для отображения на визуализации используется только первая пилюля, размещенная на этой полке.
#* "Все" - тогда в колонках таблицы выводятся все пилюли, размещенные на этой полке.
# Категории - позволяет задать по каким категориям разделять и визуализировать значения для отображения (активно используется только первая пилюля, размещённая на этой полке).
# Серии - выделяем и групируем значения по заданным категориям, а уже в рамках каждой категории делим по сериям. -> На полке есть настройка-тумблер с двумя положениями: 
#* "Вкл" - пилюли размещённые на полке "серии" используются и влияют на визуализацию, увеличивая колличество отображаемых в таблице колонок, расширяя и детализируя получаемую из визуализации информацию.
#* "Выкл" - "серии" не используются и не влияют на визуализацию.
# Фильтры - полка "Фильтры" позволяет задать как будет происходить фильтрация данных для отображения в визуализации.

Важно учитывать последние согласования и уточнения:
1) на данный момент решено отображать пилюли с мерами на полках визуалиаций светло-синим цветом (#3491F7) для всех полок за исключением полки "Фильтры" (там пилюли отображаются в стандартном, для полки "Фильтры", салатовом цвете).
2) новые секции в левой боковой панеле визуализации пока делаем не сворачиваемыми (отображаем развёрнутыми, без аккордеона).
3) Селекторы, в котором могут использоваться поля или меры:
* вкладка настроек "Общие настройки" из правой боковой панели визуализации "Таблица", на этой вкладке есть селектор "Гиперссылка строки" (Выбор поля для гиперссылки строки, позволяющий при нажатии по любой ячейке строки в режиме просмотра открывать ссылку, соответствующую этой строке) - в данном селекторе можно выбрать обычное поле, вычисляемое поле или Меру, размещённую на полках данной визуализации.
* вкладка настроек "Колонки" из правой боковой панели визуализации "Таблица", на этой вкладке есть селектор "Заголовок по другому полю" - в данном селекторе можно выбрать обычное поле, вычисляемое поле или Меру, размещённую на полке "Значения" данной визуализации.
* вкладка настроек "Колонки" из правой боковой панели визуализации "Таблица", на этой вкладке есть селектор "Гиперссылка" (Выбор колонки со ссылкой, по которой будет осуществлен переход) - в данном селекторе можно выбрать обычное поле, вычисляемое поле или Меру, размещённую на полках данной визуализации.
* вкладка настроек "Груповая обработка ФВД" из правой боковой панели визуализации "Таблица", на этой вкладке есть селектор "Ключ" - в данном селекторе можно выбрать обычное поле, вычисляемое поле или Меру, размещённую на полках данной визуализации.

Использование Мер допускается везде, где допускается использование вычисляемых полей.
