Чтобы подготовить бэкенд для правильной обработки отправляемых Фронтендом запросов, нам нужно определиться какой сейчас механизм используется фронтендом для обычных полей (и вычисляемых полей) и адаптировать его для использования с Мерами на полках визуализаций в дополнение к обычным полям. Для изучения отправляемых фронтендом запросов, мы изучим отправляемые запросы в визуализации "Таблица", при размещении на различных полках визуализации как обычных полей так и вычисляемых полей.

В данный момент для визуализации "Таблица":
* На полке "Значения" с включенным параметром "Все" (при выключении параметра таблица обрабатывает только "Первую" пилюлю размещённую на этой полке) у нас размещается -
1) пилюля обычного поля "Колличество, шт" ("amount"), агрегация SUM, без сортировки.
2) вычисляемое поле, без сортировки, наименование вычисляемого поля "Сумма", содержит код -> 
"CASE {!env.var!;''}
  WHEN 'Накопительно'
    THEN SUM(SUM("summa_rub")) OVER (PARTITION BY "region" ORDER BY "year" ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW)
  WHEN 'По регионам'
    THEN SUM("summa_rub")
  ELSE SUM("summa_rub")
END"

* На полке "Категории" у нас размещается -
1) пилюля обычного поля "Год" ("year"), без сортировки.

* На полке "Серии" с включенным параметром "Вкл" (выключение параметра позволяет отключить учёт серий) у нас размещается -
1) пилюля обычного поля "Федеральный округ" ("fed_okrug_full_name"), без сортировки.
2) пилюля обычного поля "Регион" ("region"), без сортировки.
3) пилюля обычного поля "Тип продукции" ("product_type"), без сортировки.
4) пилюля обычного поля "Продукция" ("product"), без сортировки.

* На полке "Фильтры" у нас размещается -
1) пилюля обычного поля "Федеральный округ" ("fed_okrug_full_name").
2) пилюля обычного поля "Регион" ("region"), без сортировки.
3) пилюля обычного поля "Тип продукции" ("product_type").
4) пилюля обычного поля "Продукция" ("product").
5) пилюля обычного поля "Год" ("year").
6) пилюля обычного поля "Месяц_номер" ("month_num"), для этого фильтра задан параметр "значение по другому полю" чтобы брать наименование месяца по его номеру из колонки набора данных "Месяц_название" ("month_name"), название пилюли "Месяц".
7) вычисляемое поле, наименование вычисляемого поля "Сумма_фильтр", содержит код -> 
"CASE {!env.var!;''}
  WHEN 'Накопительно'

  WHEN 'По регионам'
    THEN SUM("summa_rub")
  ELSE SUM("summa_rub")
END"
Для всех фильтров выбран тип "По значению".
