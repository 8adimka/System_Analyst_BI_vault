При работе с визуализацией "Сводная таблица" нам также доступна стандартная левая боковая панель (как и во всех других визуализациях) в которой должна появится дополнительная секция "Меры".

Для размещения полей, вычисляемых полей и Мер в данной визуализации доступны полки:
# Значения - позволяет выбрать значения, которые будут визуализироваться в колонках в сводной таблице на пересечениях иерархии в строках и иерархии в колонках. -> На полке есть настройка-тумблер с двумя положениями: 
#* "Первое" - тогда для отображения на визуализации используется только первая пилюля, размещенная на этой полке.
#* "Все" - тогда в колонках сводной таблицы выводятся все пилюли, размещенные на этой полке. Т.е. для каждого пересечения отображаются две и более ячейки (по колличеству пилюль, размещённых на полке "Значения").
# Строки - пилюли, размещённые на этой полке, позволяют задать иерархию в строках сводной таблицы.
# Детализация - пилюли, размещённые на этой полке, создают дополнительные (вне иерархии колонок) колонки, в которых можно разместить дополнительную информацию для детализации. 
# Столбцы - пилюли, размещённые на этой полке, позволяют задать иерархию в столбцах сводной таблицы.
# Дополнительные - пилюли, размещённые на этой полке, не влияют на формирование основного SQL-запроса, но могут быть использованы для некоторых дополнительных операций (например, фильтрации).
# Фильтры - полка "Фильтры" позволяет задать как будет происходить фильтрация данных для отображения в визуализации.

Важно учитывать последние согласования и уточнения:
1) на данный момент решено отображать пилюли с мерами на полках визуалиаций светло-синим цветом (#3491F7) для всех полок за исключением полки "Фильтры" (там пилюли отображаются в стандартном, для полки "Фильтры", салатовом цвете).
2) новые секции в левой боковой панеле визуализации пока делаем в соответствии с текущей реализацией, а последняя реализация - сворачиваемые секции (аккардион).
3) Селекторы, в котором могут использоваться поля или меры:
* вкладка настроек "Настройка Полей" из правой боковой панели визуализации "Сводная таблица", на этой вкладке есть селектор для выбора настроемого поля сводной таблицы - можно выбрать пилюли с полок "Значения", "Строки", "Столбцы).
* вкладка настроек "Настройка Полей" из правой боковой панели визуализации "Сводная таблица", на этой вкладке есть селектор "Заголовок по другому полю" - можно выбрать пилюли с полки "Значения".
* вкладка настроек "Расшифровка значения" из правой боковой панели визуализации "Сводная таблица", на этой вкладке есть селектор "Режим расшифрокви":
** В режиме расшифровки "Переход по ссылке" есть селектор "Выберите значение" - в этом селекторе можно выбрать пилюлю с полки "Значения". Для выбранного значения, при нажатии на него в таблице, можно добавить ссылку для перехода (и задать "Открывать" ли данную ссылку в Новой вкладке или в той же вкладке).
** При выборе режима "Модальное окно" появляется два селектора, где можно выбрать поле, вычисляемое поле или Меру, размещённую на полке "Значение":
*** селектор "Поле" - аналогично выбираем знаение из таблицы для расфишровки. При нажатии на это значение в сводной таблице будет открываться модальное окно.
*** селектор "Контекстное поле" - в этом селекторе можно выбрать пилюлю с полки "Значения" - значение из этой пилюли будет передано в открываемое модальное окно и может быть использовано для дополнительной динамической информативности модального окна.

Использование Мер допускается везде, где допускается использование вычисляемых полей.
