При работе с этой диаграммой нам доступна стандартная левая боковая панель (как и во всех других визуализациях) в которой должна появится дополнительная секция "Меры".
Для размещения полей, вычисляемых полей и Мер в данной диаграмме доступны полки:
# Значения - позволяет выбрать значения, которые будут визуализироваться в диаграмме при помощи столбцов различного размера. -> На полке есть настройка-тумблер с двумя положениями: 
#* "Первое" - тогда для отображения на визуализации используется только первая пилюля, размещенная на этой полке.
#* "Все" - тогда для отображения на диаграмме используются все пилюли, размещенные на этой полке.
# Категории - позволяет задать по каким категориям дробить значения для отображения (активно используется только первая пилюля, размещённая на этой полке).
# Серии - выделяем и групируем значения по заданным категориям, а уже в рамках каждой категории делим по сериям. -> На полке есть настройка-тумблер с двумя положениями: 
#* "Вкл" - пилюли размещённые на полке "серии" используются и влияют на визуализацию, увеличивая колличество отображаемых на диаграмме столбцов, расширяя и детализируя получаемую из визуализации информацию.
#* "Выкл" - "серии" не используются и не влияют на визуализацию.
# Фильтры - полка "Фильтры" позволяет задать как будет происходить фильтрация данных для отображения в визуализации.

Важно учитывать последние согласования и уточнения:
1) на данный момент решено отображать пилюли с мерами на полках визуалиаций светло-синим цветом (#3491F7).
2) новые секции в левой боковой панеле визуализации пока делаем не сворачиваемыми (отображаем развёрнутыми, без аккордеона).
3) Селектор, в котором могут использоваться поля или меры - это вкладка "Стилизация" из правой боковой панели визуализации "Линейная диаграмма", на этой вкладке есть селектор "Объект данных" - данный селектор доступен только если для полки визуализации "Серии" тумблер находится в положении "Выкл", т.е. серии не задействованы для отображения в диаграмме. Если для полки визуализации "Серии" тумблер находится в положении "Вкл" - этот селектор недоступен.

В селекторе "Объект данных" (если он доступен) мы можем выбрать как обычное, так и вычисляемое поле, а следовательно для этого селектора мы должны поддержать возможность выбрать Меру. Других дополнительных мест для примерения Мер в данной визуализации нет (за исключением стандартных полок визуализации) - это важно отметить для разработчиков, чтобы точно определить скоуп внедрения мер в данной визуализации.

Требуется обеспечить полноценное внедрение и использование мер в рамках визуализации "Диаграмма линейная". Использование Мер допускается везде, где допускается использование вычисляемых полей, но в текущем сценарии это только селектор "Объект данных" во вкладке "Стиль элементов" из правой боковой панели визуализации "Диаграмма столбчатая". Дополнительный селектор допустимый для мер - это "Текст для" во вкладке "Легенда" (При выборе из выпадающего списка нужной категории есть возможность ввода любого другого текста для выбранной легенды в поле «Введите текст легенды». Это позволяет давать необходимые объяснения в легенде, а не отображать только категорию) - данный селектор доступен только если для полки визуализации "Серии" тумблер находится в положении "Выкл", т.е. серии не задействованы для отображения в диаграмме. Если для полки визуализации "Серии" тумблер находится в положении "Вкл" - этот селектор также недоступен для выбора Мер.

В целом, использование Мер в данной визуализации согласуется с уже описанными общими механизмами использования мер.
