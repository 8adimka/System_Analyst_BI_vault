"Настройки клика" в визуализации "Индикатор стрелочный" работают согластно стандартному функционалу и позволяют, например, настроить переход в другой отчёт при нажатии на специальную кнопку (располагается в полоске управления сверху диаграммы).

При работе с визуализацией "Индикатор стрелочный v.2.0" нам доступна стандартная левая боковая панель (как и во всех других визуализациях). Ранее на левой боковой панеле располагались только пилюли, которые формировались из колонок набора данных, а также отдельная пилюля "Вычисляемое поле", а теперь должна появится дополнительная секция "Меры". Пилюли из левой боковой панели мы можем располагать на полках настраиваемой визуализации.
Для размещения полей, вычисляемых полей и Мер в Круговой диаграмме доступны полки:
# Значения - позволяет выбрать значения (разместить пилюли на данной полке), которые будут визуализироваться. -> На полке есть настройка-тумблер с двумя положениями: 
#* "Первое" - тогда визуализация обрабатывает только первую пилюлю, размещённую на данной полке (т.е. создаёт только одну стрелку и визуализирует значения по первой пилюле).
#* "Все" - тогда визуализация обрабатывает все пилюли, размещенные на этой полке (т.е. создаются несколько стрелок для визуализации значений из нескольких пилюль). Также пилюли, размещённые на этой полке, могут использоваться как вспомогательные и для них может выбираться в настройках особый тип - в настройках пилюли им может быть выбран "Тип": 
#** "Значение" (обрабатывается значение для визуализации),
#** "Отсечка" (получаемое значение из этой пилюли используется, чтобы отрисовать отсечку на шкале), 
#** "Minimum",
#** "Maximum",
#** "Цвет".
# Категории - позволяет задать по каким категориям групировать значения для отображения (активно используется только первая пилюля, размещённая на этой полке).
# Фильтры - полка "Фильтры" позволяет задать как будет происходить фильтрация данных для отображения в визуализации, функциональность без изменений.

Важно учитывать:
1) на данный момент решено отображать пилюли с мерами на полках визуалиаций светло-синим цветом (#3491F7) для всех полок за исключением полки "Фильтры" (там пилюли отображаются в стандартном, для полки "Фильтры", салатовом цвете).
2) новые секции в левой боковой панеле визуализации пока делаем в соответствии с текущей реализацией, а последняя реализация - сворачиваемые секции (аккардион).

Использование Мер допускается везде, где допускается использование вычисляемых полей.

В правой боковой панеле нужно проработать использование Мер в ряде настроек:
* Вкладка настроек "Легенда", селектор "Текст для", при выборе из выпадающего списка нужной пилюли с полки "Значения", позволяет задать для этой пилюли отображаемое в легенде наименование. Т.е. мы выбираем пилюлю с полки "Значения" в селекторе "Текст для" и ниже задаём для неё наименование, которое будет отображаться в легенде данной визуализации для этой пилюли.
* Во вкладке настроек правой боковой панеле "Стилизация значений", в селекторе "Объект данных" мы можем выбрать поля, вычисляемые поля или Меры, размещённые на полке "Значения", чтобы задать им особую кастомную стилистику, т.е. для визуализации настроенных тут пилюль с полки "Значения" будут использоваться заданные тут цвета стрелки и дуги (чтобы наглядно отличать это значение на визуализации, что особенно удобно, если значений задано несколько и их нужно отличать визуально). Также на вкладке "Стилизация значений" можно настроить другие параметры отображения, но для мер важно проработать их возможное использование в селекторе "Объект данных".
