Также прикрепляю скриншот визуализации "Диаграмма Радарная" (на нашем аналитическом портале) в режиме настройки для изучения разделов их настроек:
./Радарная_диаграмма_Стилизация.png

Данная визуализация используется для визуализации *нескольких характеристик* одного или нескольких объектов *на одной диаграмме*.

Главная идея радарной диаграммы - не просто показать отдельные числа, а дать возможность одним взглядом увидеть соотношение нескольких характеристик одного объекта, а также сравнить профили нескольких таких объектов.

При работе с визуализацией "Диаграмма Радарная" нам доступна стандартная левая боковая панель (как и во всех других визуализациях). Ранее на левой боковой панеле располагались только пилюли, которые формировались из колонок набора данных, а также отдельная пилюля "Вычисляемое поле", а теперь должна появится дополнительная секция "Меры". Пилюли из левой боковой панели мы можем располагать на полках настраиваемой визуализации. Левая боковая панель в данной визуализации переиспользует уже реализованный компонент в соответствии с текущей его реализацией.


Для размещения полей, вычисляемых полей и Мер в визуализации "Диаграмма Радарная" доступны полки:
# Полка "Значения" - на данной полке можно разместить поля набора данных, вычисляемые поля или Меры, значения которых используются для создания "Профиля" исследуемого объекта. -> На данной полке есть настройка-тумблер с двумя положениями: 
#* "Первое" - тогда визуализация обрабатывает только первую пилюлю, следовательно, при выключенном режиме "Серии", на визуализации будет создан только один "Профиль" - отрисовав полученное значение на каждой оси категорий и соединив все полученные точки по кругу.
#* "Все" - при выключенном режиме "Серии", каждая размещенная на этой полке пилюля создаёт свой "профиль", аналогичным образом отрисовывая полученные из пилюли значения на каждой оси категории и последовательно соединяя все точки в единый профиль. Для каждой размещённой пилюли так создаётся свой профиль. 
#* Для пилюль, размещённых на этой полке, могут использоваться как вспомогательные и для них может быть выбран "Тип" в настройках пилюли (обработка или не обработка вспомогательных пилюль также зависит от выбранного режима "Первое"/"Все"):
#** Тип "Значение",
#** Тип "Отсечка",
#** Тип "Подзаготовок",
#** Тип "Подсказка".
# Полка "Категории" - на этой полке обробатывается только первая пилюля и позволяет задать оси Радарной диаграммы по которым будут отображаться и распределяться "значения". Например, при выборе пилюли "Федеральный округ" на диаграмме мы получим распределение значения, заданного на полке "Значения", по разным федеральным округам. Т.е. каждый федеральный округ из выбранной пилюли образует свою ось на диаграмме.
# Полка "Серии" - на полке располагается тумблер "Вкл"/"Выкл", полка начинает воздействовать на диаграмму только при выполнении двух условий - тумблер находится в состоянии "Вкл" и на полке размещена валидная пилюля. Когда полка начинает воздействовать на диграмму "профили" строятся уже не по набору значений с полки "Значения", а по сериям из пилюли, размещённой на полке "Серии" (тогда значение берётся только из первой пилюли с полки "Значения", а остальные пилюли с полки "Значения" игнорируются (кроме вспомогательных при включённом режиме "Все")). Т.е. при включении режима Серий, каждая серия создаёт отдельный профиль по значению из первой пилюли с полки "Значения". На этой полке максимум обрабатывается одна размещённая пилюля.
# Полка "Фильтры" - позволяет задать как будет происходить фильтрация данных, может влиять на логику отображения картинок, подзаголовков или подсказок, реализованную через вычисляемые поля или Меры. Общая функциональность полки без изменений.

Важно учитывать:
1) на данный момент решено отображать пилюли с мерами на полках визуалиаций светло-синим цветом (#3491F7) для всех полок за исключением полки "Фильтры" (там пилюли отображаются в стандартном, для полки "Фильтры", салатовом цвете).
2) новые секции в левой боковой панеле визуализации реализуются в соответствии с уже готовой текущей реализацией.
3) все переиспользуемые компоненты, уже реализованные в других визуализациях переиспользуются как есть, отдельная реализация именно для этой визуализации не выполняется.

Использование Мер допускается везде, где допускается использование вычисляемых полей.

В правой боковой панеле, в данной визуализации, Меры и значения полученные из Мер могут попадать в следующие селекторы:
* в разделе "Легенда" - в селектор "Текст для:" при выключенном режиме "Серий" попадают активные пилюли с полки "Значения" (так как на основе пилюль, размещённых на полке "Значения", создаются визуализируемые профили и для профилей создаётся легенда). При включенном режиме "Серии" в селектор "Текст для:" попадают конкретные значения пилюли размещённой на полке "Серии" (так как легенда создаётся по этим значениям). Ниже можно задать заголовок вручную для пункта легенды выбранного в селекторе "Текст для:".
* в разделе "Стилизация" по аналогичной логике, при включенном режиме "Серии", в селектор "Объект данных:" попадают конкретные значения пилюли размещённой на полке "Серии" (для настройки стилистики по конкретному визуализируемому профилю). При выключенном режиме "Серий" в селектор "Объект данных:" попадают активные пилюли с полки "Значения" (в зависимости от выбранного режима "Первое"/"Все" на полке "Значения").

В целом, использование Мер в данной визуализации согласуется с уже описанными общими механизмами использования мер.
