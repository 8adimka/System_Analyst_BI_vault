Остальные настройки дублируют настройки, например, в "Диаграмме столбчатой".

При работе с визуализацией "Диаграмма круговая" нам доступна стандартная левая боковая панель (как и во всех других визуализациях). Ранее на левой боковой панеле располагались только пилюли, которые формировались из колонок набора данных, а также отдельная пилюля "Вычисляемое поле", а теперь должна появится дополнительная секция "Меры". Пилюли из левой боковой панели мы можем располагать на полках настраиваемой визуализации.
Для размещения полей, вычисляемых полей и Мер в Круговой диаграмме доступны полки:
# Значения - позволяет выбрать значения (разместить пилюли на данной полке), которые будут визуализироваться в данной диаграмме. -> На полке есть настройка-тумблер с двумя положениями: 
#* "Первое" - тогда визуализация обрабатывает только первую пилюлю, размещённую на данной полке (т.е. визуализирует выбранные значения в круговой диаграмме).
#* "Все" - тогда визуализация обрабатывает все пилюли, размещенные на этой полке, но визуализирует значения в круговой диаграмме всё равно только по первой выбранной пилюле на данной полке. Другие пилюли со значениями могут использоваться как вспомогательные и выбираться в настройках - в настройках пилюли им может быть выбран "Тип": "Значение" (обрабатывается только первая пилюля), "Цвет", "Подзаголовок", "Подсказка".
# Категории - позволяет задать по каким категориям групировать значения для отображения (активно используется только первая пилюля, размещённая на этой полке).
# Серии - выделяем и групируем значения по заданным категориям, а уже в рамках каждой категории делим по сериям. Похоже, что, в рамках круговой диаграммы, мы зачастую получаем отображение только по одной серии. -> На полке есть настройка-тумблер с двумя положениями: 
#* "Вкл" - пилюли размещённые на полке "серии" используются и влияют на визуализацию (дополнительная групировка).
#* "Выкл" - "серии" не используются и не влияют на визуализацию.
# Фильтры - полка "Фильтры" позволяет задать как будет происходить фильтрация данных для отображения в визуализации, функциональность без изменений.
