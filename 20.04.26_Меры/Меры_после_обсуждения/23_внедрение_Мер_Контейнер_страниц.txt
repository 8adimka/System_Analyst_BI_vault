./Панель_с_картинкой_Настройки_изображения.png

Данная визуализация используется для организации и групировки других визуализаций портала по страницам. Внутри "Контейнера страниц" можно создать несколько страниц, разместить на них заранее подготовленные визуализации текущего отчёта (при помощи кнопки "Групировка") и для их просмотра переключать страницы - это помогает экономить место и не перегружать отчёт, а также организовывать в отчёте смысловые группы визуализаций. 

При работе с визуализацией "Контейнер страниц" нам доступна стандартная левая боковая панель (как и во всех других визуализациях). Ранее на левой боковой панеле располагались только пилюли, которые формировались из колонок набора данных, а также отдельная пилюля "Вычисляемое поле", а теперь должна появится дополнительная секция "Меры". Пилюли из левой боковой панели мы можем располагать на полках настраиваемой визуализации.
Для размещения полей, вычисляемых полей и Мер в визуализации "Контейнер страниц" доступны полки:
# Полка "Значения" - на данной полке можно разместить поля набора данных, вычисляемые поля или Меры, информация из которых будет использована в построении визуализации. -> На данной полке есть настройка-тумблер с двумя положениями: 
#* "Первое" - тогда визуализация обрабатывает только первую пилюлю, размещённую на данной полке.
#* "Все" - тогда визуализация обрабатывает все пилюли, размещенные на этой полке. 
#* Для пилюль, размещённых на этой полке, "Тип" в настройках пилюли выюран быть не может.
# Полка "Фильтры" - позволяет задать как будет происходить фильтрация данных, может влиять на логику отображения картинок, подзаголовков или подсказок, реализованную через вычисляемые поля или Меры. Общая функциональность полки без изменений.

Важно учитывать:
1) на данный момент решено отображать пилюли с мерами на полках визуалиаций светло-синим цветом (#3491F7) для всех полок за исключением полки "Фильтры" (там пилюли отображаются в стандартном, для полки "Фильтры", салатовом цвете).
2) новые секции в левой боковой панеле визуализации пока делаем в соответствии с текущей реализацией, а последняя реализация - сворачиваемые секции (аккардион).

Использование Мер допускается везде, где допускается использование вычисляемых полей.

В правой боковой панеле, в данной визуализации, Меры используются в разделе "Стиль страниц" - в селекторе "Заголовок из данных" появляются все пилюли размещённые на полке "Значения".

Настройка "Заголовок из данных" позволяет задавать название для настраеваемой страницы опираясь на данные из выбранной пилюли.

В целом, использование Мер в данной визуализации согласуется с уже описанными общими механизмами использования мер.
