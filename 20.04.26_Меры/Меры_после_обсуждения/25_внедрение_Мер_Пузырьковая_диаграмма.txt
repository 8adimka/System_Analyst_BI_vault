При работе с визуализацией "Диаграмма пузырьковая" нам доступна стандартная левая боковая панель (как и во всех других визуализациях). Ранее на левой боковой панеле располагались только пилюли, которые формировались из колонок набора данных, а также отдельная пилюля "Вычисляемое поле", а теперь должна появится дополнительная секция "Меры". Пилюли из левой боковой панели мы можем располагать на полках настраиваемой визуализации. Левая боковая панель в данной визуализации переиспользует уже реализованный компонент в соответствии с текущей его реализацией.

Для размещения полей, вычисляемых полей и Мер в визуализации "Диаграмма пузырьковая" доступны полки:
# Полка "ЗначенияY" - активно обрабатывается только первая размещённая пилюля (задаёт ось Y пузырьковой диаграммы), но можно разместить вспомогательные пилюли и назначить им Тип.
#* Для пилюль, размещённых на этой полке, могут использоваться как вспомогательные и для них может быть выбран "Тип" в настройках пилюли (обработка или не обработка вспомогательных пилюль также зависит от выбранного режима "Первое"/"Все"):
#** Тип "Значение",
#** Тип "Цвет",
#** Тип "Подзаголовок",
#** Тип "Подсказка".
# Полка "ЗначенияX" - активно обрабатывается только первая размещённая пилюля (задаёт ось X пузырьковой диаграммы), можно разместить вспомогательные пилюли и назначить им особый Тип.
#* Для пилюль, размещённых на этой полке, могут использоваться как вспомогательные и для них может быть выбран "Тип" в настройках пилюли (обработка или не обработка вспомогательных пилюль также зависит от выбранного режима "Первое"/"Все"):
#** Тип "Значение",
#** Тип "Цвет",
#** Тип "Подзаголовок",
#** Тип "Подсказка".
# Полка "Значения" - на данной полке можно разместить поля набора данных, вычисляемые поля или Меры, значения которых используются для создания "Профиля" исследуемого объекта. -> На данной полке есть настройка-тумблер с двумя положениями: 
#* "Первое" - тогда визуализация обрабатывает только первую пилюлю. При размещении вспомогательных пилюль (назначении им особого типа) - пилюли после первой аналогично не обрабатываются.
#* "Все" - каждая размещенная на этой полке пилюля может обрабатываться диаграммой и участвовать в построении запроса, а также возможно размещать тут вспомогательные пилюли (назначать им особый тип). 
#* Для пилюль, размещённых на этой полке, могут использоваться как вспомогательные и для них может быть выбран "Тип" в настройках пилюли (обработка или не обработка вспомогательных пилюль также зависит от выбранного режима "Первое"/"Все"):
#** Тип "Значение",
#** Тип "Цвет",
#** Тип "Подзаголовок",
#** Тип "Подсказка".
# Полка "Категории" - на этой полке обробатывается только первая пилюля и позволяет задать отображаемые категории.
# Полка "Серии" - на полке располагается тумблер "Вкл"/"Выкл", полка начинает воздействовать на диаграмму только при выполнении двух условий - тумблер находится в состоянии "Вкл" и на полке размещена валидная пилюля. Когда полка начинает воздействовать на диграмму пузыри на диаграмме создаются уже для категория*серия - разбиение на серии (несколько наборов точек).
# Полка "Фильтры" - позволяет задать как будет происходить фильтрация данных, может влиять на логику отображения картинок, подзаголовков или подсказок, реализованную через вычисляемые поля или Меры. Общая функциональность полки без изменений.

Использование Мер допускается везде, где допускается использование вычисляемых полей.

В правой боковой панеле, в данной визуализации, Меры и значения полученные из Мер не используются. В открытых вопросах оставить для проверки разработчиком селектор "Подпись по другому полю" в разделе настроек "Легенда для цвета".
