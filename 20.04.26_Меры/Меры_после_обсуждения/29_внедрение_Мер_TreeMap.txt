Вот пример настроек визуализации "Дерево (TreeMap)" в режиме отладки ./Настройки_TreeMap_в_режиме_отладки.txt

При работе с визуализацией "Дерево (TreeMap)" нам доступна стандартная левая боковая панель (как и во всех других визуализациях). Ранее на левой боковой панеле располагались только пилюли, которые формировались из колонок набора данных, а также отдельная пилюля "Вычисляемое поле", а теперь должна появиться дополнительная секция "Меры". Пилюли из левой боковой панели мы можем располагать на полках настраиваемой визуализации. Левая боковая панель в данной визуализации переиспользует уже реализованный компонент в соответствии с его текущей реализацией.

Для размещения полей, вычисляемых полей и Мер в визуализации "Дерево (TreeMap)" доступны полки:
# Полка "Значения",
# Полка "Категории",
# Полка "Серии",
# Полка "Фильтры".

Полка "Серии" активная только если её тумблер (Вкл/Выкл) находится в положении *"Вкл"* и на ней размещена хотя бы одна пилюля. Иначе полка *неактивна*.

В зависимости от активности полки "Серии", наблюдается разное поведение визуализации.

Если полка "Серии" *активна*, то наблюдается такое поведение:
# Полка "Значения" - на данной полке можно разместить поля набора данных, вычисляемые поля или Меры, полученные из них значения используются для визуализации распределения этих значений по категориям (категории получаем из первой пилюли, размещенной на полке "Категории") и подкатегорий (серий) -> значения, полученные из первой пилюли, размещённой на полке "Значения", визуализируются показывая распределение значений по категориям (и подкатегориям (сериям), при их активации). Для пилюль, размещённых на полке "Значения", можно выбрать тип ("Значение", "Цвет", "Подзаголовок", "Подсказка" -> последние три типа - вспомогательные). Допускается размещение нескольких пилюль, но для визуализации значений используется только первая, размещённая на этой полке, пилюля, независимо от выбранного для неё типа. Количество обрабатываемых пилюль определяется выбранным режимом "Первое"/"Все":
#* "Первое" - тогда визуализация обрабатывает только первую пилюлю, размещённую на данной полке. Если для первой пилюли на полке "Значения" назначен вспомогательный тип "Цвет" или "Подзаголовок", визуализируются значения получаемые из этой пилюли, даже при наличие других необрабатываемых пилюль типа "Значение" на этой полке (то есть первая пилюля обрабатывается как тип "Значение", независимо от выбранного для неё типа). Однако, при выборе вспомогательного типа "Подсказка" для первой пилюли на полке "Значения" - визуализация не строится и отображает стандартное ошибочное состояние визуализации - "Что-то пошло не так, но мы обязательно разберемся" (даже при наличие других необрабатываемых пилюль типа "Значение" на этой полке).
#* "Все" - при активном режиме "Все" визуализация может обрабатывать все пилюли, размещенные на этой полке, но для визуализации значений используется только первая пилюля, размещённая на полке "Значения" - при выборе для неё типов "Цвет" или "Подзаголовок", визуализируются значения получаемые из этой пилюли (то есть первая пилюля обрабатывается как тип "Значение", независимо от выбранного для неё типа). Однако, при выборе вспомогательного типа "Подсказка" для первой пилюли на полке "Значения" - визуализация не строится и отображает стандартное ошибочное состояние визуализации - "Что-то пошло не так, но мы обязательно разберемся" (даже при наличие других пилюль типа "Значение" на этой полке). Остальные пилюли обрабатываются в соответствии с их выбранным типом (то есть обрабатываются только вспомогательные типы пилюль). 
# Полка "Категории" - визуализация активно обрабатывает только первую пилюлю, размещённую на данной полке. Активная пилюля, размещённая на полке "Категории", используется для определения отображаемых категорий и распределения значений по этим категориям.
# Полка "Серии" - визуализация активно обрабатывает только первую пилюлю, размещённую на данной полке. Активная пилюля, размещённая на полке "Серии", используется для определения отображаемых подкатегорий и распределения значений по этим подкатегориям.
# Полка "Фильтры" - позволяет задать как будет происходить фильтрация данных. Общая функциональность полки без изменений.

Если полка "Серии" *НЕ активна*, то наблюдается такое поведение:
# Полка "Значения" - на данной полке можно разместить поля набора данных, вычисляемые поля или Меры, полученные из них значения используются для визуализации распределения этих значений по категориям (категории получаем из первой пилюли, размещенной на полке "Категории") -> значения, полученные из первой пилюли, размещённой на полке "Значения", визуализируются показывая распределение значений по категориям. Для пилюль, размещённых на полке "Значения", можно выбрать тип ("Значение", "Цвет", "Подзаголовок", "Подсказка" -> последние три типа - вспомогательные). Допускается размещение нескольких пилюль, но для визуализации значений используется только первая пилюля этой полки, при наличии у неё типа "Значение". Количество обрабатываемых пилюль определяется выбранным режимом "Первое"/"Все":
#* "Первое" - тогда визуализация обрабатывает только первую пилюлю, размещённую на данной полке. Если для первой пилюли на полке "Значения" назначен вспомогательный тип "Цвет", "Подзаголовок" или "Подсказка" - визуализация не строится корректно и отображает пустое значение ("0") (даже при наличие других необрабатываемых пилюль типа "Значение" на этой полке).
#* "Все" - при активном режиме "Все" визуализация может обрабатывать все пилюли, размещенные на этой полке, но для визуализации значений используется только первая пилюля, размещённая на полке "Значения". При выборе для первой пилюли типов "Цвет", "Подзаголовок" или "Подсказка" - визуализация не строится корректно и отображает пустое значение ("0"), даже при наличие других пилюль типа "Значение" на этой полке. Остальные пилюли обрабатываются в соответствии с их выбранным типом (то есть обрабатываются только вспомогательные типы пилюль).
# Полка "Категории" - визуализация активно обрабатывает только первую пилюлю, размещённую на данной полке. Активная пилюля, размещённая на полке "Категории", используется для определения отображаемых категорий и распределения значений по этим категориям.
# Полка "Серии" - не обрабатывается визуализацией в таком сценарии.
# Полка "Фильтры" - позволяет задать как будет происходить фильтрация данных. Общая функциональность полки без изменений.

Не нужно описывать это поведение так подробно, но важно зафиксировать, что введение механизма Мер не меняет стандартного поведения визуализации. Доработка поведения визуализации не входит в скоп задач по данной Истории. Мы фокусируемся на введении механизма Мер и полноценного использования Мер в рамках данной визуализации на равне в обычными и вычисляемыми полями в различных сценариях.

2) новые секции в левой боковой панеле визуализации реализуются в соответствии с уже готовой текущей реализацией.

В правой боковой панеле, в данной визуализации, Меры (и значения полученные из Мер) не использутся в селекторах настроек. Поведение текущих настроек визуализации не меняется от добавления мехнизма Мер в рамках этой визуализации.
