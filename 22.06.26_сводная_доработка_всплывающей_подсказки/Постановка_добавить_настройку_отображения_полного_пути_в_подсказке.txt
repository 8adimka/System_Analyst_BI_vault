h3. Контекст и проблематика

В визуализации *«Таблица сводная»* при наведении на ячейку отображается tooltip с полным иерархическим путём до текущей ячейки. Сейчас такой путь начинается со служебного фрагмента {{root/}} и может включать несколько вложенных уровней, например: {{root/ДВФО/Забайкальский край/Мягкая мебель/Кресло}}.

Для пользователя это выглядит как техническая информация, перегружает подсказку и мешает быстро считать значение текущей ячейки. В большинстве сценариев пользователю достаточно видеть только текст той ячейки, на которую он навёл указатель.

----

h3. Цель задачи:

# Добавить для визуализации *«Таблица сводная»* настройку типа {{checkbox}}: *«Показывать полный путь к ячейке в подсказке»*.
# По умолчанию настройка должна быть выключена: {{tooltip}} показывает только значение текущей ячейки.
# При включённой настройке {{tooltip}} показывает полный путь к ячейке по иерархии сводной таблицы, но без служебного {{root/}} и без подстановки иных дополнительных уровней (например, «Итого»).
# Обеспечить сохранение настройки в конфигурации виджета и обратную совместимость со старыми отчётами.

*Пользовательская история:*
Как пользователь аналитического портала, я хочу управлять детализацией всплывающей подсказки в сводной таблице, чтобы видеть либо только значение текущей ячейки, либо полный иерархический путь без технических артефактов.

----

h3. 1. Описание текущего поведения.

* В основном портале в визуализации *«Таблица сводная»* при наведении на ячейку отображается tooltip.
* Tooltip всегда строится как полный путь до ячейки и начинается со служебного уровня {{root/}}.
* В tooltip могут попадать промежуточные уровни иерархии, которые не всегда нужны пользователю.
* Настройки, позволяющей переключить tooltip в режим отображения только текущей ячейки, сейчас нет.
* Примеры текущего поведения приведены на скриншотах во вложениях к задаче.

----

h3. 2. Описание целевого поведения.

В настройках сводной таблицы появляется два режима работы tooltip.

# *Настройка выключена* — tooltip показывает только значение текущей ячейки:

* отображается текст/значение ячейки, на которую наведён указатель;
* значение выводится с учётом текущего форматирования ячейки;
* полный путь по иерархии не отображается.

# *Настройка включена* — tooltip показывает полный путь к ячейке:

* сохраняется текущая логика определения пути до ячейки по уровням иерархии сводной таблицы;
* из начала пути удаляется служебный сегмент {{root/}};
* после удаления {{root/}} не должно оставаться ведущего {{/}}, двойных разделителей или пустых сегментов;
* слово «Итого» не добавляется как замена {{root/}} и не используется как искусственный корневой уровень.

----

h3. 3. Требования к реализации.

h4. 3.1. Интерфейс и настройки.

* Добавить checkbox в настройки визуализации *«Таблица сводная»*.
* Разместить настройку в разделе *«Общие настройки»*.
* Название настройки: *«Показывать полный путь к ячейке в подсказке»*.
* Значение по умолчанию: *выключено*.

|| Параметр || Значение ||
| Тип настройки | checkbox |
| Раздел | Общие настройки |
| Значение по умолчанию | выключено |
| Область действия | только визуализация «Таблица сводная» |

* Tooltip при наведении на саму настройку должен отражать текущий режим:
  ** если настройка выключена: *«В подсказке отображается только значение текущей ячейки.»*;
  ** если настройка включена: *«В подсказке отображается полный путь к ячейке с учётом иерархии сводной таблицы.»*.

---
h4. 3.2. Фронтенд-логика tooltip.

* При выключенной настройке tooltip должен брать только отображаемое значение текущей ячейки.
* Если текст в ячейке визуально обрезан из-за ширины колонки, в tooltip допускается показывать полное значение этой ячейки, но без иерархического пути.
* При включённой настройке tooltip должен показывать полный путь по иерархии, но в пользовательском виде:
  ** без {{root/}};
  ** без иных начальных значений;
  ** без пустых сегментов и лишних разделителей.
* Визуальный стиль tooltip, позиционирование, поведение при наведении и скрытии должны сохраниться без изменений, если они не противоречат новой логике содержимого.

---
h4. 3.3. Сохранение настройки и метаданные.

* Настройка должна сохраняться в конфигурации конкретного виджета сводной таблицы.
* Для новых сводных таблиц настройка должна создаваться со значением {{false}}.
* Для ранее созданных отчётов, где параметр отсутствует, система должна трактовать отсутствие параметра как {{false}}.
* Рекомендуемое техническое имя параметра: {{show_full_path_in_tooltip}}. Итоговое имя согласовать с текущими соглашениями frontend/backend.
* При сохранении отчёта не должны затираться другие настройки визуализации.
* Если сохранение конфигурации выполняется через backend-объект отчёта, перед {{update}} необходимо использовать актуальное состояние через {{get/list}} согласно существующему контракту портала.

---
h4. 3.4. Технические ограничения.

* Задача не должна менять SQL-генерацию, состав набора данных, фильтрацию, сортировку, drill-down и отображение итогов в самой сводной таблице.
* При наведении на ячейку не должно появляться дополнительных backend-запросов только для формирования tooltip.
* Изменение применяется только к визуализации *«Таблица сводная»* и не должно влиять на плоскую таблицу или другие визуализации.

---
h4. 3.5. Что не входит в рамки задачи:

* Редизайн tooltip.
* Изменение логики расчёта строк и колонок.
* Изменение структуры полок сводной таблицы.
* Изменение поведения фильтров, контейнера фильтров и общей панели фильтров.

----

h3. 5. Критерии приёмки (AC):

AC.1 — *Настройка добавлена в корректный раздел:*

* *Дано:* пользователь редактирует виджет *«Таблица сводная»*;
* *Когда:* он открывает раздел *«Общие настройки»*;
* *Тогда:* отображается checkbox *«Показывать полный путь к ячейке в подсказке»*;
* *И:* по умолчанию checkbox выключен.

AC.2 — *Tooltip при выключенной настройке показывает только текущую ячейку:*

* *Дано:* настройка выключена;
* *Когда:* пользователь наводит указатель на ячейку сводной таблицы;
* *Тогда:* tooltip содержит только значение этой ячейки;
* *И:* tooltip не содержит {{root}}, {{root/}} и иерархический путь через родительские уровни.

AC.3 — *Tooltip при включённой настройке показывает полный путь без технических артефактов:*

* *Дано:* настройка включена;
* *Когда:* пользователь наводит указатель на ячейку, у которой есть несколько уровней иерархии;
* *Тогда:* tooltip содержит полный путь к ячейке по уровням сводной таблицы;
* *И:* путь не начинается с {{root/}};
* *И:* в начале пути не отображается «Итого» как замена {{root/}};
* *И:* в tooltip нет ведущего {{/}}, двойных {{//}} и пустых сегментов.

AC.4 — *Подсказка настройки отражает текущий режим:*

* *Дано:* пользователь навёл указатель на настройку *«Показывать полный путь к ячейке в подсказке»*;
* *Когда:* checkbox выключен;
* *Тогда:* tooltip настройки сообщает, что в подсказке отображается только значение текущей ячейки;
* *Когда:* checkbox включён;
* *Тогда:* tooltip настройки сообщает, что в подсказке отображается полный путь к ячейке с учётом иерархии.

AC.5 — *Настройка сохраняется и восстанавливается:*

* *Дано:* пользователь изменил значение настройки и сохранил отчёт;
* *Когда:* пользователь повторно открывает отчёт или обновляет страницу;
* *Тогда:* значение checkbox восстановлено в сохранённом состоянии;
* *И:* tooltip работает в соответствии с сохранённым режимом.

AC.6 — *Старые отчёты работают без миграционных ошибок:*

* *Дано:* открыт отчёт со сводной таблицей, созданный до появления настройки;
* *Когда:* пользователь открывает настройки виджета и наводит указатель на ячейки таблицы;
* *Тогда:* checkbox отображается выключенным;
* *И:* tooltip показывает только значение текущей ячейки;
* *И:* в консоли браузера и ответах backend нет ошибок из-за отсутствующего параметра.

AC.7 — *Пограничные значения обрабатываются без технического текста:*

* *Дано:* в сводной таблице есть пустые значения, длинные значения, свёрнутые/развёрнутые уровни и строки/колонки итогов;
* *Когда:* пользователь наводит указатель на такие ячейки;
* *Тогда:* tooltip не показывает {{root}}, {{undefined}}, {{null}} как технический текст, если такие значения не являются фактическим отображаемым значением данных;
* *И:* поведение таблицы при раскрытии уровней не меняется.

AC.8 — *Нет побочных изменений в работе сводной таблицы:*

* *Дано:* пользователь работает со сводной таблицей после включения или выключения новой настройки;
* *Когда:* он применяет фильтры, раскрывает уровни, меняет сортировку или сохраняет отчёт;
* *Тогда:* расчёты, данные, фильтрация, сортировка и структура сводной таблицы остаются без изменений;
* *И:* изменение затрагивает только содержимое tooltip.
