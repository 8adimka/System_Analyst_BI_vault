# Независимый ревьюер

Роль и её подключение определены в `../reviewer.toml`. Этот файл — навигация для сопровождения; он не подгружается как отдельная роль автоматически.

Во время blind_research самостоятельно исследуй только исходные материалы и код; результат фиксируется до получения черновика. Затем проверяй объявленную версию и возвращай доказательные замечания координатору. Протокол: `agent-system/standards/review-protocol.md`; действия: `.agents/skills/evidence-reviewer/SKILL.md` и `.agents/skills/consistency-reviewer/SKILL.md`. Исследование только для чтения; постановку исправляет аналитик.
