# Modus BI: разработка по умолчанию

Корень workspace — `/home/v/desk/work`. Обычные запросы выполняй как full-stack разработчик по [AGENT.md](AGENT.md): исследуй портал, пиши код и готовь работающие `.html`-макеты. Эта проектная настройка заменяет прежний постоянный режим постановщика и временный режим строителя системы; сопровождение самой системы выполняй по отдельному запросу.

- Навигация разработчика: [developer/README.md](developer/README.md). Действия: `.agents/skills/portal-fullstack/`, `portal-html-mockup/`, `codebase-wiki/`. Читай нужные инструкции по задаче.
- Знания о коде и оформлении: `.private/knowledge/index.md`; правила накопления — `.private/knowledge/SCHEMA.md`. Wiki направляет к исходнику; существенные выводы проверяй по файлу, символу и версии. Подтверждённое отделяй от предположений и предложений.
- `.private/repositories/{bi_react,bi-forms,modusbi,plugins}/` — эталонные внешние репозитории только для чтения. Не изменяй их, не выполняй там install/build/test, pull/checkout/reset/clean. Разработку веди в отдельной приватной копии `.private/development/<задача>/`; макеты — в `.private/mockups/<задача>/`. Перед записью проверяй канонический путь и симлинки.
- `.private/` целиком приватна. Код, Wiki, макеты, патчи и выводы по корпоративным материалам не переносить в публичную часть автоматически. Секреты, `Доступы.txt`, авторизацию, глобальные настройки Codex/VS Code и старые сессии не читай и не меняй. Внешние сервисы для корпоративных данных требуют подтверждённого разрешения компании.
- Сохраняй чужие изменения. Git add/commit/push автоматически не выполняй; перед возможной публикацией проверь `git status`, `git check-ignore`, `git ls-files` и содержимое результата.

По явному запросу «используй агентскую систему для написания постановок» / «запусти постановщика» переключай текущую задачу на Python-координатор по разделу «Новая постановка» в [README.md](README.md). Одного интерактивного ответа недостаточно для независимого ревью. Не запускай эту систему для обычной разработки, исследования кода или HTML-макета. Следующий самостоятельный запрос снова обрабатывай как разработчик, если пользователь не задал иной режим.

Назначенные координатором `analyst` и `reviewer` всегда следуют своим структурированным схемам, стандартам и `agent-system/runtime/AGENTS.md`; режим разработчика к ним не применяется. Их независимые Thread, `Sandbox.read_only`, слепое исследование до черновика, запись через координатор и лимит 5+1 сохраняются. Роли не перезапускают координатор и не создают разработчиков-подагентов.
