Редактор для SQL и JS кода. Внедрение. Шаг 1 - базовый компонент, storybook

*Контекст и цель задачи:*
Ранее нами был проведен ресерч и сравнительный анализ библиотек для встраиваемого редактора кода. По итогам обсуждения оценки принято решение сделать корпоративным стандартом библиотеку *CodeMirror*, так как она обеспечивает максимальную гибкость интеграции и нативную поддержку _SQL_ наравне с другими языками.

Цель текущей задачи — реализовать независимый переиспользуемый виджет _редактора кода_ на базе *CodeMirror* и первично внедрить его в функционал _«Вычисляемые поля»_. 
Внедрение в _«Вычисляемые поля»_ должно делаться с нуля, без копирования уже сформированной логики (используемой в текущем редакторе), с целью заложить качественную архитектуру.

*Требования к виджету CodeMirror:*

* *Поддерживаемые языки:* 
** SQL (приоритет).
** JS/TS, CSS, HTML, XML.

* *Базовый UX редактора:*
** Нумерация строк, подсветка синтаксиса, подсветка и автозакрытие скобок/кавычек.
** Поддержка истории изменений (Undo/Redo).
** Подсветка/подчеркивание ошибок синтаксиса.
** Поддержка мультиселекта (мультикурсора) для одновременного редактирования нескольких строк.

* *Автодополнение:*
** Редактор должен предлагать автодополнение по списку при вводе.
** В список подсказок должны входить встроенные функции (SUM, AVG и т.д.) и список полей/метаданных из контекста.

* *Работа с позицией курсора (Drag-and-Drop):*
** Поддержка точного позиционирования. 
** При перетаскивании элемента (поля/таблицы) из левой боковой панели метаданных, он должен вставляться ровно в то место, где в данный момент установлена каретка (курсор) редактора.

* *Юридические и технические требования:*
** Библиотека CodeMirror распространяется под свободной лицензией MIT. 
** Необходимо явно указать использование данного OpenSource-инструмента в проектной документации.
** Обертка для React пишется самостоятельно (или используются проверенные неофициальные обертки с адаптацией).

*Критерии приёмки (AC):*
* *AC1:* Виджет редактора успешно добавлен в Storybook, корректно рендерится и поддерживает переключение синтаксиса (SQL, JS/TS, HTML, CSS, XML).
* *AC2:* В функционале «Вычисляемые поля» старый редактор полностью заменен на новый виджет CodeMirror.
* *AC3:* UI окна редактора в «Вычисляемых полях» увеличен, добавлен корректный внутренний скролл, верстка не ломается при изменении размера экрана.
* *AC4:* При вводе текста появляется выпадающий список автодополнения, содержащий агрегатные функции (SUM, AVG) и доступные поля/метаданные из источника.
* *AC5:* Перетаскивание (Drag-and-drop) поля из левой панели метаданных вставляет наименование поля точно в текущую позицию курсора (каретки).
* *AC6:* Работает подчеркивание синтаксических ошибок для базовых конструкций.
* *AC7:* Работает мультикурсор (multi-select) и горячие клавиши истории (Ctrl+Z / Cmd+Z для Undo и отката изменений).
* *AC8:* В проектную wiki/документацию добавлена информация об использовании библиотеки CodeMirror (с указанием лицензии MIT).
