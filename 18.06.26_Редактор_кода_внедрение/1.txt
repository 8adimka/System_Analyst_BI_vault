Подготовь ответы и уточнения по следующим вопросам:
1) -> Какие объекты должен возвращать список таблиц?

Для новых команд `datasources / metadata.tables.list` и `datasources / metadata.tables.get` нужно уточнить состав доступных объектов.

Предварительно реализуем следующий объём:

- обычные пользовательские таблицы текущей настроенной базы данных;+
- таблицы из всех доступных пользовательских схем внутри этой базы;+
- таблицы независимо от наличия и состава первичного ключа.+

Нужно уточнить:
1. Включать ли views?+
2. Включать ли foreign/external tables?-
3. Включать ли временные таблицы?-

2) -> Как нормализовать типы SQLite?

SQLite использует динамическую типизацию.

Предварительно используем следующее сопоставление:

| Объявленный тип содержит | Тип API |
|---|---|
| `INT` | `integer` |
| `CHAR`, `CLOB`, `TEXT` | `string` |
| `REAL`, `FLOA`, `DOUB`, `NUMERIC`, `DECIMAL` | `number` |
| `DATE` | `date` |
| `DATETIME`, `TIMESTAMP` | `datetime` |
| `BLOB`, пустой или неизвестный тип | `undefined` |

Нужно подтвердить это сопоставление либо предоставить другие правила, в частности для:

- `BOOLEAN`;
- `NUMERIC` без уточнения назначения;
- произвольных пользовательских названий типов;
- колонок без объявленного типа;
- типов даты и времени, которые SQLite физически хранит как число или строку.
