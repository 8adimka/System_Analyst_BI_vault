h3. Контекст и цель.
В меню настроек пилюли, размещённой на полке «Фильтры», доступные настройки могут отличаться и конфликтовать с конфигурацией общего фильтра, заданной в правой боковой панели фильтров, визуализациях «Контейнер с фильтрами» и «Иерархический фильтр». Настройки пилюли, размещённой на полке «Фильтры», в первую очередь расчитаны для настройки локального фильтра визуализации, поэтому при режиме «Локальный» = «Выкл», набор доступных настроек должен быть сокращён. 

*Требуется:* скрывать настройки локального фильтра при режиме «Локальный» = «Выкл» и исключить их влияние, сохраняя возможность настройки пилюли в локальном режиме. Применить ту же концепцию к настройкам выбранной колонки в разделе «Поиск» визуализации «Таблица»: в нелокальном режиме форма поиска определяется настройками общего фильтра, кроме типа «По сравнению», для которого используется существующая экранная форма «По значению».

----
h3. 1. Функциональные требования.
Во всех визуализациях, где для пилюли на полке «Фильтры» предусмотрен переключатель «*Локальный*», при его значении «*Выкл*» оставлять только следующие настройки в указанном порядке:
* «Уровень отбора»;
* «Локальный».

Все остальные настройки фильтра скрывать, включая «Тип фильтра», «Режим», условия, логику И/ИЛИ, динамические значения, «Автофильтр», «Зависит от», «Сброс», «Значение при сбросе», «Сортировка по другому полю» с подчинённым параметром «Направление сортировки по другому полю» и «Невидимый».

При «*Локальный*» = «*Вкл*» скрывать «Уровень отбора» и отображать применимые настройки в следующем порядке:
* «Тип фильтра»;
** «Режим» — при «Тип фильтра» = «По диапазону» и типе данных «Дата»;
* «Условие», «Логика», «Динамическое значение» и остальные параметры условий — по действующим правилам для соответствующих типа данных, типа фильтра и режима;
* «Автофильтр»;
* «Зависит от»;
* «Сброс»;
** «Значение при сбросе»;
* «Сортировка по другому полю» с применимым подчинённым параметром направления;
* «Невидимый»;
* «Локальный».

Состав подчинённых параметров и условия их доступности сохраняются, кроме явно изменённых правил локальности. Для локального фильтра настройка «Зависит от» по умолчанию учитывает все фильтры, воздействующие на визуализацию на момент применения фильтра; пользователь может изменить зависимость вручную. Сохранённая ручная настройка не заменяется значением по умолчанию при переключении режима.

В разделе «Поиск» визуализации «Таблица» после выбора колонки действуют те же состав и порядок настроек фильтра. Первой настройкой под списком «Выберите колонку» в обоих режимах остаётся «Поиск для колонки»; она управляет включением поиска колонки и не скрывается по правилу сокращения настроек фильтра. Переключатель «Локальный» находится внизу обоих списков.

При «Локальный» = «Выкл» скрытые настройки пилюли или локального поиска не применяются к общему фильтру и не перезаписывают его настройки, заданные через правую боковую панель фильтров, визуализацию «Контейнер с фильтрами» и «Иерархический фильтр». Скрытые настройки сохраняются для возврата в локальный режим. Правило действует также для ранее сохранённых визуализаций, при переключении режима, сохранении и повторном открытии отчёта. При возврате к «Локальный» = «Вкл» сохранённые настройки вновь доступны и действуют с учётом типа фильтра и существующих условий их применимости.

Связанный общий фильтр определяется по {{alias}} поля. Совпадение отображаемых названий не устанавливает связь. Существующее взаимодействие выбранных значений общего фильтра между интерфейсами сохраняется. Локальные и общие настройки и выбранные значения разделены: переход в общий режим показывает действующий общий выбор, возврат в локальный — прежний локальный выбор; автоматического переноса выбора между режимами нет.

При «Локальный» = «Выкл» нажатие на активный элемент колонки в строке поиска таблицы открывает форму по типу данных и действующим настройкам связанного общего фильтра, заданным в правой боковой панели фильтров, «Контейнере с фильтрами» или «Иерархическом фильтре», с исключением для общего типа «По сравнению», описанным ниже. Сохранённый тип нелокальной пилюли и скрытые локальные настройки не определяют форму поиска. Изменение настроек общего фильтра учитывается при следующем открытии формы.

Для общих типов «По значению» и «По диапазону» сохраняются все предусмотренные постановкой поиска и текущим макетом сочетания экранных форм: список значений; строковые и числовые условия; формы даты для режимов «Произвольный диапазон», «Последние N дней», «До текущей даты». Новые формы не добавляются. Поиск изменяет состояние связанного общего фильтра, а не создаёт дополнительное локальное условие поверх него. Существующее взаимодействие поиска с пагинацией сохраняется.

Эти ограничения меню не распространяются на собственные настройки общих фильтров в правой боковой панели, «Контейнере с фильтрами» и «Иерархическом фильтре».

Допустимость типа «По сравнению» определяется связанной постановкой [MB-6321|https://jira.modusbi.ru/browse/MB-6321]. Сохраняются исключения для «Таблицы сравнения», «Контейнера с фильтрами» и «Иерархического фильтра», действующие ограничения правой боковой панели и работа ранее сохранённых конфигураций без обязательной смены типа, автоматического сброса или преобразования.

Ручная смена типа выполняется только там, где выбор типа доступен: для локальной пилюли — при «Локальный» = «Вкл», для общего фильтра — через существующие общие интерфейсы с учётом их ограничений. Требование ручной смены не означает показ скрытого «Тип фильтра» при «Локальный» = «Выкл» и не требует добавлять выбор типа там, где его нет. После перехода на допустимый тип повторный выбор «По сравнению» в запрещённом контексте недоступен.

При «Локальный» = «Вкл», если для поиска колонки действует ранее сохранённый локальный тип «По сравнению», поиск этой колонки недоступен с пояснением; настройки, выбранные значения и прежняя работа локального фильтра сохраняются. После ручной смены локального типа на допустимый поиск становится доступен. Поиск не добавляет форму «По сравнению».

При «Локальный» = «Выкл» и действующем типе связанного общего фильтра «По сравнению» поиск колонки доступен и открывает существующую экранную форму «По значению» со списком значений. Это исключение определяет только тип экранной формы поиска и не добавляет выбор типа в настройки. Простое открытие формы не заменяет общий отбор и не меняет сохранённый тип общего фильтра. После применения выбранного в списке набора значений он заменяет общий выбор и прежний общий отбор; связанные интерфейсы и визуализации используют новый общий выбор по действующим правилам. Дополнительное локальное условие не создаётся, сохранённый локальный выбор не подмешивается. Тип общего фильтра остаётся «По сравнению».

Для общего фильтра сохраняется допустимое действующее временное отображение как «По значению» с возможностью перевыбора списка; после сброса фильтра, перезагрузки страницы или потери контекста фильтрации общий фильтр снова отображается как «По сравнению». Этот механизм не требует отдельной доработки; значения при сбросе определяются действующей логикой. При действующем общем типе «По сравнению» поиск таблицы использует описанное выше исключение экранной формы.

h3. 2. Критерии приёмки:
AC.1 — *Состав меню:*
* *Дано:* пилюля с переключателем «Локальный» либо выбранная колонка в разделе «Поиск» таблицы; сохранены настройки списка или диапазона, включая поле сортировки;
* *Когда:* пользователь выключает локальный режим и открывает настройки;
* *Тогда:* из настроек фильтра отображаются только «Уровень отбора» и «Локальный» в указанном порядке; остальные настройки, включая тип, параметры диапазона, направление сортировки и «Невидимый», скрыты;
* *И:* в разделе «Поиск» первой под списком выбора колонки остаётся настройка «Поиск для колонки».

AC.2 — *Неактивность сохранённых настроек:*
* *Дано:* общий фильтр с тем же {{alias}} имеет варианты А, Б, В, выбор Б, без автофильтра, зависимости и сброса; у пилюли заданы автофильтр MAX, зависимость от «Региона», сброс в MIN и сортировка по другому полю по убыванию; локальная зависимость оставляет только А, локальная сортировка даёт В, Б, А, общий порядок — А, Б, В;
* *Когда:* пользователь выключает локальность, меняет «Регион» и открывает варианты фильтра внутри визуализации и в общем интерфейсе;
* *Тогда:* в обоих интерфейсах доступны А, Б, В в общем порядке, выбран Б; нет автоматического выбора MAX, ограничения до А, очистки или сброса в MIN; визуализация фильтруется по Б, конфигурация общего фильтра не перезаписана.

AC.3 — *Возврат после сохранения:*
* *Дано:* новая либо ранее сохранённая визуализация с локальными настройками пилюли;
* *Когда:* пользователь выключает локальность, сохраняет отчёт, повторно открывает его и включает локальность;
* *Тогда:* до включения действует AC.2; после включения восстановлены прежние настройки пилюли, доступные и действующие по условиям их применимости;
* *И:* тот же сценарий выполнен для настроек колонки в разделе «Поиск» таблицы; сохранённая ручная зависимость восстановлена.

AC.4 — *Связь интерфейсов:*
* *Дано:* общие фильтры представлены в правой боковой панели, «Контейнере с фильтрами» и «Иерархическом фильтре»;
* *Когда:* пользователь изменяет общий выбор через доступные интерфейсы;
* *Тогда:* взаимодействие выбранных значений сохраняется для одного {{alias}}; одинаковые названия при разных {{alias}} фильтры не объединяют.

AC.5 — *Локальные настройки:*
* *Дано:* пилюли и поиск колонок для типов данных «Строка», «Число», «Дата», типов фильтра «По значению», «По диапазону» и применимых режимов даты;
* *Когда:* пользователь включает «Локальный» и открывает настройки каждой конфигурации;
* *Тогда:* «Уровень отбора» скрыт, применимые настройки расположены в порядке раздела 1, «Локальный» находится внизу; в разделе «Поиск» настройка «Поиск для колонки» остаётся первой;
* *И:* для локального фильтра с зависимостью по умолчанию список вариантов учитывает все фильтры, воздействующие на визуализацию на момент применения; после ручного изменения зависимости варианты определяются выбранной зависимостью.

AC.6 — *Форма поиска по общему фильтру:*
* *Дано:* поиск колонки работает при «Локальный» = «Выкл»; сохранённый тип пилюли или локального поиска отличается от типа связанного общего фильтра;
* *Когда:* пользователь открывает поиск, затем меняет настройки общего фильтра через доступный общий интерфейс и повторно открывает поиск;
* *Тогда:* форма соответствует действующим настройкам общего фильтра с исключением для типа «По сравнению» по AC.9, а не сохранённому типу пилюли или локального поиска; изменение условия через поиск отражается в общем фильтре без дополнительного локального условия;
* *И:* проверены общие фильтры из правой боковой панели, «Контейнера с фильтрами» и «Иерархического фильтра», а также все сочетания форм из раздела 1: список для строки, числа и даты, строковые и числовые условия диапазона и три режима даты; состав форм соответствует текущему макету поиска.

AC.7 — *Раздельный выбор:*
* *Дано:* в локальном поиске колонки выбрана «Казань», в связанном общем фильтре — «Москва»;
* *Когда:* пользователь выключает «Локальный», добавляет «Самару» через поиск и возвращается в локальный режим;
* *Тогда:* в общем режиме первоначально показана «Москва», после изменения — «Москва» и «Самара»; при возврате восстановлены локальные настройки и «Казань», общий выбор остаётся «Москва» и «Самара».

AC.8 — *Совместимость типа «По сравнению»:*
* *Дано:* ранее сохранённая пилюля «По сравнению» у визуализации вне исключений; отдельно — локальный поиск колонки таблицы с ранее сохранённым локальным типом «По сравнению»;
* *Когда:* пользователь открывает отчёт, проверяет оба режима локальности, включает поиск и сохраняет отчёт без смены типа;
* *Тогда:* настройки, значения и прежняя работа фильтров сохраняются; при «Локальный» = «Выкл» выбор типа в пилюле и разделе «Поиск» скрыт; при «Локальный» = «Вкл» поиск колонки с действующим локальным типом «По сравнению» недоступен с пояснением;
* *И:* ручной переход локального фильтра на допустимый тип делает локальный поиск доступным; в запрещённом контексте повторный выбор «По сравнению» недоступен сразу и после сохранения и повторного открытия;
* *И:* для «Таблицы сравнения», «Контейнера с фильтрами», «Иерархического фильтра» и правой боковой панели сохраняются возможности и ограничения выбора и использования «По сравнению» по MB-6321; применение общего состояния к связанным визуализациям не блокируется сокращением меню пилюли.

AC.9 — *Поиск при общем типе «По сравнению»:*
* *Дано:* поиск колонки таблицы включён, «Локальный» = «Выкл»; связанный по {{alias}} общий фильтр имеет тип «По сравнению» и применённый общий отбор; у колонки сохранены локальный тип «По сравнению» и локальный выбор «Казань»; в списке общего фильтра доступны «Москва» и «Самара»;
* *Когда:* пользователь открывает поиск колонки, затем выбирает в списке только «Москву» и «Самару» и применяет выбор;
* *Тогда:* поиск доступен, открывается существующая экранная форма «По значению»; до применения общий отбор и сохранённый тип общего фильтра не меняются;
* *И:* после применения общий выбор содержит только «Москву» и «Самару», прежний общий отбор заменён; связанные интерфейсы и визуализации используют новый общий выбор по действующим правилам, без дополнительного локального условия и подмешивания «Казани»; тип общего фильтра остаётся «По сравнению», выбор типа в нелокальных настройках не появляется;
* *И:* допустимо действующее временное отображение общего фильтра как «По значению» с перевыбором списка; при отдельной проверке сброса фильтра, перезагрузки страницы и потери контекста фильтрации общий фильтр снова отображается как «По сравнению», значения определяются действующей логикой; при действующем общем типе «По сравнению» поиск таблицы по-прежнему открывает форму «По значению»;
* *И:* при возврате в локальный режим восстановлены локальный тип «По сравнению» и «Казань», локальный поиск недоступен с пояснением; сценарий общего поиска проверен для общих фильтров из правой боковой панели, «Контейнера с фильтрами» и «Иерархического фильтра».
