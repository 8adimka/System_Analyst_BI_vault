В данном окне, при вводе значения в поле поиска, поиск на совпадения введённого значения производится по-умолчанию в любом месте строки, но можно включить параметр "Поиск с начала строки", чтобы поиск совпадений начинался именно с начала строки.

Ниже зоны настроек поиска располагается секция с результатом полученных строк-значений, которые были найдены по результатам поиска.
Также есть настройка "Выделить все найденные значения" - при включении данного парамерта все строки-значения из секции отображения значений будут выделены галочкой и фильтр может быть применён при нажатии кнопки "Применить". Важно понимать, что галочки остаются только на значениях сейчас отображаемых в секции отображения значений. Набор отображаемых значений может менять по ходу ввода, а галочки должны оставаться только на значениях, которые попадут в зону отображения значений после ввода поискового запроса, а не те значения, которые могли там отображаться по ходу ввода поисковой фразы, а в фильтр попадает только набор значений с галочкой, который был выделен в момент нажатия кнопки "Применить".
