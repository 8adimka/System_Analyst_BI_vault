h3. Контекст и проблематика.

На аналитическом портале в визуализации "Таблица" отсутствует механизм скрытия колонок по заданным условиям. Сейчас скрытие колонки выполняется только статично — тумблером "Скрыть результат" в настройках пилюли на полке "Значения". Колонка либо всегда скрыта, либо всегда показана, независимо от фактических данных отчёта.

В визуализации "Таблица" уже существует раздел настроек "Условное форматирование", однако его текущий интерфейс не позволяет управлять видимостью колонок — доступно только оформление (цвет текста, цвет фона, цвет спарклайна).

Требуется реализовать функционал динамическго скрытия колонок при выполнении заданных условий, например, чтобы не показывать колонки с нерелевантными или пустыми срезами данных без ручной перенастройки отчёта и привести интерфейс раздела "Условное форматирование" визуализации "Таблица" к целевому виду с добавлением тумблера "Скрыть колонку".

----

h3. Цель задачи.

*Требуется:*

# Добавить в визуализацию "Таблица" возможность скрывать колонку целиком, если хотя бы одна строка в этой колонке удовлетворяет заданному условию.
# Реализовать это в существующем разделе "Условное форматирование" правой боковой панели настроек — добавлением нового тумблера "Скрыть колонку" в блок настроек оформления, без создания отдельного раздела настроек.
# Унифицировать интерфейс раздела "Условное форматирование" визуализации "Таблица" с аналогичным доработанным разделом визуализации "Таблица сводная".
# Скрытие колонки должно выполняться через тот же механизм, что и статичное скрытие пилюли (тумблер "Скрыть результат" в настройках пилюли на полке "Значения").
# Добавить тумблер "Скрыть результат" для пилюль на полках "Категории" и "Серии".

_Пользовательская история:_
Как аналитик, настраивающий визуализацию "Таблица", я хочу задавать условие, при выполнении которого колонка автоматически скрывается, чтобы не показывать пользователям колонки с нерелевантными данными, без необходимости вручную перестраивать отчёт.

----

h3. 1. Описание текущего поведения.

В визуализации "Таблица" раздел "Условное форматирование" правой боковой панели настроек позволяет создать правило условного форматирования со следующими настройками:
# Название правила;
# Проверяемое поле (пилюля с полки "Значения");
# До двух условий сравнения с логикой И/ИЛИ;
# Цвет текста;
# Цвет фона;
# Цвет спарклайна;
# Вся строка.

Текущий интерфейс раздела не имеет выраженной структуры секций "Что проверяем", "Что оформляем", "Как оформляем" (по аналогии с этим разделом в визуализации "Таблица сводная"), а также не содержит тумблера "Скрыть колонку".

Скрытие колонки в текущей реализации возможно только статично — через тумблер "Скрыть результат" в настройках пилюли на полке "Значения" или через настройку "Показывать" в разделе настроек "Колонки". Данные механизмы не зависят от значений данных и не связаны с разделом "Условное форматирование".

Тумблер "Скрыть результат" отсутствует у пилюль на полках "Категории" и "Серии".

----

h3. 2. Описание целевого поведения.

---
h4. 2.1. Целевой вид раздела настроек "Условное форматирование".

После нажатия кнопки "Создать" в разделе "Условное форматирование" правой боковой панели настроек визуализации "Таблица" создаётся новое правило условного форматирования и отображается интерфейс его настройки со следующей структурой:

# *Выпадающий список правил и название правила:*
#* В самом верху раздела располагается выпадающий список со всеми созданными правилами условного форматирования; выбор правила в списке открывает его настройки для редактирования.
#* *Название правила* — поле для задания названия правила; заданное название отображается как пункт в выпадающем списке правил.
# *Секция "Что проверяем":*
#* Выпадающий список пилюль с полок "Значения" (независимо от выбранного режима полки {{Первое/Все}}), "Категории" и "Серии" — определяет, по каким значениям сравнивается условие.
#* *Условие 1* — оператор сравнения из выпадающего списка и значение для сравнения.
#* *Логика* — переключатель {{И/ИЛИ}} между условием 1 и условием 2.
#* *Условие 2* — оператор сравнения и значение для сравнения (по аналогии с условием 1); задаётся, когда для одного поля требуется проверить сразу два условия. Если нужно проверить несколько независимых диапазонов для одного поля — создаются отдельные правила.
# *Секция "Что оформляем" — область применения:*
#* Выпадающий список пилюль с полок "Значения" (независимо от режима {{Первое/Все}}), "Категории", "Серии" — определяет, к каким колонкам применяется правило (проверка условия и оформление/скрытие).
#** *Список поддерживает множественный выбор пилюль*: правило должно иметь возможность одновременно применяться к нескольким колонкам с единым условием проверки и единым набором настроек оформления (включая "Скрыть колонку").
# *Секция "Как оформляем" — параметры оформления и скрытия:*
#* *Цвет текста* — colorpicker, цвет текста при срабатывании правила.
#* *Цвет фона* — colorpicker, цвет фона при срабатывании правила.
#* *Цвет спарклайна* — colorpicker, добавляется при условии, что параметр в текущей реализации влияет на внешний вид визуализации. Если параметр не влияет на отображение — исключить его из интерфейса. _При наличии параметра — добавить к нему пояснительную подсказку (tooltip), описывающую, на что он влияет_.
#* *Начертание* — три независимых чекбокса: B (полужирное), I (курсив), U (подчёркнутое).
#* *Индикатор* — выпадающий список внешнего вида индикатора, отображаемого рядом со значением, подходящим под условие.
#* *Цвет индикатора* — colorpicker, цвет элемента, выбранного в поле "Индикатор".
#* *Вся строка* — тумблер; при включении *оформление* (цвет, начертание, индикатор) распространяется на всю строку, а не только на значение выбранной колонки.
#* *Скрыть колонку* (новый элемент) — тумблер; при включении и наличии хотя бы одной строки в колонке, удовлетворяющей заданному условию, колонка скрывается целиком через тот же механизм, что и тумблер "Скрыть результат" в настройках пилюли на полке "Значения".
#** К тумблеру добавить подсказку (tooltip): "При выполнении заданного условия выбранная колонка будет скрыта".
#** Тумблер по умолчанию *выключен*.

*Отличия от визуализации "Таблица сводная":*
* В секциях "Что проверяем" и "Что оформляем" выпадающие списки пилюль формируются из полок "Значения" (независимо от режима {{Первое/Все}}), "Категории" и "Серии".
* Чекбоксы "Значение" и "Итоги" отсутствуют — проверка условия и применение оформления/скрытия выполняется построчно для всех строк колонки.

---
h4. 2.2. Дополнительные сценарии и правила поведения.

# Если тумблер "Скрыть колонку" включён и хотя бы одна проверяемая строка колонки удовлетворяет условию правила — колонка скрывается целиком; частичное скрытие отдельных ячеек не производится.
# Если ни одна строка колонки не удовлетворяет условию — колонка отображается в обычном режиме, правила оформления к ней не применяются (в том числе правила скрытия колонки).
# При множественном выборе пилюль в "Что оформляем" правило проверяется и применяется независимо для каждой выбранной колонки: колонка может скрыться, если условие выполняется хотя бы в одной её строке, независимо от выполнения условия в других выбранных колонках.
# Если для одной и той же колонки одновременно применимы несколько правил с включённым тумблером "Скрыть колонку", колонка скрывается при срабатывании хотя бы одного из этих правил (логика ИЛИ между правилами).
# Одновременное включение тумблеров "Вся строка" и "Скрыть колонку" в рамках одного правила недопустимо. Включение второго тумблера при уже активном первом выключает первый тумблер и активирует второй.
# Колонка, скрытая по условию, продолжает участвовать в вычислениях (агрегатах, сортировке) — скрытие является визуальным и не влияет на данные.
# В случае одновременного включения настроеки "Скрыть результат" (в настройках пилюли) и "Скрыть колонку" (из настроек условного форматирования) - приоритет по отображению или скрытию отдаётся настройке "Скрыть колонку" из настроек условного форматирования. Т.е. при условии, что включены обе настройки, но в конкретной колонке не выполняется заданное условие ни для одной строки - данная колонка отображается.

h3. 3. Требования к реализации.

---
h4. 3.1. Фронтенд-часть.

* Раздел "Условное форматирование" визуализации "Таблица" привести к структуре, описанной в п. 2.1: секции "Что проверяем", "Что оформляем", "Как оформляем".
* Выпадающий список пилюль в секции "Что оформляем" перевести в режим множественного выбора.
* В секции "Как оформляем" добавить тумблер "Скрыть колонку" с подсказкой "При выполнении заданного условия выбранная колонка будет скрыта", по умолчанию выключен.
* Реализовать взаимное исключение тумблеров "Вся строка" и "Скрыть колонку": включение одного автоматически выключает другой.
* При включении тумблера "Скрыть колонку" интерфейс должен визуально отображать (в предпросмотре таблицы) скрытие колонки при срабатывании условия, без пересохранения визуализации или отчёта.
* Для пилюль на полках "Категории" и "Серии" добавить тумблер "Скрыть результат" по аналогии с существующим тумблером на полке "Значения".
* Состояние тумблера "Скрыть колонку" сохраняется в конфигурации правила условного форматирования и корректно восстанавливается при повторном открытии настроек визуализации.
* Для параметра "Цвет спарклайна": 
** если он не влияет на визуальное отображение — исключить из интерфейса; 
** если влияет — сохранить его в интерфейсе, но добавить tooltip с пояснением.

---
h4. 3.2. Бэкенд-часть.

* В структуре объекта правила условного форматирования (элемент массива {{rules}} в метаданных визуализации) добавить новое булево поле, отвечающее за состояние тумблера "Скрыть колонку" (далее — {{hideColumn}}), по умолчанию {{false}}.
* Логика вычисления условия ("Что проверяем": {{fieldId}}, {{cons}} — условия 1 и 2 с операторами и логикой И/ИЛИ) не изменяется — переиспользуется существующий механизм.
* При построении итогового набора данных для отображения таблицы: для каждой колонки, попадающей в область действия правила (выбранные в "Что оформляем" пилюли), проверяется, срабатывает ли условие правила хотя бы для одной строки этой колонки; если правило с {{hideColumn: true}} срабатывает — колонка помечается как скрытая по тому же признаку/механизму, что и статичное скрытие через {{hideResult}} у пилюли.
* Если для колонки одновременно применимо несколько правил с {{hideColumn: true}}, колонка скрывается при срабатывании хотя бы одного из них (логика ИЛИ между правилами).
* Обеспечить корректную обработку пустых значений ({{null}}) при вычислении условия скрытия — отсутствие данных интерпретируется как невыполнение условия для соответствующей строки и не приводит к ошибке.
* Для пилюль полок "Категории" и "Серии" реализовать поле {{hideResult}} в структуре описания пилюли, аналогично существующему полю пилюль полки "Значения", и обеспечить его работу через тот же механизм скрытия.

---
h4. 3.3. Технические требования и ограничения.

* Изменение структуры метаданных правила ({{hideColumn}}) должно быть обратно совместимо: отсутствие поля в ранее сохранённых конфигурациях интерпретируется как {{false}} (тумблер выключен, поведение не изменяется относительно текущей версии).
* Вычисление условия скрытия колонки не должно требовать дополнительных SQL-запросов сверх уже выполняемых для получения данных, отображаемых в отчёте — используется тот же набор данных, что и для применения условного форматирования (цвет/индикатор).
* Порядок и состав колонок, не затронутых правилами со включённым {{hideColumn}}, не должен изменяться.
* Производительность вычисления условия скрытия должна оставаться сопоставимой с текущей производительностью применения условного форматирования — проверка выполняется в рамках уже существующего цикла обработки данных таблицы.
* Существующие сохранённые правила условного форматирования визуализации "Таблица" должны продолжать работать без изменений после доработки.

h3. 5. Критерии приёмки (AC):

AC.1 — *Отображение тумблера "Скрыть колонку":*
* *Дано:* открыт раздел "Условное форматирование" правой боковой панели настроек визуализации "Таблица", создано правило условного форматирования;
* *Когда:* пользователь переходит в секцию "Как оформляем";
* *Тогда:* отображается тумблер "Скрыть колонку" с подсказкой "При выполнении заданного условия выбранная колонка будет скрыта", по умолчанию выключен.

AC.2 — *Скрытие колонки при срабатывании условия:*
* *Дано:* создано правило условного форматирования, в "Что проверяем" задано условие, в "Что оформляем" выбрана колонка (пилюля) и включён тумблер "Скрыть колонку";
* *Когда:* хотя бы одна строка выбранной колонки удовлетворяет заданному условию;
* *Тогда:* колонка скрывается целиком, аналогично поведению при включении тумблера "Скрыть результат" у пилюли.

AC.3 — *Колонка не скрывается при невыполнении условия:*
* *Дано:* создано правило с включённым тумблером "Скрыть колонку";
* *Когда:* ни одна строка выбранной колонки не удовлетворяет заданному условию;
* *Тогда:* колонка отображается в обычном режиме без применения оформления данного правила.

AC.4 — *Несколько правил для одной колонки:*
* *Дано:* для одной и той же колонки применимы два правила условного форматирования с включённым тумблером "Скрыть колонку", у каждого своё условие;
* *Когда:* срабатывает хотя бы одно из двух правил;
* *Тогда:* колонка скрывается.

AC.5 — *Взаимное исключение тумблеров:*
* *Дано:* в рамках одного правила включён тумблер "Вся строка";
* *Когда:* пользователь включает тумблер "Скрыть колонку";
* *Тогда:* тумблер "Вся строка" автоматически выключается, тумблер "Скрыть колонку" активируется.

AC.6 — *Множественный выбор пилюль:*
* *Дано:* создано правило условного форматирования;
* *Когда:* пользователь в секции "Что оформляем" выбирает несколько пилюль и включает тумблер "Скрыть колонку";
* *Тогда:* правило применяется независимо к каждой выбранной колонке, скрытие происходит для каждой колонки при выполнении условия хотя бы в одной её строке.

AC.7 — *Обратная совместимость:*
* *Дано:* ранее сохранённая конфигурация правила условного форматирования не содержит поля {{hideColumn}};
* *Когда:* визуализация открывается после доработки;
* *Тогда:* правило работает как прежде (оформление), колонка не скрывается — новый тумблер по умолчанию считается выключенным.

AC.8 — *Тумблер "Скрыть результат" для полок "Категории" и "Серии":*
* *Дано:* пользователь открывает настройки пилюли на полке "Категории" или "Серии";
* *Когда:* доступен тумблер "Скрыть результат";
* *Тогда:* при его включении колонка скрывается статично, аналогично поведению пилюли на полке "Значения".
