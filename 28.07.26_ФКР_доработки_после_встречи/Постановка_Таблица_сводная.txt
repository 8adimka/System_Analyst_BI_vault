h3. Контекст и проблематика.

На аналитическом портале в визуализации "Таблица сводная" отсутствует механизм скрытия колонок по заданным условиям. Сейчас скрытие колонки/пилюли выполняется только статично — тумблером "Скрыть результат" в настройках пилюли на полке "Значения", то есть колонка либо всегда скрыта, либо всегда показана, независимо от фактических данных в отчёте.

Аналитикам и пользователям портала требуется скрывать колонки динамически — не показывать колонку при не выполнении заданного условия (например, по заданному пороговому значению (сумме, количеству и т.п.)), либо не показывать "пустые"/нерелевантные срезы данных без ручной перенастройки отчёта под каждый набор данных.

Раздел настроек "Условное форматирование" уже содержит необходимый набор настроек для описания условия проверки (по каким полям/значениям сравнивать, какие операторы и логику применять). Расширение этого раздела новым тумблером "Скрыть колонку" позволяет переиспользовать существующий интерфейс и логику вычисления условий, не вводя для пользователя новый, отдельный раздел настроек.

----

h3. Цель задачи.

*Требуется:*

# Добавить в визуализацию "Таблица сводная" возможность скрывать колонку целиком, если хотя бы одна строка в этой колонке удовлетворяет заданному условию.
# Реализовать это в существующем разделе "Условное форматирование" правой боковой панели настроек — добавлением нового тумблера "Скрыть колонку" в блок настроек оформления, без создания отдельного раздела настроек.
# Скрытие колонки должно выполняться через тот же механизм, что и статичное скрытие пилюли (тумблер "Скрыть результат" в настройках пилюли на полке "Значения"), т.е. организовать условное динамическое управление данным флагом/тумблером, согласованное с уже существующим поведением рендеринга таблицы.
# При необходимости (если это потребуется по логике реализации) добавить аналогичный тумблер "Скрыть результат" для пилюль на полках "Строки" и "Столбцы".

_Пользовательская история:_
Как аналитик, настраивающий визуализацию "Таблица сводная", я хочу задавать условие, при выполнении которого колонка автоматически скрывается, чтобы не показывать пользователям колонки с нерелевантными или незначимыми данными без необходимости вручную перестраивать отчёт.

----

h3. 1. Описание текущего поведения.

В разделе "Условное форматирование" правой боковой панели настроек визуализации "Таблица сводная" пользователь может создать правило условного форматирования: выбрать поле для проверки условия ("Что проверяем"), задать до двух условий сравнения с логикой И/ИЛИ, выбрать строки/колонки, к которым применяется оформление ("Что оформляем"), задать цвет текста, цвет фона, начертание, индикатор и распространение форматирования.

Скрытие колонки в текущей реализации возможно только статично — через тумблер "Скрыть результат" в настройках пилюли на полке "Значения". Данный механизм не зависит от значений в данных и не связан с разделом "Условное форматирование": колонка скрывается независимо.

----

h3. 2. Описание целевого поведения.

h4. 2.1. Целевой вид раздела настроек "Условное форматирование".

После нажатия кнопки "Создать" в разделе "Условное форматирование" правой боковой панели настроек визуализации "Таблица сводная" создаётся новое правило условного форматирования и отображается интерфейс его настройки со следующей структурой:

# *Выпадающий список правил и название правила:*
#* В самом верху раздела располагается выпадающий список со всеми созданными правилами условного форматирования; выбор правила в списке открывает его настройки для редактирования.
#* *Название правила*
#** Поле для задания названия правила; заданное название отображается как пункт в выпадающем списке правил (см. п. 1).
# *Секция "Что проверяем":*
#* Выпадающий список пилюль с полки "Значения" (независимо от выбранного режима полки {{Первое/Все}}) — определяет, по каким значениям сравнивается условие.
#* *Условие 1* — оператор сравнения из выпадающего списка и значение для сравнения.
#* *Логика* — переключатель {{И/ИЛИ}} между условием 1 и условием 2: {{И}} — правило срабатывает только если истинны оба условия; {{ИЛИ}} — правило срабатывает, если истинно хотя бы одно из условий.
#* *Условие 2* — оператор сравнения и значение для сравнения (по аналогии с условием 1); задаётся, когда для одного поля требуется проверить сразу два условия (например, диапазон значений). Если нужно проверить несколько независимых диапазонов для одного поля — создаются отдельные правила.
# *Секция "Что оформляем" — область применения:*
#* Выпадающий список пилюль с полок "Значения" (независимо от режима {{Первое/Все}}), "Строки", "Столбцы" — определяет, к каким колонкам применяется правило (проверка условия и оформление/скрытие).
#** *Список поддерживает множественный выбор пилюль*: правило должно иметь возможность одновременно применяться к нескольким колонкам с единым условием проверки и единым набором настроек оформления (включая "Скрыть колонку"), без необходимости создавать отдельное правило под каждую колонку.
#* Два чекбокса — "Значение" и "Итоги": определяют, участвуют ли построчные значения и/или итоговая строка в проверке условия и применении оформления. Оба чекбокса включены по умолчанию.
# *Секция "Как оформляем" — параметры оформления и скрытия:*
#* *Цвет текста* — colorpicker, цвет текста при срабатывании правила.
#* *Цвет фона* — colorpicker, цвет фона при срабатывании правила.
#* *Начертание* — три независимых чекбокса: B (полужирное), I (курсив), U (подчёркнутое).
#* *Индикатор* — выпадающий список внешнего вида индикатора, отображаемого рядом со значением/итогом, подходящим под условие.
#* *Цвет индикатора* — colorpicker, цвет элемента, выбранного в поле "Индикатор".
#* *Вся строка* — тумблер; при включении *оформление* (цвет, начертание, индикатор) распространяется на всю строку, а не только на значение выбранной колонки.
#* *Скрыть колонку* (новый элемент) — тумблер; при включении и наличии хотя бы одной строки в колонке, удовлетворяющей заданному условию, колонка скрывается целиком через тот же механизм, что и тумблер "Скрыть результат" в настройках пилюли на полке "Значения".
#** К тумблеру добавить подсказку (tooltip): "При выполнении заданного условия выбранная колонка будет скрыта".
#** Тумблер по умолчанию *выключен*.

*Изменения расположения элементов относительно текущей реализации:*
* Секции "Что проверяем" и "Что оформляем" сохраняют свой состав почти без изменений, но перестраиваются.
* Выпадающий список пилюль в "Что оформляем" переводится в режим множественного выбора (см. п. 4) — это меняет поведение компонента относительно текущей реализации, где выбор мог быть ограничен одной пилюлей; необходимо обеспечить, что все выбранные пилюли получают единые условия проверки и единые настройки оформления/скрытия в рамках одного правила.
* Секция "Оформление" переименовывается в "Как оформляем".
* Тумблер "Скрыть колонку" размещается непосредственно после тумблера "Вся строка", в конце блока визуальных параметров оформления, как логическое продолжение настроек, влияющих на оформление/отображение колонки.

---
h4. 2.2. Дополнительные сценарии и правила поведения.

# Если тумблер "Скрыть колонку" включён и хотя бы одна проверяемая строка колонки (с учётом состояния чекбоксов "Значение"/"Итоги") удовлетворяет условию правила — колонка скрывается целиком; частичное скрытие отдельных ячеек не производится.
# Если ни одна проверяемая строка колонки не удовлетворяет условию — колонка отображается в обычном режиме, правила оформления к ней не применяется.
# При множественном выборе пилюль в "Что оформляем" (см. п. 2.1., п. 4) правило проверяется и применяется независимо для каждой выбранной колонки: колонка может скрыться сама по себе, если условие выполняется хотя бы в одной её строке, независимо от того, выполняется ли условие в других выбранных колонках.
# Если для одной и той же колонки одновременно применимы несколько правил с включённым тумблером "Скрыть колонку", колонка скрывается при срабатывании хотя бы одного из этих правил (логика ИЛИ между правилами).
# Совместное включение тумблеров "Вся строка" и "Скрыть колонку" в рамках одного правила - недопустимы. Включение второго тумблера, при уже активном первом, выключает первый тумблер и активирует второй.
# Тумблер *"Скрыть колонку"*, в настройках раздела "Условное форматирование" доступен для любых пилюль, выбранных из полок "Значения"/"Строки"/"Столбцы", в то время как тумблер *"Скрыть результат"* доступен только в настройках пилюль с полке "Значения". В рамках этой доработки, крайне желательно добавить аналогичный тумблер в настройки пилюль с полок "Строки"/"Столбцы", по аналогии с уже существующим тумблером на полке "Значения".
# Колонка, скрытая по условию, продолжает участвовать в вычислениях (агрегатах, сортировке) — скрытие является визуальным и не влияет на данные.
# В случае одновременного включения настроеки "Скрыть результат" (в настройках пилюли) и "Скрыть колонку" (из настроек условного форматирования) - приоритет по отображению или скрытию отдаётся настройке "Скрыть колонку" из настроек условного форматирования. Т.е. при условии, что включены обе настройки, но в конкретной колонке не выполняется заданное условие ни для одной строки - данная колонка отображается.

h3. 3. Требования к реализации.

h4. 3.1. Фронтенд-часть.

* В секции "Как оформляем" раздела "Условное форматирование" добавить новый тумблер "Скрыть колонку", в соответствии с описанным видом и поведением.
* Расположение существующих настроек блоков "Что проверяем" и "Что оформляем" может измениться в рамках общей визуальной переработки раздела "Условное форматирование" (без изменения состава и смысла этих настроек).
* При включении тумблера "Скрыть колонку" интерфейс должен визуально отображать (в предпросмотре таблицы), что колонка будет скрыта (при срабатывании условия), без пересохранения визуализации или отчёта.
* Для пилюль на полках "Строки" и "Столбцы" требуется добавление тумблера "Скрыть результат", аналогично уже существующему тумблеру "Скрыть результат" на полке "Значения".
* Состояние тумблера "Скрыть колонку" сохраняется в конфигурации правила условного форматирования и восстанавливается корректно при повторном открытии настроек визуализации.

---
h4. 3.2. Бэкенд-часть.

* В структуре объекта правила условного форматирования (элемент массива {{rules}} в метаданных визуализации, аналогично существующим полям {{color}}, {{background}}, {{isTextBold}}, {{indicatorType}}, {{indicatorColor}}, {{hideTypeTotals}}) добавить новое булево поле, отвечающее за состояние тумблера "Скрыть колонку" (далее — {{hideColumn}}), по умолчанию {{false}}.
* Логика вычисления условия ("Что проверяем": {{fieldId}}, {{cons}} — условия 1 и 2 с операторами и логикой И/ИЛИ) не изменяется — переиспользуется существующий механизм расчёта срабатывания правила.
* При построении итогового набора данных для отображения таблицы: для каждой колонки, попадающей в область действия правила (выбранные в "Что оформляем" пилюли), проверяется, срабатывает ли условие правила хотя бы для одной строки этой колонки (с учётом включённых чекбоксов "Значение"/"Итоги"); если правило с {{hideColumn: true}} срабатывает — колонка помечается как скрытая по тому же признаку/механизму, что и статичное скрытие через {{hideResult}} у пилюли.
* Если для колонки одновременно применимо несколько правил с {{hideColumn: true}}, колонка скрывается при срабатывании хотя бы одного из них (логика ИЛИ между правилами).
* Обеспечить корректную обработку случая отсутствия данных (пустой набор строк, {{null}}-значения) при вычислении условия скрытия — отсутствие данных не должно приводить к ошибке вычисления и должно интерпретироваться как невыполнение условия для соответствующей строки.
* Если для пилюль полок "Строки"/"Столбцы" не реализовано аналогичное поле {{hideResult}} в структуре описания пилюли для этих полок (по аналогии с существующим полем {{hideResult}} у пилюль полки "Значения"), то аналогичное поле требуется реализовать.

---
h4. 3.3. Технические требования и ограничения.

* Изменение структуры метаданных правила ({{hideColumn}}) должно быть обратно совместимо: отсутствие поля в ранее сохранённых конфигурациях интерпретируется как {{false}} (тумблер выключен, поведение не изменяется относительно текущей версии).
* Вычисление условия скрытия колонки не должно требовать дополнительных SQL-запросов сверх уже выполняемых для получения данных, отображаемых в отчёте — используется тот же набор данных, что и для применения условного форматирования (цвет/индикатор).
* Порядок и состав колонок, не затронутых правилами со включённым {{hideColumn}}, не должен изменяться.
* Производительность вычисления условия скрытия должна оставаться сопоставимой с текущей производительностью применения условного форматирования — проверка выполняется в рамках уже существующего цикла обработки данных таблицы.
* Существующие сохранённые правила условного форматирования визуализации "Таблица сводная" должны продолжать работать без изменений после доработки.

h3. 5. Критерии приёмки (AC):

AC.1 — *Отображение тумблера "Скрыть колонку":*
* *Дано:* открыт раздел "Условное форматирование" правой боковой панели настроек визуализации "Таблица сводная", создано правило условного форматирования;
* *Когда:* пользователь переходит в секцию "Что оформляем";
* *Тогда:* отображается тумблер "Скрыть колонку" с подсказкой "При выполнении заданного условия выбранная колонка будет скрыта", по умолчанию выключен.

AC.2 — *Скрытие колонки при срабатывании условия:*
* *Дано:* создано правило условного форматирования, в "Что проверяем" задано условие, в "Что оформляем" выбрана колонка (пилюля) и включён тумблер "Скрыть колонку";
* *Когда:* хотя бы одна строка выбранной колонки удовлетворяет заданному условию (с учётом включённых чекбоксов "Значение"/"Итоги");
* *Тогда:* колонка скрывается целиком, аналогично поведению при включении тумблера "Скрыть результат" у пилюли.

AC.3 — *Колонка не скрывается при невыполнении условия:*
* *Дано:* создано правило с включённым тумблером "Скрыть колонку";
* *Когда:* ни одна строка выбранной колонки не удовлетворяет заданному условию;
* *Тогда:* колонка отображается в обычном режиме без применения оформления данного правила.

AC.4 — *Учёт чекбоксов "Значение" и "Итоги" при скрытии:*
* *Дано:* создано правило с включённым тумблером "Скрыть колонку", выключен чекбокс "Итоги";
* *Когда:* условие выполняется только в итоговой строке/столбце, но не выполняется ни в одной обычной строке значений;
* *Тогда:* колонка не скрывается, так как итоги исключены из проверки условия для скрытия.

AC.5 — *Несколько правил для одной колонки:*
* *Дано:* для одной и той же колонки применимы два правила условного форматирования с включённым тумблером "Скрыть колонку", у каждого своё условие;
* *Когда:* срабатывает хотя бы одно из двух правил;
* *Тогда:* колонка скрывается.

AC.6 — *Множественный выбор пилюль:*
* *Дано:* создано правило условного форматирования;
* *Когда:* пользователь в секции "Что оформляем" выбирает несколько пилюль и включает тумблер "Скрыть колонку";
* *Тогда:* правило применяется независимо к каждой выбранной колонке, скрытие происходит для каждой колонки при выполнении условия хотя бы в одной её строке.

AC.7 — *Обратная совместимость:*
* *Дано:* ранее сохранённая конфигурация правила условного форматирования не содержит поля {{hideColumn}};
* *Когда:* визуализация открывается после доработки;
* *Тогда:* правило работает как прежде (цвет, оформление, индикатор), колонка не скрывается — новый тумблер по умолчанию считается выключенным.
