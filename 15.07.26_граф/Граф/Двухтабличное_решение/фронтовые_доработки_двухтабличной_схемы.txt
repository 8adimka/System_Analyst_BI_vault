При вводе двухтабличной схемы работы диаграммы граф потребуется доработать интерфейс и фронтенд. Сейчас важно зафиксировать в каком виде и как будет строиться работа сразу с двумя наборами данных для пользователя.

На данный момент, при входе в настройки визуализации, слева расположена боковая панель - в этой панеле мы можем выбрать набор данных (с которым будет работать данная визуализация), под выпадающим списком, где мы задаём набор данных, располагаются поля Набора данных (идут колонкой вниз).

Так как переработка затрагивает именно диаграмму Граф, то далее я буду описывать как будет выглядеть окно настройки именно диаграммы Граф, после доработок для двухтабличного режима.

Так как у нас появляется уже два набора данных, то на боковой панеле их нужно разграничить и подписать. В общем случае их можно подписать как "Основной набор данных" и "Дополнительный набор данных", но для диаграммы Граф имеет смысл сделать такое наименование -> Под заголовком "Структура данных" мы размещаем подзаголовок "Узлы" и ниже аналогичный выпадающий список для выбора набора данных, который будет содержать набор отображаемых Узлов - это наш первый набор данных. После выбора набора данных для "Узлы", аналогичным образом как это работает сейчас, ниже будут располагаться поля набора данных "Узлы".
Но теперь ниже у нас появляется ещё один подраздел "Связи" с таким же выпадающим списком для выбора второго набора данных. После выбора второго набора данных из раздела "Связи" под выпадающим списком должна появится аналогичная колонка с полями, а чтобы общий список полей двух наборов данных не становился слишком громоздким мы вводит возможность сворачивать и разворачивать списки полей наборов данных. При нажатии на специальную область под выпадающим списком для выбора набора данных, мы сворачиваем все поля данного набора данных - у нас остаётся только наименование подзаголовка ("Узлы"/"Связи") и поле выбора набора данных (выпадающий список), а все поля этого набора данных оказываются скрыты (сворачиввание "аккардион"), а при повторном нажатии на специальное поле под выпадающим списком для выбора набора данных - список полей данного набора данных разворачивается обратно, давая пользователю доступ к полям набора данных для размещения их на полках визуализации. Пользователь может свернуть оба набора данных, развернуть только один из них или развернуть сразу оба и работать с двумя наборами данных.

Также набор полок визуализации "Граф" также будет немного скорректирован:
1) Полка "Узел" - будет переименована в "Узлы", где будет размещатся колонка (пилюля) из набора данных "Узлы", содержащая Наименования всех узлов.
2) Полка "Связь" будет переименована в "Связи" - на эту полку мы будем размещать две колонки из набора данных "Связи" - колонка "Узел-источник" и колонка "Узел-приёмник", для каждой колонки (пилюли) мы должны нажать на символ выпадающих настроек пилюли ("🢓") и там задать "Тип" ("Узел-источник" или "Узел-приёмник") для каждой колонки, чтобы диаграмма верно простраивала связи между узлами Графа. "Узел-источник" - это колонка из набора данных содержащая узел из которого выходит связь, а колонка "Узел-приёмник" содержит наименования узлов в которые данныя связь входит - так диаграмма попарно обрабатывает два изла и строит между ними связь.
3) Ниже будет полка "Свойства узлов" (сейчас она называется "Значения") - на эту полку мы будет размещать различные колонки (пилюли) из набора данных "Узлы", которые будут помогать отрисовывать узлы особым образом - для каждого узла может задаваться его радиус, цвет или иные значения для отображения подсказок и т.д. Для каждой размещенной на этой полке пилюли мы также должны аналогичным образом в настройках пилюли (нажать на "🢓") задать её "Тип" (Радиус, Цвет, Значение).
4) Ниже будет полка "Свойства связей" (сейчас она называется "Категории") - на эту полку мы будет размещать различные колонки (пилюли) из набора данных "Связи", которые будут помогать отрисовывать связи между узлами особым образом - для каждой связи мы можем задавать - тип связи, цвет, значение для отображения подсказок и т.д. Для каждой размещенной на этой полке пилюли мы также должны аналогичным образом в настройках пилюли (нажать на "🢓") задать её "Тип" (Тип связи, Цвет, Значение).
5) Последняя полка остаётся без изменений - "Фильтры". Эта полка также отвечается за выбор пилюль по которым будет производится фильтрация.
