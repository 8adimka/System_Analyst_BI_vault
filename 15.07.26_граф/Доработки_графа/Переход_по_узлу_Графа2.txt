h3. Контекст и проблематика.

В диаграмме «Граф» раздел «Настройки клика» позволяет задать общий URL или выбрать отчёт для перехода, указать вкладку открытия либо назначить другую операцию. Автор отчёта не может настроить отдельный адрес перехода для каждого узла. Это ограничивает функциональность графа для показа детальной информации о выбранном объекте.

----
h3. Цель задачи.

Обеспечить переход по нажатию на узел графа по ссылке из поля текущего набора данных, сохранив существующий общий режим перехода.

----
h3. 1. Описание целевого поведения.

Первым параметром раздела «Настройки клика» в правой боковой панели добавить выпадающий список «Режим клика» со значениями «По визуализации» и «Переход по узлу». По умолчанию выбран режим «По визуализации».

|| Режим || Доступные настройки || Действие ||
| По визуализации | Существующие выбор отчёта, «URL ссылки», «Открывать в», «Другая операция», «Текст всплывающей подсказки» | Сохраняется действующий механизм общего перехода через кнопку на панели визуализации. «Другая операция» является альтернативой переходу по URL. |
| Переход по узлу | «Источник ссылки», «Открывать в» | Нажатие на узел открывает его ссылку из выбранного поля набора данных. |

В режиме «Переход по узлу» общий URL, выбор отчёта, «Другая операция» и «Текст всплывающей подсказки» скрыты и не участвуют в обработке перехода. Общий переход через кнопку панели визуализации в этом режиме недоступен.

«Открывать в» определяет вкладку для перехода: «Той же вкладке» или «Новой вкладке». Для новой конфигурации используется «Той же вкладке».

Если выбран режим «Переход по узлу» и в параметре «Источник ссылки» выбрано поле, «Режим фильтра» автоматически переключается в положение «Выкл» (если был включён) и становится недоступным для включения. Раздел «Режим фильтра» отображается в неактивном состоянии: тумблер — «Выкл», заголовок раздела — чёрного цвета, аналогично действующему поведению при настройке «Дрилл» в других визуализациях.

Правило применяется независимо от порядка выбора режима и источника ссылки, в том числе при повторном открытии сохранённого отчёта. При возврате к режиму «По визуализации» раздел «Режим фильтра» снова становится доступным, но остаётся выключенным до ручного включения. Ранее заданные настройки фильтра сохраняются.

----
h3. 2. Функциональные требования.

h4. 2.1. Источник ссылки и действия пользователя.

Предусловие к данным: каждый узел хотя бы один раз представлен в поле, размещённом на полке «Узел». Строка узла может не содержать узла-приёмника; это не препятствует размещения в этой строке URL-ссылки и переходу по этому узлу, в том числе когда сам данный узел является приёмником в других связех (на другой строке набора данных). Соответствие ссылки-узла и узла определяется полем, размещённым на полке «Узел».

* «Источник ссылки» — выбор одного поля из доступных полей текущего набора данных диаграммы. Поле не требуется предварительно размещать на полках.
* Поле содержит готовый адрес перехода с необходимыми параметрами. Поддерживаются полные HTTP(S)-адреса и внутренние пути от корня портала, например {{/report/123}}. Портал использует адрес для нажатого узла; отдельный выбор целевого отчёта или составление шаблона ссылки не требуется.
* Ссылкой узла является значение выбранного поля из первой исходной строки этого узла в актуальных данных диаграммы. Последующие строки не используются, в том числе если в первой строке значение пустое или не соответствует поддерживаемым форматам. Ссылка сопоставляется с узлом по его действующему ключу; адрес другого узла не подставляется.
** При соблюдении стандартов портала допускается иная реализации на усмотрение разработчика, например, через агрегации. Ожидаемое поведение набора данных, что, если для узла в наборе данных есть несколько строк, то в каждой из строк узла должен быть размещён одинаковый URL ссылки-узла.
* Ссылка получается в том же контексте данных, что и граф, с учётом действующих фильтров и ограничений доступа. Выбор источника ссылки не изменяет состав узлов и связей или расчёт других свойств диаграммы.
* Если ссылка узла отсутствует, равна {{null}}, представляет собой пустую строку или не соответствует поддерживаемым форматам, переход не выполняется и курсор ссылки не отображается. Общий URL и другая операция в качестве замены не используются.
* В режиме «Переход по узлу» нажатие на узел выполняет только переход (происходит автоматическое отключение «Режим фильтра»). Фильтрация и детализация по этому нажатию не выполняются, в том числе при отсутствии доступной ссылки для отдельного узла. Настройки сохраняются и после возврата в режим «По визуализации» действуют по прежним правилам.
* Нажатие на фон или связь не выполняет переход. Перетаскивание узла, перемещение и масштабирование графа не должны вызывать переход.
* Настройки «Подсказки узлов» и «Подсказки связей» сохраняют своё назначение; скрытие общего текста подсказки клика не отключает эти подсказки.

h4. 2.2. Сохранение и совместимость.

* При переключении режима сохраняются ранее введённые значения настроек обоих режимов. «Открывать в» остаётся общим параметром выбранного режима.
* Выбранный режим, источник ссылки и параметры перехода должны сохраняться в составе отчёта и восстанавливаться после повторного открытия.
* Сохранённые отчёты без нового параметра режима открываются в режиме «По визуализации» и сохраняют действующие настройки и поведение без ручной перенастройки.
* В режиме «Переход по узлу», если источник ссылки не выбран либо выбранное поле удалено или недоступно в новом наборе данных, в настройках отображается проблема и необходимость выбрать источник, а переходы по узлам отключаются. Сохранение отчёта разрешено; после повторного открытия проблема остаётся видимой до выбора доступного источника. Автоматическая подстановка другого поля не допускается. Если необходимые для построения графа поля доступны, граф продолжает отображаться.
* Доработка должна обеспечивать настройку режима, получение ссылки соответствующего узла, обработку нажатия и сохранение конфигурации. Необходимость изменений бэкенда, способ получения значения и контракт обмена определяются при технической проработке по правилам раздела 2.1.

h3. 4. Критерии приёмки (AC):

*AC.1 — Выбор режима:*
* *Дано:* открыты «Настройки клика» диаграммы «Граф»;
* *Когда:* пользователь переключается между двумя значениями «Режим клика»;
* *Тогда:* состав доступных настроек соответствует разделу 1, введённые значения и выбранная вкладка не сбрасываются; скрытые настройки общего режима не выполняются в режиме узла.

*AC.2 — Индивидуальные ссылки и вкладка:*
* *Дано:* выбран режим «Переход по узлу»; поле {{URL_узла}} отсутствует на полках, но выбрано источником; узлам {{A}} и {{B}} однозначно соответствуют адреса {{https://example.com/object/A}} и {{/report/101?object=B}};
* *Когда:* пользователь нажимает каждый узел; сценарий повторяется с обоими значениями «Открывать в»;
* *Тогда:* открывается адрес соответствующего узла в указанной вкладке; для новой вкладки исходный отчёт остаётся открытым.

*AC.3 — Пустая или недопустимая ссылка и другие действия с графом:*
* *Дано:* режим «Переход по узлу»; для трёх узлов источник содержит соответственно {{null}}, пустую строку и текст {{не ссылка}}; в общем режиме ранее задан URL;
* *Когда:* пользователь наводит указатель и нажимает эти узлы, затем нажимает фон или связь, перетаскивает узел и изменяет масштаб;
* *Тогда:* ни одно действие не выполняет переход; у этих узлов нет курсора ссылки; общий URL не используется; перетаскивание, масштабирование и настроенные подсказки остаются доступны.

*AC.4 — Сохранение и смена источника:*
* *Дано:* для узлов подготовлены два поля с однозначными, различающимися ссылками;
* *Когда:* пользователь выбирает первое поле, сохраняет и повторно открывает отчёт, затем выбирает второе поле и повторяет сохранение и открытие;
* *Тогда:* режим, выбранное поле и вкладка восстанавливаются; переход использует значение последнего сохранённого источника для нажатого узла.

*AC.5 — Сохранение без доступного источника:*
* *Дано:* выбран режим «Переход по узлу», а необходимые для построения графа поля доступны; источник не выбран, удалён либо недоступен после смены набора данных;
* *Когда:* пользователь сохраняет и повторно открывает отчёт, затем выбирает доступное поле ссылки;
* *Тогда:* сохранение разрешено; до выбора поля граф отображается без переходов, а в настройках видна проблема; другое поле автоматически не назначается; после выбора источника переходы доступны для узлов с допустимыми ссылками.

*AC.6 — Совместимость общего режима:*
* *Дано:* до доработки сохранены отчёты с общим URL и с каждой из трёх других операций;
* *Когда:* отчёты открыты после доработки и пользователь вызывает действие кнопкой панели визуализации;
* *Тогда:* выбран режим «По визуализации»; настройки, вкладка, подсказка и результат действия соответствуют сохранённой конфигурации.

*AC.7 — Ссылка в актуальном контексте данных:*
* *Дано:* узел {{A}} представлен несколькими исходными строками с одинаковым URL и связан с узлами {{B}} и {{C}}; к диаграмме применены фильтры и действующие ограничения доступа;
* *Когда:* пользователь выбирает поле ссылки источником и обновляет диаграмму, затем изменяет фильтр;
* *Тогда:* для каждого состояния фильтра выбор источника не меняет состав узлов, связей и значения остальных свойств по сравнению с графом без настроенного источника; {{A}} не дублируется, его ссылка соответствует доступным строкам актуального результата.

*AC.8 — Ссылка из первой строки узла:*
* *Дано:* узлу {{A}} соответствуют две исходные строки с разными URL в источнике ссылки; в используемом порядке данных строка с {{https://example.com/first}} является первой, с {{https://example.com/second}} — второй;
* *Когда:* пользователь нажимает узел {{A}} в режиме «Переход по узлу»;
* *Тогда:* открывается {{https://example.com/first}}; если в первой строке вместо URL находится {{null}}, пустая строка или недопустимое значение, переход не выполняется и URL второй строки не используется.

*AC.9 — Взаимоисключение «Режима фильтра» и «Перехода по узлу»:*
* *Дано:* для графа включен «Режим фильтра» по нажатию на узел, для перехода выбрано открытие в новой вкладке;
* *Когда:* пользователь в разделе «Настройки клика» выбирает «Режим клика» — «Переход по узлу» и указывает поле в «Источник ссылки»;
* *Тогда:* «Режим фильтра» автоматически переключается в «Выкл», раздел становится недоступным для включения (заголовок чёрного цвета). Нажатие на узел не вызывает фильтрацию независимо от наличия допустимой ссылки для конкретного узла.

*AC.10 — Узел без исходящей связи:*
* *Дано:* строка узла {{B}} содержит его URL и пустое значение узла-приёмника; другая строка задаёт связь {{A}} → {{B}};
* *Когда:* в режиме «Переход по узлу» пользователь нажимает {{B}};
* *Тогда:* открывается ссылка из строки узла {{B}}; наличие входящей связи и отсутствие исходящей не препятствуют переходу.
