Данные примера · Граф связей

У каждого узла — своё значение click_url. В поле report_url находятся другие ссылки: выберите его в «Источнике ссылки», чтобы проверить смену назначения.

УзелИсточникclick_urlreport_urlregion_name

В примере значения ссылки для одного узла однозначны. У «Партнёр 3» ссылка отсутствует.

Переходы открывают локальную демонстрационную страницу с выбранным адресом. Реальные отчёты и внешние сайты не запрашиваются.
Настройки клика · О макете

Откройте «Настройки клика» в правой панели. Согласованный вариант — выпадающий список «Режим клика» первым полем раздела.

  • По визуализации — прежний набор настроек: отчёт или единый URL, вкладка, другая операция и текст подсказки. Если URL задан, выполняется переход; иначе — выбранная операция.
  • Переход по узлу — источник ссылки из текущего набора данных и выбор вкладки. Общая ссылка, другая операция и текст подсказки скрыты. Введённые значения сохраняются при переключении режима.
  • Проверьте поле click_url, затем report_url. Выберите region_name, чтобы увидеть обработку значений, которые не являются ссылками. Очистите источник, чтобы проверить обязательное поле.
  • «Сохранить» запоминает настройки в текущем открытом макете. «Отмена» возвращает последнее сохранённое состояние. «Сбросить» восстанавливает исходный пример.
  • Нажатия на узлы работают сразу. В новой вкладке открывается этот же HTML с локальной карточкой назначения. Кнопка возврата возвращает к настройкам.

Внешний вид основан на приложенном скриншоте и исходниках портала bi_react c6f51bb7. Данные вымышленные. Самостоятельный макет работает без сервера и сетевых запросов.

Согласовано: узел без ссылки не выполняет переход и не показывает курсор ссылки. Правило выбора ссылки при нескольких разных URL у одного узла остаётся открытым; в примере используются однозначные значения.
