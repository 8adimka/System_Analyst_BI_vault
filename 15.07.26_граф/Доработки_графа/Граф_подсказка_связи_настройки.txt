h3. Контекст и проблематика.

Диаграмма «Граф» запрашивает данные с группировкой по упорядоченной паре {{[node]}} + {{[linkage]}}, где {{[node]}} — узел-источник, а {{[linkage]}} — узел-приёмник. Бэкенд возвращает отдельное агрегированное значение пилюли с полки «Значения» для каждой такой пары.

При последующей обработке данных значения разных связей одного узла-источника сворачиваются до значения из первой полученной строки. В результате это значение используется для отображения свойств данного узла и свойств связи с этим узлом, несмотря на то, что в ответе бэкенда для связей получены разные значения.

----

h3. Цель задачи.

Обеспечить отображение в текстовой подсказке каждой связи значения, относящегося к соответствующей паре {{[node]}} + {{[linkage]}}, без изменения текущей группировки данных и обработки свойств узлов.

*Требуется:*

# Считать свойством связи только пилюлю с полки «Значения», выбранную в настройке «Подсказки связей» → «Шаблон» (со значением «текст подсказки») → «Текст подсказки».
# Для выбранной пилюли сохранять соответствие между значением и конкретной упорядоченной парой {{[node]}} + {{[linkage]}}.
# Не распространять значение одной связи на другие связи для того же узла-источника.
# Сохранить текущую обработку остальных пилюль с полки «Значения», используемых как свойства узла.

----

h3. 1. Описание целевого поведения.

* Для каждой связи текст подсказки формируется из значения выбранной пилюли в строке результата с соответствующими {{[node]}} и {{[linkage]}}.
* При сопоставлении значения учитываются роли полок: {{[node]}} является узлом-источником, {{[linkage]}} — узлом-приёмником. Действующие правила определения направления и отрисовки связей не изменяются.
* Если один узел-источник связан с несколькими узлами-приёмниками, каждой связи назначается собственное значение подсказки.
* Если для конкретной пары значение выбранной пилюли отсутствует, значение другой связи не подставляется.
* Строка с заполненным {{[node]}} и пустым {{[linkage]}} участвует в формировании узла, но не создаёт связь и подсказку связи.
* Для свойств узла сохраняется текущая логика: если после группировки одному {{[node]}} соответствуют несколько строк, для отрисовки узла используется значение из первой полученной строки. Фиксировать порядок строк не требуется.

----

h3. 2. Требования к реализации.

h4. 2.1. Обработка свойства связи.

* Специальная обработка применяется только в контексте формирования текстовой подсказки связи и только к пилюле, выбранной в настройке «Текст подсказки».
* При формировании модели связей необходимо использовать значение выбранной пилюли из результата для той же пары {{[node]}} + {{[linkage]}}.
* К выбранному свойству связи не должна применяться постобработка свойств узла с выбором одного значения среди всех строк одного {{[node]}}.
* Полученное от бэкенда значение используется без дополнительной агрегации или пересчёта на фронтенде. Агрегация исходных данных в пределах пары {{[node]}} + {{[linkage]}} продолжает выполняться на бэкенде согласно настройке пилюли.
* Должна использоваться именно выбранная в настройке пилюля независимо от её позиции на полке «Значения».

---
h4. 2.2. Совместимость и ограничения.

* Не изменять состав payload, группировку по {{[node]}} + {{[linkage]}}, SQL-генерацию, API-контракт и обработку данных на бэкенде.
* Не изменять существующие полки и настройки диаграммы «Граф» и не добавлять новые запросы для получения свойств связей.
* Не изменять правила формирования и дедупликации узлов, а также обработку пилюль с полки «Значения» в контекстах свойств узла.
* Сохранённые отчёты с уже настроенной текстовой подсказкой связи должны открываться без миграции и перенастройки.
* Различение нескольких самостоятельных связей между одной и той же упорядоченной парой {{[node]}} + {{[linkage]}} в рамки задачи не входит.

h4. 2.3. Дополнительные доработки.

* Изменить наименование раздела настроек «Подсказки» для диаграммы «Граф» на «Подсказки узлов».

h3. 4. Критерии приёмки (AC):

*AC.1 — Разные значения для связей одного узла-источника:*
* *Дано:* в отчёте для воспроизведения пилюля {{Тип_связи}} размещена на полке «Значения» и выбрана в параметре «Текст подсказки»;
* *Когда:* пользователь последовательно наводит указатель на три связи узла «Хэндисофт, ООО»;
* *Тогда:* в подсказках отображаются значения соответствующих пар:
|| Связь || Значение подсказки ||
| Хэндисофт, ООО → Департамента информационных технологий и связи Ямало-Ненецкого автономного округа (ДИТиС ЯНАО) | Есть успешные |
| Хэндисофт, ООО → Министерство Обороны Российской Федерации (Минобороны России) | Открытые сделки |
| Хэндисофт, ООО → Министерство Российской Федерации по делам гражданской обороны, чрезвычайным ситуациям и ликвидации последствий стихийных бедствий | Только неуспешные |
* *И:* значение ни одной из пар не используется в подсказках других пар.

*AC.2 — Выбор пилюли независимо от её позиции:*
* *Дано:* на полке «Значения» размещены пилюли {{Свойство_1}} и {{Свойство_2}}; вторая пилюля {{Свойство_2}} выбрана в параметре «Текст подсказки»; для связи {{A}} → {{B}} значения пилюль равны {{X}} и {{Y}} соответственно;
* *Когда:* пользователь открывает подсказку связи {{A}} → {{B}};
* *Тогда:* в подсказке отображается {{Y}} — значение выбранной пилюли {{Свойство_2}}.

*AC.3 — Независимая обработка свойств узла:*
* *Дано:* узел {{A}} представлен строками для связей {{A}} → {{B}} и {{A}} → {{C}}; пилюля {{Радиус}} с типом «Радиус» имеет значение {{10}} в обеих строках, а выбранное свойство связи — значения {{X}} и {{Y}} соответственно;
* *Когда:* диаграмма сформирована;
* *Тогда:* узел {{A}} отрисован один раз с радиусом {{10}}, для связи {{A}} → {{B}} в подсказке отображается {{X}}, для связи {{A}} → {{C}} — {{Y}}.

*AC.4 — Пустые значения:*
* *Дано:* одна строка содержит {{[node]}} без {{[linkage]}}, а для другой строки с заполненной парой {{[node]}} + {{[linkage]}} отсутствует значение выбранного свойства связи;
* *Когда:* диаграмма сформирована;
* *Тогда:* первая строка создаёт узел без связи; вторая строка создаёт связь, при открытии её подсказки значение выбранного свойства не отображается и не заменяется значением другой связи; диаграмма отрисовывается без ошибки.

*AC.5 — Сохранённый отчёт:*
* *Дано:* до установки доработки сохранён отчёт с пилюлей, выбранной в параметре «Текст подсказки»;
* *Когда:* отчёт открыт после установки доработки;
* *Тогда:* отчёт открывается без миграции, повторной настройки и повторного сохранения; пилюля остаётся выбранной в параметре «Текст подсказки», а значение каждой подсказки определяется соответствующей парой {{[node]}} + {{[linkage]}}.

*AC.6 — Сохранение текущего запроса данных:*
* *Дано:* настроена диаграмма «Граф» с пилюлей, выбранной в параметре «Текст подсказки»;
* *Когда:* диаграмма запрашивает данные;
* *Тогда:* в {{group}} передаются поля {{[node]}} и {{[linkage]}}, для выбранной пилюли сохраняется настроенная агрегация, а отдельный дополнительный запрос для получения свойства связи не отправляется.

*AC.7 — Изменение наименования раздела настроек:*
* *Дано:* пользователь заходит в настройки диаграммы «Граф»;
* *Когда:* использует правую боковую нанель настроек диаграммы «Граф»;
* *Тогда:* наименование раздела настроек отображается как «Подсказки узлов» вместо «Подсказки».
