# Уточнение требований

Применяй к краткому запросу, неясному типу задачи или нескольким возможным интерпретациям. Стандарт достаточности — `agent-system/standards/requirements-quality.md`.

Выясни роль пользователя, затронутый компонент, текущее и ожидаемое поведение, ценность и рамки. Для бага проверь окружение, шаги, ожидаемый/фактический результат. Изучи материалы и доступный код прежде, чем спрашивать о технических фактах. Если ссылка недоступна, укажи конкретный пробел, не выдумывая её содержимое.

Подготовь полезный черновик по подтверждённой части. Отмечай `[ПРЕДПОЛОЖЕНИЕ]`, `[УТОЧНИТЬ У ...]`, существенные развилки помещай в «Открытые вопросы». Не выбирай произвольное поведение, когда ответ меняет смысл задачи. Вопросы ранжируй по влиянию: не более трёх важнейших за один подход; при необходимости следующий набор после ответа. Для каждого поясни неоднозначность и какие требования/AC изменятся. Если данных достаточно, вопросы не требуются.

Результат координатору: черновик в Jira wiki, подтверждения и список оставшихся вопросов в объявленной структуре. Черновик с существенными вопросами не является согласованной постановкой.
