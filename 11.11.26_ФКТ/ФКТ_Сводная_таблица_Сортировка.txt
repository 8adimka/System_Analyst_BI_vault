h3. ФКТ. Сводная таблица. Сквозная сортировка по колонке.
*Релиз:* 3.18.

h3. Контекст и цель.
При просмотре отчёта пользователь ФКТ сортирует сводную таблицу из заголовка колонки. Сейчас порядок определяется по полученной части данных: строки за пределами выдачи не участвуют в сортировке, что искажает представление о наибольших и наименьших значениях. Сортировка через контрольную панель в сводной таблице, а также сортировка через пилюли в режиме настройки визуализации - служат текущим ориентиром поведения сквозной сортировки по всем данным.

*Требуется:* сохранить сортировку из заголовков сводной таблицы и определять порядок по всем относящимся к визуализации данным с действующими фильтрами до ограничения выдачи.

----
h3. 1. Правила сортировки.
* Сквозная сортировка применяется как к иерархической сводной таблице, так и к сводной с полями на полке «Детализация», включая сортировку по заголовку поля детализации. Получение только части строк не должно исключать остальные строки из определения порядка.
* При сортировке по значению, ключ определяется полным путём выбранной колонки и показателем. Например: «Корпусная мебель → Шкаф-купе → Вычисляемая_Сумма». Одноимённый показатель в другой подколонке является другим ключом сортировки.
* Переставляются строки целиком: связь ячеек строки сохраняется. Возрастание или убывание обеспечивается по выбранной подколонке в пределах каждой группы соседних строк; остальные подколонки следуют тому же порядку строк.
* В иерархической сводной таблице на каждом уровне сортируются соседние строки внутри своего родителя. Группы сравниваются по значению выбранной колонки для группы, дочерние строки — по собственным значениям. Строки разных родителей не перемешиваются. Правило распространяется и на строки, которые будут загружены при последующем раскрытии.
* Итоговые строки сохраняют предусмотренное для них положение. При выборе итоговой колонки порядок определяется её итоговыми значениями.

----
h3. 2. Управление и временный приоритет.
* Повторные нажатия на один заголовок переключают состояния: по возрастанию → по убыванию → отключено. Одновременно активен один заголовок; выбор другого начинает сортировку по возрастанию по новому ключу. Индикация показывает выбранную колонку и направление.
* Активная сортировка из заголовка временно определяет порядок вместо сортировки, заданной в настройках визуализации. Настройки сортировки в контрольной панеле сводной таблицы и пилюлях сохраняются; при отключении сортировки из заголовка применяется порядок из настроек.
* При изменении фильтров активная сортировка применяется к данным с новыми условиями. Раскрытие и сворачивание строк сохраняют выбранную сортировку. Сворачивание ветви колонок сбрасывает её и возвращает порядок из настроек, как в действующем механизме.
* При новом открытии отчёта после закрытия применяется порядок из настроек визуализации. Временная сортировка из заголовка не сохраняется в настройках отчёта. Правила действуют и для ранее сохранённых сводных таблиц.
* При ошибке обновления используется действующее уведомление об ошибке. Ошибка не должна подменять сквозную сортировку сортировкой полученного фрагмента; настройки визуализации сохраняются.

----
h3. 3. Открытый вопрос:
Основной вариант — описанная сквозная сортировка. Если разработчик, при оценке трудозатрат, определяет данную доработку как крайне сложную и трудозатратную, то допускается отдельно рассмотреть полное удаление сортировки из заголовков сводной таблицы. Данное решение отложено до оценки.

h3. 5. Критерии приёмки (AC):
AC.1 — *Сортировка до ограничения выдачи:*
* *Дано:* данных сводной больше, чем получено; за пределами полученного фрагмента есть строки с минимальным и максимальным значениями выбранной колонки среди строк одного родителя.
* *Когда:* пользователь включает сортировку по возрастанию, затем по убыванию.
* *Тогда:* соответствующий минимум или максимум попадает в начало выдачи среди соседних строк; порядок совпадает с сортировкой всех данных этого родителя с действующими фильтрами до ограничения выдачи.

AC.2 — *Точный путь колонки:*
* *Дано:* подколонки «Вычисляемая_Сумма» для «Корпусная мебель → Шкаф-купе» и «Корпусная мебель → Стол приставной» дают разные порядки строк.
* *Когда:* пользователь сортирует первую подколонку, затем выбирает вторую.
* *Тогда:* сначала строки упорядочены по значениям «Шкаф-купе», затем по значениям «Стол приставной» по возрастанию; активный индикатор переносится во вторую подколонку. Значения остальных ячеек остаются связаны со своими строками.

AC.3 — *Иерархия и итоги:*
* *Дано:* сводная содержит несколько родителей, дочерние строки, включая ещё не загруженные, итоговые строки и итоговую колонку; порядки по обычной и итоговой колонкам различаются.
* *Когда:* пользователь сортирует обычную колонку и раскрывает группы, затем выбирает сортировку итоговой колонки.
* *Тогда:* группы и дочерние строки отсортированы внутри своих родителей, включая строки, полученные при раскрытии. Во втором случае сравниваются значения итоговой колонки. Иерархия и положение итоговых строк сохраняются.

AC.4 — *Полка «Детализация»:*
* *Дано:* сводная содержит поля на полке «Детализация»; часть строк не получена, и среди них есть первые по возрастанию и убыванию значения выбранного поля детализации.
* *Когда:* пользователь последовательно включает оба направления сортировки из заголовка этого поля.
* *Тогда:* порядок определяется по всем относящимся к визуализации данным с действующими фильтрами до ограничения выдачи; первые значения появляются на соответствующих местах, ячейки строк сохраняют связь. При наличии родителей сортировка выполняется внутри каждого родителя.

AC.5 — *Приоритет и отключение:*
* *Дано:* в настройках визуализации задан порядок, отличающийся от порядка выбранной колонки.
* *Когда:* пользователь тремя нажатиями на её заголовок проходит цикл сортировки.
* *Тогда:* применяются возрастание, убывание и затем порядок из настроек. Индикация соответствует состоянию; значения настроек в панели управления и пилюлях не изменяются.

AC.6 — *Фильтры и жизненный цикл:*
* *Дано:* открыта ранее сохранённая сводная с активной сортировкой из заголовка; изменение фильтра меняет состав данных и порядок групп.
* *Когда:* пользователь меняет фильтр, раскрывает и сворачивает строки.
* *Тогда:* выбранная сортировка сохраняется и применяется ко всем данным с новым фильтром.
* *И:* при сворачивании ветви колонок сортировка из заголовка сбрасывается; после закрытия и нового открытия отчёта также применяется порядок из настроек визуализации.

AC.7 — *Ошибка обновления:*
* *Дано:* для сводной с частично полученными данными задан порядок в настройках визуализации.
* *Когда:* при применении сортировки из заголовка обновление завершается ошибкой.
* *Тогда:* отображается действующее уведомление об ошибке; полученный фрагмент не сортируется вместо выполнения сквозной сортировки, настройки визуализации не изменяются.
