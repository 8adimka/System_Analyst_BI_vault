# MB-5275 — результат backend-проверки

## Матрица доступности

Для всех типов отображаются общие поля: тип подключения, имя источника, отображаемое название, краткое описание и порядок сортировки.

### Параметры подключения

| Тип подключения | Отображать | Скрыть |
|---|---|---|
| MS SQL Server | Хост, порт, имя БД, схема, логин, пароль | URL |
| PostgreSQL | Хост, порт, имя БД, схема, логин, пароль | URL |
| SQLite | Путь к файлу | Хост, порт, схема, логин, пароль, URL |
| ClickHouse | Хост, порт, имя БД, схема, логин, пароль | URL |
| ClickHouse HTTPS | Хост, порт, имя БД, схема, логин, пароль | URL |
| ClickHouse+SSL | Хост, порт, имя БД, схема, логин, пароль | URL |
| Метаданные | — | Хост, порт, имя БД, схема, логин, пароль, URL |
| Vertica | Хост, порт, имя БД, схема, логин, пароль | URL |
| MS SQL Server Instance | Хост в формате `server\instance`, имя БД, схема, логин, пароль | Порт, URL |

| StarRocks | Хост, порт, имя БД, схема, логин, пароль | URL |

`db_url` сохраняется в модели источника, но при формировании подключения не используется. Для SQLite в `db_name` передаётся путь к файлу, поэтому название поля в интерфейсе нужно заменить с «Хост БД» на «Путь к файлу».

## Список типов подключения

Backend возвращает все типы, которые не помечены как удалённые. Отдельной фильтрации списка нет.

- OLAP (XMLA) и Полиматика поддерживаются backend, но их нужно убрать из интерфейса.
- ClickHouse, ClickHouse HTTPS и ClickHouse+SSL используют один backend-драйвер `clickhouse-tcp`. Различается формирование строки подключения. В интерфейсе оставляем все три отдельных варианта.

## Дополнительные параметры

Backend не делит параметры карточки на основные и дополнительные. Перенос полей в аккордеон не меняет запросы и не требует backend-работ, если имена и значения полей в запросе сохраняются.

Боковую панель «Дополнительные параметры» оставляем без изменений.

Параметры подключения — хост, порт, имя БД или путь к файлу, схема, логин и пароль — должны оставаться в основной части карточки.

## Ответы на вопросы из задачи

2. **Как устроено подключение к Метаданным?** Это служебный источник, использующий подключение приложения к metadata-БД. Пользовательские параметры подключения не нужны.
3. **Нужен ли URL для ClickHouse HTTPS?** Нет. Используются хост, порт, имя БД, схема, логин и пароль.
4. **Поддерживается ли RLS для вариантов ClickHouse?** Нет. В матрице для всех трёх вариантов нужно поставить `✗`.
5. **Что поддерживается для Vertica?** Формы ввода, отчётные формы, коррекция данных, импорт из Excel и RLS поддерживаются.
6. **Чем MS SQL Server Instance отличается от MS SQL Server?** Instance указывается в хосте в формате `server\instance`; отдельный порт не используется.
7. **Что указывать в поле «Имя БД» для SQLite?** Путь к файлу SQLite. Поле лучше переименовать в «Путь к файлу».
