Сводная таблица — визуализация для многомерного анализа данных: она позволяет одновременно группировать, агрегировать и сравнивать данные в разрезе нескольких измерений.

Для настройки представления используются полки — области, в которые добавляются поля набора данных (пилюли). Состав и порядок полей на каждой полке определяют структуру и содержимое таблицы.

Полка «Строки» определяет, какие поля формируют строки таблицы. При добавлении нескольких полей они образуют иерархическую структуру в порядке размещения: каждый следующий уровень детализирует предыдущий. Пользователь может разворачивать и сворачивать уровни иерархии непосредственно в таблице.

Полка «Столбцы» работает аналогично полке «Строки», но управляет горизонтальной структурой таблицы. Поля, размещённые на этой полке, формируют заголовки столбцов, а при наличии нескольких полей — иерархию столбцов с возможностью её разворачивания.

Полка «Значения» определяет, какие показатели отображаются на пересечении строк и столбцов. Как правило, здесь размещаются числовые поля с агрегирующей функцией (сумма, среднее, количество и др.).

Полка «Детализация» добавляет в таблицу дополнительные колонки справа от колонок полки «Строки». Эти колонки отображают атрибуты, уточняющие информацию по самому нижнему уровню иерархии строк. На полку «Детализация» можно разместить как поле из набора данных, так и вычисляемое поле; поддерживаются поля с гиперссылками в текстовом формате.

_________

Полка «Фильтры» предназначена для ограничения отображаемых данных. Поля, размещённые на этой полке, становятся доступны как фильтры: пользователь может задать условия отбора, и таблица будет отображать только те данные, которые им соответствуют.

Полка «Дополнительно» служит резервным набором полей, которые аналитик заранее подготавливает для пользователя в режиме конструктора. Поля на этой полке не влияют на отображение таблицы напрямую, однако в режиме просмотра становятся доступны в выпадающем боковом списке. Для этого нажмите на поле в полке и выберите один из вариантов: без сортировки, по возрастанию или по убыванию. При необходимости можно указать другое поле, по значениям которого будет выполняться сортировка.
