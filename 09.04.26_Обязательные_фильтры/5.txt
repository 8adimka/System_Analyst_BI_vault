В дополнение к этим постановкам подготовь постановку для решения ещё одной недоработки ->
В текущем функционале тумблер "Локальный" доступен прямо в настройках пилюль, размещённых на полке "Фильтры" визуализаций.
В то время как настройка "Обязательный фильтр" доступна только:
* из боковой панели фильтров (при настройке отдельных выбранных на дашборде фильтров),
* из настроек визуализаций "Контейнер с фильтрами" и "Иерархический фильтр". 

В этих настройках мы можем для любого выбранного фильтра включить параметр "Обязательный фильтр" и сделать его обязательным для заполнения - в случае его незаполненности, запросы в базу данных не будут отправляться для визуализаций.

Требуется добавить тумблер "Обязательный фильтр" в настройки пилюль, размещённых на полке "Фильтры" для всех визуализаций, где доступна настройка "Локальный". Новый тумблер "Обязательный фильтр" добавить рядом (ниже) под тумблером "Локальный".

Дополнительно требуется добавить тумблер "Обязательный фильтр" в боковую панель фильтров в разделе "Локальные" для обеспечения возможности включения обязательности фильтров для локальных фильтров визуализаций из боковой панели фильтров. 

При выключенном тумблере "Локальный":
* При включении тумблера "Обязательный фильтр" из настроек пилюль, размещённых на полке "Фильтры" (для всех визуализаций), данная настройка должна синхронно включаться:
** в боковой панеле фильтров для связанных глобальных фильтров, использующих данное поле набора данных;
** в настройках визуализаций "Контейнер с фильтрами", использующий данное поле набора данных и размещённой соответствующей пилюлей на полке "Фильтры";
** в настройках визуализаций "Иерархический фильтр", использующий данное поле набора данных и размещённой соответствующей пилюлей на полке "Фильтры".

При включенном тумблере "Локальный" для конкретной визуализации:
* При включении тумблера "Обязательный фильтр" из настроек пилюль, размещённых на полке "Фильтры" (для всех визуализаций), данная настройка должна синхронно включаться:
** в боковой панеле фильтров для связанных локальных фильтров данной визуализации, использующих данное поле набора данных;

Как системный аналитик с большим стажем, опираясь на изученные материалы и общий контекст нашего портала сформулируй необходимые доработки интерфейса нашего аналитического портала для внедрения тумблера "Обязательный фильтр" в настройках пилюль, размещённых на полке "Фильтры" для всех визуализаций и, дополнительно, внедрения тумблера "Обязательный фильтр" в боковую панель фильтров в разделе "Локальные" для обеспечения возможности включения обязательности фильтров для локальных фильтров визуализаций из боковой панели фильтров.
