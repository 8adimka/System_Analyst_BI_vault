h3. Общая структура и принципы

Панель переходит от плоского единого списка вкладок к иерархической структуре: несколько именованных групп верхнего уровня, каждая из которых раскрывается и содержит вложенные Разделы.  Некоторые вложенные Разделы при переходе на них разворачивают горизонтальные подразделы в основной области контента (не в боковой панели) — такой паттерн уже показан в ориентировочном дизайне на скрине. 
Группы — аккордеон: по умолчанию все группы раскрыты, но лишние могут быть свёрнуты при нажатии на соответствующую кнопку (стрелка раскрытия) рядом с названием группы. Иконка группы + подпись + стрелка раскрытия. Активный пункт подсвечивается. Нижняя панель из трёх режимов отображения (как в текущем on-premise интерфейсе) сохраняется без изменений. 

----

h3. Категория 1 — «Данные».

Охватывает всё, что связано с получением, хранением и описанием данных.
Разделы:
- *Источники и подключения* — объединённый раздел для внешних источников данных, на основе которых можно создавать Произвольные или Простые наборы данных (горизонтальные подразделы: «Источники», «Подключения», «Загрузка из таблиц»).
- *Правила загрузки данных* — после создания Подключения к внешнему источнику, данные из него можно загрузить на внутренний ClickHouse портала и для этого задать правила загрузки данных из внешних источников. В правилах загрузки данных для "Подключений" мы определяем как именно проводить загрузку данных и можем провести предобработку данных и создать "Простой" набор данных.
- *Наборы данных* — данный раздел позволяет работать с наборами данных и создавать "Произвольные" наборы данных из уже созданных "Источников" задавая им произвольный пользовательский SQL-запрос, а так же в соответствующем разделе можно из уже созданных "Простых" наборов данных (создаются на этапе "Правила загрузки данных") создавать "Составные" наборы данных (горизонтальные подразделы: «Произвольные наборы данных», «Простые и составные наборы данных»).

----

h3. Категория 2 — «Аналитика».

Всё, что связано с визуализацией и созданием отчётности.
*Разделы:*
- *Отчёты*
- *Компоненты* *(только для on-premise и для администратора; в облаке — только для администратора)*

> *Фасеты* — сейчас решили полностью скрыть данный функционал (функционал нерабочий, незадокументированный, вводит пользователя в заблуждение).
----

h3. Категория 3 — «Администрирование».

Управление пользователями, правами доступа и безопасностью.
*Разделы:*
- *Пользователи*
- *Пользовательские переменные* — переименованный раздел «Переменные» (текущее название «Переменные» вводит в заблуждение, поскольку это серверные переменные для RLS и SQL-запросов к наборам данных, не связанные с переменными окружения отчётов)
- *Настройки RLS* (настройки строковой безопасности)
- *Роли RLS*
- *Профили доступа к отчётам*
- *Профили наборов данных*
- *Лицензия*

----

h3. Категория 4 — «Настройки».

Системные настройки портала, не связанные напрямую с правами пользователей.
*Разделы:*
- *Общие настройки* — переименованные «Настройки портала» (соответствует принятой практике именования в других сервисах)
- *Темы интерфейса*
- *Настройки безопасности*
- *Настройки кэширования*
- *Профили экспорта*

----

h3. Нижняя панель режимов (сохранить без изменений).

Три кнопки-режима в нижней части боковой панели — как в текущем on-premise интерфейсе.  На скриншоте видны три иконки:
- *Режим 1* — список / каталог (левая кнопка)
- *Режим 2* — «Настройки портала» (средняя кнопка, активна в текущем интерфейсе — именно этот режим обсуждается)
- *Режим 3* — профиль пользователя (правая кнопка)

Эта панель обязательна к воспроизведению и не изменяется.
----

h3. Ключевые переименования.

- «Настройки портала» → *«Общие настройки»* (в группе «Настройки»)
- «Переменные» → *«Пользовательские переменные»* (в группе «Администрирование»)
- «Загрузка из Excel» → *«Загрузка из таблиц»* (охватывает Excel и Google Sheets)
