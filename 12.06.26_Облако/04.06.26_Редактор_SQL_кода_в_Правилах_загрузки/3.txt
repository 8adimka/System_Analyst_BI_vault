Ранее в рамках доработок нашего аналитического портала, мной была подготовлена постановка по внедрению дерева метаданный в редактор кода в нашем портале (задача MB-4513) - ./Постановка_для_корректировки_Редактор_кода_Шаг_3_Наборы_данных_Этап_2.txt

Изучи данную постановку для контекста создания новой постановки.

Для продолжения работ на фронтенде требуется на стороне бэкенда разработать api для получения информации непосредственно о таблицах облачного источника данных и их полях.
Существующий функционал портала ограничен информацией только о датасетах, что при изменениях в правилах подключений приводит к неполноте доступной на фронтенде информации о состоянии таблиц и не позволяет в полной мере использовать возможности вычисляемых выражений.
 
Для реализации задачи MB-4513 необходимыми являются следующие команды и поля в ответах этих команд:
tables.list
  name //имя таблицы
tables.get
  name //имя таблицы
  fields[] // существующий аналог - поле fields[] ответа команды extraction_rules.get
    name // имя поля
    type // тип поля, с возможностью однозначного маппинга на значения типов эндпойнта trivial_type
    
Эти доработки касаются в первую очередь обычной версии портала, именно в обычной версии портала мы реализуем дерево метаданный для "произвольного" набора данных (который получаем на основании существующего Источника), но также аналогичные доработки должны быть внесены и в облачную версию портала.

Мы отталкиваемся от текущих механик облачного портала и делаем универсальное решение которое видит таблицы напрямую. Поэтому нам и не подходит текущее API от датасетов и мы делаем новое.

Шаг 1 — Получить список источников данных
Используем уже существующую команду. Из её ответа выбираем нужный источник по caption или name.

Запрос
json
{
    "command": {
        "name": "list"
    },
    "object": {
        "name": "datasources"
    }
}
Ответ (фрагмент)
json
{
    "mode": "online",
    "status": 200,
    "message": "",
    "data": [
        {
            "ID": 10,
            "caption": "ClickHouse",
            "name": "ClickHouse system",
            "parentID": 50,
            "rls": 0,
            "rls_install": 0,
            "...": "..."
        },
        {
            "ID": 28,
            "caption": "ADQM_BI",
            "name": "ADQM_BI",
            "parentID": 50,
            "rls": 0,
            "rls_install": 0,
            "...": "..."
        }
    ]
}
Фронтенд определяет нужный источник из контекста карточки набора данных и берёт его ID. В данном примере выбираем источник ClickHouse с "ID": 10.

Шаг 2 — Получить список таблиц источника (tables.list)
Используем полученный ID: 10 как command.id. Объект — datasources, потому что мы запрашиваем таблицы, принадлежащие этому источнику.

Запрос
json
{
    "command": {
        "name": "tables.list",
        "id": 10
    },
    "object": {
        "name": "datasources"
    }
}
Ответ
json
{
    "mode": "online",
    "status": 200,
    "message": "",
    "data": [
        {
            "name": "dim_product"
        },
        {
            "name": "dim_customer"
        },
        {
            "name": "dim_date"
        },
        {
            "name": "fact_sales"
        },
        {
            "name": "fact_orders"
        }
    ]
}
Фронтенд отображает полученный список верхним уровнем дерева метаданных. Пользователь раскрывает узел таблицы — например, fact_sales.

Шаг 3 — Получить поля конкретной таблицы (tables.get)
Используем тот же ID: 10 (источник данных) и добавляем object.table с именем раскрытой таблицы.

Запрос
json
{
    "command": {
        "name": "tables.get",
        "id": 10
    },
    "object": {
        "name": "datasources",
        "table": "fact_sales"
    }
}
Ответ
json
{
    "mode": "online",
    "status": 200,
    "message": "",
    "data": {
        "name": "fact_sales",
        "fields": [
            {
                "name": "sale_id",
                "type": "number"
            },
            {
                "name": "sale_date",
                "type": "date"
            },
            {
                "name": "customer_id",
                "type": "number"
            },
            {
                "name": "product_id",
                "type": "number"
            },
            {
                "name": "region",
                "type": "string"
            },
            {
                "name": "amount",
                "type": "number"
            },
            {
                "name": "quantity",
                "type": "number"
            },
            {
                "name": "created_at",
                "type": "date"
            }
        ]
    }
}
