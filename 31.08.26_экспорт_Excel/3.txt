1) *Описание:*
При формировании отчета пользователь использует сводную таблицу. Для некоторых технических полей в настройках сводной активирована опция «скрыть результат». Однако при экспорте данной сводной таблицы в формат Excel выгрузка игнорирует этот параметр и добавляет все скрытые поля в итоговый файл.

*Шаги для воспроизведения:*
1. Открыть нужный отчет со сводной таблицей.
2. В настройках любого из полей на полке значений установить чекбокс «скрыть результат».
3. Убедиться, что поле пропало из визуального отображения сводной в отчете.
4. Экспортировать сводную таблицу в эксель.
5. Открыть полученный файл.

*Фактическое поведение:*
В выгруженном Excel файле поле с настройкой «скрыть результат» присутствует в таблице, хотя оно было скрыто в интерфейсе отчета.

*Ожидаемое поведение:*
При выгрузке в Excel должны экспортироваться только те поля, которые в данный момент отображаются и активны в сводной таблице на экране. Поля, у которых активирована настройка «скрыть результат» должны исключаться из финальной выгрузки, аналогично тому, как они исключены из отображения на отчете.

___________________________________________________________________

2) *Описание:*
При экспорте сводной таблицы в Excel в файл попадают технические фильтры с полки фильтров сводной таблицы. Эти фильтры используются только для настройки логики отображения данных и не несут полезной информации для пользователя. Например, в выгрузке может отображаться значение вида
{code:java}
ВП774== 1{code}
*Фактическое поведение:*
В настройках сводной таблицы технический фильтр помечен как "невидимый", однако при экспорте компонента в Excel он отображается в списке примененных фильтров. В результате пользователь видит технические поля и значения, которые не предназначены для анализа отчета.

*Ожидаемое поведение:*
Если поле на полке фильтров сводной таблицы помечено параметром "невидимый", при экспорте компонента в Excel данное поле не должно отображаться в списке примененных фильтров.

Помимо единственной вынесенной на полку Значений колонки появляется колонка с окончанием "Color_HEX_colorBy". Скольким полям присвоен цвет по другому полю - для стольких будут созданы колонки-дубли, содержащие HEX-код ячеек. Настройки для отключения показа данной колонки не обнаружено - если для обычных полей можно настроить опцию в разделе "Колонки" -> "Показывать" -> "Нет", и они не будут выгружаться в Excel, то для подобных специфичных колонок так не работает.

*Ожидаемое поведение:* таблица выгружается в обычном виде и без отображения лишних колонок-дублей. Опция "Колонки" -> "Показывать" -> "Нет" не перестает работать при включении цвета/сортировки по другому полю.
