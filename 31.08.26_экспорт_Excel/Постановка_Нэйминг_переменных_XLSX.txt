h3. Контекст и проблематика.

В рамках задачи по выводу переменных в XLSX-экспорт был реализован базовый функционал отображения блока «Переменные». Однако текущая реализация использует системное имя переменной, что не всегда соответствует человекочитаемому наименованию, которое видит пользователь в интерфейсе портала.

Переменные в отчёте создаются и существуют в привязке к пилюлям контейнера с фильтрами. Каждая пилюля имеет собственный алиас (человекочитаемое наименование), который отображается пользователю в интерфейсе. Именно это наименование должно использоваться при выводе переменных в XLSX, чтобы экспортированный файл был интуитивно понятен вне портала.

В иерархических фильтрах переменные в настоящее время не поддерживаются, поэтому данная задача ограничивается только контейнером с фильтрами.

----

h3. Цель задачи.

*Требуется:*
# При экспорте данных в XLSX для каждой переменной в блоке «Переменные» ({{\{Variables\}}}) выводить наименование, соответствующее алиасу пилюли контейнера с фильтрами, к которой привязана переменная.
# Обеспечить единое поведение для общего XLSX-шаблона и частного XLSX-шаблона Таблицы.
# Реализовать иерархию определения отображаемого наименования переменной с корректной fallback-логикой.

*Пользовательская история:*
Как пользователь отчёта, я хочу видеть в XLSX-выгрузке переменные с теми же наименованиями, которые я вижу в интерфейсе портала (в контейнере с фильтрами), чтобы корректно интерпретировать выгруженные данные вне портала.

----

h3. 1. Описание текущего поведения.

* Переменные в отчёте создаются в рамках визуализации «Контейнер с фильтрами» и с привязкой к конкретным пилюлям.
* Каждая пилюля контейнера с фильтрами имеет:
  * системное имя поля ({{name}}) — техническое имя поля из набора данных;
  * алиас ({{alias}}) — человекочитаемое наименование, отображаемое в интерфейсе;
  * заголовок ({{title}}) — дополнительный пользовательский заголовок, если задан.
* При экспорте в XLSX в блоке «Переменные» в настоящее время выводится системное имя переменной, которое не совпадает с тем, что пользователь видит в интерфейсе отчёта.

----

h3. 2. Описание целевого поведения.

* При экспорте данных в XLSX в блоке «Переменные» для каждой переменной должно выводиться отображаемое наименование, соответствующее алиасу пилюли контейнера с фильтрами, к которой привязана переменная.
* Если у пилюли задан заголовок ({{title}}), он имеет приоритет над алиасом.
* Если алиас и заголовок не задан - используется системное имя поля ({{name}}) пилюли.
* Для визуализаций, где переменные не используются, поведение не меняется.

----

h3. 3. Требования к реализации.

---
h4. 3.1. Правило формирования отображаемого наименования переменной.

Отображаемое наименование переменной при экспорте в XLSX должно формироваться по следующей иерархии:

# *Заголовок пилюли ({{title}})* — если задан на уровне пилюли контейнера с фильтрами, к которой привязана переменная.
# *Алиас пилюли ({{alias}})* — человекочитаемое наименование пилюли. Алиас всегда заполняется автоматически (дублирует `name` при создании), но может быть изменён пользователем.
# *Системное имя поля ({{name}})* — техническое имя поля из набора данных. Используется только в случае, если алиас и заголовок недоступны (крайний случай).

---
h4. 3.2. Источник данных для определения наименования.

* Наименование переменной определяется на основе пилюли контейнера с фильтрами, к которой привязана переменная.
* Каждая, отображаемая при выгрузке в Excel, переменная всегда существует в привязке к конкретной пилюле контейнера с фильтрами.
* Если *одна пилюля* содержит *несколько переменных*, все они *используют наименование этой пилюли*.
* Переменные, используемые для получения данных, не могут существовать вне привязки к пилюле визуализации «Контейнер с фильтрами». Сценарий «переменная без пилюли» не рассматривается, т.к. *не используемые* переменные не попадают в выгрузку Excel.

---
h4. 3.3. Применение в общем XLSX-шаблоне.

* При использовании общего XLSX-шаблона и маркеров {{\{Variables\}}} или {{\{Variables_by_rows\}}} в ячейке A6 отображаемое наименование переменной формируется по правилам, описанным в п. 3.1.
* Логика вывода блока «Переменные» (порядок, форматирование, разделители) не меняется — изменяется только источник наименования.

---
h4. 3.4. Применение в частном XLSX-шаблоне Таблицы.

* При использовании частного XLSX-шаблона Таблицы и маркеров {{\{Variables\}}} или {{\{Variables_by_rows\}}} отображаемое наименование переменной формируется по правилам, описанным в п. 3.1.
* Логика вывода блока «Переменные» также не меняется.

---
h4. 3.5. Взаимодействие с «Значения по другому полю».

* Правило формирования отображаемого наименования переменной не зависит от настройки «Значения по другому полю».
* Настройка «Значения по другому полю» влияет только на отображение значения переменной, но не на её наименование.

---
h4. 3.6. Fallback-логика.

* Если, по какой-либо причине, не удалось получить наименование пилюли (заголовок, алиас или системное имя), используется системное имя переменной как безопасный fallback.
* Ошибка получения наименования не должна прерывать экспорт.

----

h3. 4. Пограничные сценарии:

* У пилюли задан заголовок ({{title}}), отличный от алиаса.
* У пилюли не задан заголовок, но задан алиас.
* Одна пилюля содержит несколько переменных.
* Переменная привязана к пилюле с настройкой «Значения по другому полю».
* Ошибка при получении наименования пилюли.

----

h3. 5. Критерии приёмки (AC):

*AC.1 — Отображение наименования по алиасу пилюли:*
* *Дано:* в контейнере с фильтрами есть пилюля с алиасом «Год (переменная)», к которой привязана переменная {{year}}; переменная используется в экспортируемой визуализации.
* *Когда:* пользователь экспортирует визуализацию в XLSX.
* *Тогда:* в блоке «Переменные» переменная отображается с наименованием «Год (переменная)».

*AC.2 — Приоритет заголовка над алиасом:*
* *Дано:* у пилюли задан заголовок «Отчётный год» и алиас «Год».
* *Когда:* пользователь экспортирует визуализацию с использованием переменной, привязанной к этой пилюле.
* *Тогда:* в блоке «Переменные» отображается наименование «Отчётный год».

*AC.3 — Единое поведение для общего и частного шаблонов:*
* *Дано:* одна и та же визуализация экспортируется с использованием общего XLSX-шаблона и частного XLSX-шаблона Таблицы с маркером {{\{Variables\}}}.
* *Когда:* пользователь выполняет оба экспорта.
* *Тогда:* наименование переменной в обоих файлах идентично.

*AC.4 — Несколько переменных в одной пилюле:*
* *Дано:* к одной пилюле с алиасом «Год» привязаны две переменные, обе используются в экспортируемой визуализации.
* *Когда:* пользователь экспортирует визуализацию в XLSX.
* *Тогда:* обе переменные отображаются с наименованием «Год».

*AC.5 — Независимость от «Значения по другому полю»:*
* *Дано:* переменная привязана к пилюле с алиасом «Показатель», для которой настроено отображение значений по другому полю.
* *Когда:* пользователь экспортирует визуализацию в XLSX.
* *Тогда:* наименование переменной отображается как «Показатель», а значение — по полю отображения.
