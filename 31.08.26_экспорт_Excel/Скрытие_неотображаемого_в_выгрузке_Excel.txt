*Скрытие неотображаемых полей и фильтров при экспорте в Excel*

h3. 1. Контекст и цель задачи.

Оригинальные баг-репорты:
* Выгрузка полей с активной опцией "Скрыть результат": [https://jira.modusbi.ru/browse/MB-4954].
* Выгрузка фильтров с активной опцией "Невидимый": [https://jira.modusbi.ru/browse/MB-5698].
* Выгрузка технических полей выбранных в опциях "Цвет по другому полю" и "Сортировка по другому полю": [https://jira.modusbi.ru/browse/MB-4115].

При экспорте визуализаций в XLSX в файл попадают результаты "скрытых" пилюль, "невидимые" фильтры и вспомогательные колонки "Цвет по другому полю" и "Сортировка по другому полю". Пользователь получает технические данные, которые не предназначены для отображения в отчёте.

*Требуется:* формировать пользовательское содержимое XLSX с учётом действующих настроек видимости, сохраняя влияние скрытых полей и фильтров на расчёты, отбор и порядок данных.

Правила распространяются на существующие способы XLSX-экспорта визуализаций основного портала: с общим шаблоном, включая шаблон по умолчанию, и с частным шаблоном там, где он поддерживается. Обязательные сценарии — «Таблица» и «Сводная таблица»; для других визуализаций применяются те же правила в части поддерживаемых ими настроек.

----

h3. 2. Описание текущего поведения.

По предоставленным баг-репортам:

|| Сценарий воспроизведения || Фактический результат в XLSX ||
| В сводной таблице для поля на полке «Значения» включить «Скрыть результат», убедиться, что результат скрыт в отчёте, и выполнить экспорт. | Скрытый результат присутствует в файле. |
| На полке «Фильтры» сводной таблицы применить фильтр с параметром «Невидимый» и выполнить экспорт с выводом списка фильтров. | В списке остаются название и условие технического фильтра, например {{ВП774 == 1}}. |
| В «Таблице» для «Поля 1» включить «Цвет по другому полю» и выбрать {{Color_HEX}}, не выводя его на полку «Значения». | Появляется дополнительная колонка {{Поле 1_Color_HEX_colorBy}} с HEX-кодами; при настройке нескольких полей появляются соответствующие дубли. |
| В «Таблице» включить «Сортировка по другому полю», поле-сортировщика отдельно не выводить и выполнить экспорт. | Поле-сортировщик остаётся в файле; после отключения сортировки по другому полю дополнительное техническое поле больше не выводится в файле экспорта. |

Например, компонент "Таблица" - на полке Значений вынесено одно поле - "Поле 1". Для данного поля установлена опция {*}"Цвет по другому полю"{*}:

Поле "Color_HEX" на полку не выносится. *На текущий момент* при экспорте таблицы в Excel-файле мы можем видеть следующее:

h3. 3. Целевое поведение и функциональные требования.

---
h4. 3.1. Состав выгружаемых данных.

* Состав выводимых полей определяется настройками экспортируемой визуализации на момент запуска экспорта в соответствии с настройками видимость; прокрутка и текущая экранная страница не ограничивают объём выгрузки.

|| Условие || Требуемый результат ||
| Для поля включено «Скрыть результат». | Его результат и относящиеся к нему заголовки исключаются из сформированной области данных XLSX, в том числе из представления показателей сводной таблицы. |
| Для поля-фильтра включено «Невидимый». | Из описания применённых фильтров исключается запись этого фильтра целиком: название, оператор и значения. Условие фильтра продолжает применяться к данным. |
| Для колонки задано «Колонки» → «Показывать» → «Нет». | Колонка исключается из области данных, в том числе при включённых цвете и/или сортировке по другому полю. |
| Поле включено в результат обработки данных исключительно как вспомогательное для «Цвет по другому полю» и/или «Сортировка по другому полю» и не имеет самостоятельного отображаемого размещения. | Вспомогательное представление этого поля, его технический заголовок и значения не выводятся как самостоятельные данные XLSX. Если то же поле имеет явно отображаемое размещение, оно выгружается по общим правилам, без технического дубля. |

* Исключаемые результаты не записываются в автоматически сформированные скрытые строки или колонки Excel. В области данных не остаются пустые колонки или заголовки, созданные вместо исключённых результатов.
* Для оставшихся полей сохраняются относительный порядок, соответствие заголовков значениям, форматирование и действующая логика итогов/подытогов. Скрытие вспомогательного поля не меняет значения видимых показателей, отбор и сортировку строк, а также поддерживаемое оформление по другому полю.
* Правила применяются к конкретному использованию поля. Скрытая колонка не является основанием для удаления видимого фильтра по тому же полю; использование поля в служебной роли не делает его явно отображаемое размещение невидимым.

---
h4. 3.2. Список применённых фильтров.

* Из описания применённых фильтров исключается запись фильтра, для которого установлен параметр «Невидимый» в конфигурации экспортируемой визуализации. Его название, оператор и значения не выводятся.
* Условие такого фильтра продолжает применяться к экспортируемым данным. Параметр «Локальный» сам по себе не является основанием для скрытия записи фильтра.
* Исключение действует во всех существующих местах вывода фильтров: в общем шаблоне, в поддерживаемых маркерах частного шаблона — {{Filter}}, {{Filters}}, {{Filters_by_rows}}.
* Оставшиеся записи сохраняют относительный порядок и действующие правила наименования, форматирования, разделения и отображения значений по другому полю. Отсутствие поля отображения на полках экспортируемой визуализации не отменяет использование настройки глобального фильтра.
* Между оставшимися фильтрами не появляются лишние разделители или пустые строки вместо исключённых записей. Если после исключения список пуст, результат подстановки фильтров пустой, без технического текста маркера и служебных значений.

---
h4. 3.3. Фронтенд и бэкенд.

* Фронтенд обеспечивает передачу актуальных настроек видимости экспортируемой визуализации и контекста применённых фильтров при запуске экспорта.
* Механизм формирования XLSX на стороне бэкенда обеспечивает состав данных и описаний по пп. 3.1–3.2. Вспомогательные данные и метаданные остаются доступными внутренним операциям, которым они нужны; исключение из XLSX не должно нарушать эти зависимости.
* Конкретное распределение подготовки состава выгрузки между фронтендом и бэкендом определяется при технической проработке. Новые имена полей API данной постановкой не задаются.

----

h3. 4. Совместимость и пограничные сценарии.

* Существующие настройки скрытия учитываются и в ранее созданных отчётах без повторной настройки. После изменения видимости следующий экспорт должен использовать новое состояние; после сохранения и повторного открытия отчёта применяется сохранённое состояние.
* При пустой выборке скрытые и служебные колонки также не возвращаются в заголовки.
* Правила состава данных и фильтров одинаковы *во всех сформированных файлах и листах*, если экспорт разбивается на части.
* Сохраняются действующие правила обработки общего и частного шаблонов, дополнительных листов, названий и плейсхолдеров. В частном шаблоне описание фильтров выводится только в предусмотренных для этого маркерах.
* Блок «Переменные» сохраняет самостоятельные правила состава и вывода. Исключение колонки или записи фильтра не исключает переменную из этого блока. Если фильтры и переменные размещены в одной ячейке шаблона, пустой список фильтров не препятствует обработке переменных и других маркеров.
* Для оставшихся фильтров сохраняются действующие правила форматирования.

----

h3. 5. Критерии приёмки (AC):

*AC.1 — Скрытый результат сводной таблицы.*
* *Дано:* на полке «Значения» есть отображаемый показатель и показатель с «Скрыть результат»; скрытый показатель используется при вычислении отображаемого.
* *Когда:* выполняется экспорт сводной таблицы.
* *Тогда:* скрытый результат и его заголовки отсутствуют; значения отображаемого показателя и его итогов/подытогов соответствуют действующей логике расчёта с учётом скрытого показателя. Пустых мест вместо исключённого результата нет.

*AC.2 — Цвет и сортировка по другому полю.*
* *Дано:* в «Таблице» для нескольких отображаемых полей настроен «Цвет по другому полю»; для отображаемого поля включена «Сортировка по другому полю», выбран сортировщик и задано направление сортировки. Вспомогательные поля цвета не добавлены как самостоятельные отображаемые колонки. Значения сортировщика позволяют однозначно проверить заданный порядок строк, отличающийся от порядка по отображаемому полю.
* *Когда:* выполняется экспорт для двух вариантов размещения поля-сортировщика: он не добавлен как самостоятельная колонка; он добавлен, но скрыт через «Колонки» → «Показывать» → «Нет». В каждом варианте проверяются цвет и сортировка по другому полю отдельно и одновременно.
* *Тогда:* служебные колонки цвета и сортировки отсутствуют; явно скрытая колонка-сортировщик также отсутствует. Исключённые данные не записаны в скрытые средствами Excel строки или колонки. При включённой сортировке строки следуют порядку по выбранному сортировщику; при включённом цвете сохраняется поддерживаемое XLSX-экспортом оформление.

*AC.3 — Вспомогательное поле также отображается пользователю.*
* *Дано:* поле используется для цвета или сортировки и одновременно явно добавлено как отображаемая колонка.
* *Когда:* выполняется экспорт.
* *Тогда:* пользовательская колонка присутствует, технический дубль отсутствует. После скрытия этой колонки и повторного экспорта она исключается, а цвет/сортировка продолжают работать.

*AC.4 — Невидимый фильтр сохраняет действие на данные.*
* *Дано:* применены невидимый фильтр с полки «Фильтры» сводной таблицы и видимый локальный фильтр; данные позволяют проверить влияние обоих условий.
* *Когда:* выполняется экспорт с выводом фильтров в одну строку и построчно.
* *Тогда:* описание невидимого фильтра отсутствует, видимый локальный фильтр выведен по действующим правилам; выгруженные данные учитывают оба условия. Лишних разделителей и пустых строк вместо скрытой записи нет.

*AC.5 — Все записи фильтров исключены.*
* *Дано:* все применённые фильтры помечены как невидимые; в шаблоне одна ячейка содержит маркеры фильтров и используемых переменных.
* *Когда:* выполняется экспорт.
* *Тогда:* подстановка фильтров пустая, переменные выводятся с действующими наименованиями и значениями; данные остаются отфильтрованными.

*AC.6 — Видимый фильтр по скрытой колонке.*
* *Дано:* отображаемая колонка и *видимый* фильтр по тому же полю с отображением значений по другому полю; дополнительно применён видимый глобальный фильтр, отсутствующий на полках компонента. Зафиксировано описание фильтров в экспорте до скрытия колонки.
* *Когда:* колонка скрывается и выполняется повторный экспорт без изменения условий фильтров и исходных данных.
* *Тогда:* скрытой колонки нет в области данных; фильтр, размещённый на полке «Фильтры» компонента, отображается в выгрузке с учётом заданных значений по другому полю. Отсутствующий на полках визуализации заданный фильтр не отображается в выгрузке. Метаданные, необходимые для поддерживаемого форматирования фильтра, не теряются вследствие исключения колонки из выгрузки.

*AC.7 — Изменение настроек и ранее созданные отчёты.*
* *Дано:* ранее созданный отчёт с настроенным скрытием полей и фильтров.
* *Когда:* последовательно выполняются экспорт, изменение видимости и повторный экспорт, сохранение и повторное открытие отчёта с экспортом.
* *Тогда:* каждый файл учитывает соответствующее состояние настроек; заголовки, значения и оформление оставшихся колонок согласованы, их относительный порядок сохранён.

*AC.8 — Независимость настроек разных пилюль одного поля.*
* *Дано:* поле явно задано на одной из полок как отображаемая колонка и одновременно используется пилюля с этим полем на полке «Фильтры» с параметром «Невидимый».
* *Когда:* выполняется экспорт с выводом описания фильтров.
* *Тогда:* отображаемая колонка и её заголовок присутствуют в области данных; запись невидимого фильтра отсутствует в описании фильтров; данные учитывают его условие.
* *И:* При использовании нескольких размещений одного поля, дополнительно проверяется сценарий с одним скрытым и одним отображаемым размещением: исключается только скрытое размещение.

*AC.9 — Единообразие режимов экспорта.*
* *Дано:* сценарии AC.1–AC.8 подготовлены для «Таблицы», «Сводной таблицы» и других визуализаций с соответствующими настройками.
* *Когда:* выполняется экспорт с шаблоном по умолчанию, общим и поддерживаемым частным шаблоном, включая пустую выборку и разбиение на листы/файлы.
* *Тогда:* состав данных и описаний подчиняется единым правилам во всех частях выгрузки; сохраняются действующие правила подстановки значений в маркеры шаблона и переноса дополнительных листов. Частный шаблон без маркеров фильтров не получает автоматически добавленного описания фильтров.
