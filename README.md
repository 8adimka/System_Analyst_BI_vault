# BI Analysis Vault

Персональное хранилище рабочих материалов по системному анализу и развитию BI-платформы.

Репозиторий используется для резервного хранения, ведения истории изменений и синхронизации текстовых рабочих материалов между компьютерами.

## Содержимое

В репозитории хранятся:

- постановки на разработку;
- требования;
- аналитические заметки;
- описания бизнес-логики;
- технические спецификации;
- результаты анализа;
- рабочая документация;
- Markdown-документы;
- текстовые файлы;
- Excel-таблицы, используемые в рамках анализа.

Основные отслеживаемые форматы:

- `.md`
- `.txt`
- `.xlsx`

## Структура

Рабочие материалы организованы по тематическим директориям и датам.

Существующая структура каталогов сохраняется без изменений, чтобы репозиторий одновременно являлся рабочей директорией и архивом накопленных материалов.
