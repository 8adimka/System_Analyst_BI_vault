Бизнес-ценность: «продаваемая» фича — клиенты смогут получать готовый Excel с уже настроенными сводными таблицами, диаграммами и макросами.



Цель: Вернуть и улучшить функционал, который сломался после бэкендовой переработки (≈12-й релиз).

Две основные проблемы:

Удаляются все лишние листы. Раньше клиент мог в шаблоне на листе 2 (и далее) настроить готовую сводную таблицу / диаграмму / макросы, ссылающиеся на данные с листа 1. Сейчас все листы удаляются из шаблона, кроме первого листа с данными.

То есть нужно дать возможность сохранять в шаблоне дополнительные вкладки, чтобы разместить там визуализации, которые можно будет связать с данными, которые мы только получим в процессе экспорта таблицы в этот шаблон.

Жёсткая подмена имени листа (например, _1). Клиент не может задать своё понятное название.

Предлагаемое решение (обсуждалось в транскрипции):



Всегда использовать первый лист как лист с данными (шаблон). В идеале не завязываться на его названии. Но этот пункт не столь критичен, допускается и оставить название "Лист_1".

Главное, не удалять остальные листы(вкладки).

Все остальные листы оставлять как есть (сводные, диаграммы, макросы, форматирование) без изменений.

Данные записывать только в первый лист, созластно указанному там шаблону.



2. Полное описание функционала из базы знаний («Экспорт компонента/отчета» + «Общий шаблон»)

Экспорт таблицы в Excel:



При выборе экспорта в Excel данные экспортируются в виде простой таблицы.

Если выбран шаблон — используется шаблон пользователя.

Если шаблона нет — простой экспорт с заголовками.

Установка шаблона для экспорта таблиц:



Загружается в режиме конструктора → Настройки компонента → Основные настройки / Шаблон экспорта → «Загрузить».

Можно привязать к уровню детализации (дрилл).

Кнопка «Сбросить» удаляет шаблон.

Правила создания шаблона (полная цитата):



Значащие столбцы должны начинаться с первого столбца на листе.

Повторяющаяся строка таблицы в шаблоне должна быть последней непустой строкой в файле шаблона.

Количество столбцов шаблона должно совпадать с количеством столбцов в отчете.

В шаблоне возможно задать ячейки и формат для вывода заголовка и значений фильтров, используя переменные (в фигурных скобках):{Title} – заголовок визуализации

{Report_title} – заголовок отчета (аналогично {Title})

{Filter} – фильтры в одну строку (старое поведение)

{Filters} – фильтры в одну строку (для совместимости)

{Filters_by_rows} – каждый фильтр с новой строки

Важно: В шаблоне необходимо использовать только один из переменных фильтра.

При использовании любой переменной фильтров отображаются только те фильтры, которые применены к визуализации (включая локальные и невидимые). Порядок и формат сохраняются.

Для общего шаблона экспорта (настройки портала → Шаблон Excel по умолчанию):



Должен быть один лист.

A1 — стили для шапки таблицы.

A2 — стили для строк таблицы.

A3 — стили для заголовка визуализации.

A4 — стили для фильтров ({Filters_by_rows} — с новой строки).

A5 — стили для заголовка отчета.

Ширина колонки A — ширина по умолчанию.

Особенности:



Числовые значения — с учётом точности из настроек компонента (шаблон имеет приоритет по «Число десятичных знаков»).

Итоги и подытоги выводятся, если настроены.

Формат даты: можно задать в настройках колонки таблицы (иначе timestamp).

В шаблонах важно понимать, что на Лист_1 мы привязываемся к нижней строчке - из неё мы берём формат вывода и её мы заменяем нашими реальными данными, а все прочие данные выше этой нижней строчки выводятся как есть.
