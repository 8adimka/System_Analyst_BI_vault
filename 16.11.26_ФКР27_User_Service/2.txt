| Создание пользователей | Назначение прав | Следствие                                                                          |
| ---------------------- | --------------- | ---------------------------------------------------------------------------------- |
| Автоматическое         | Автоматическое  | Учётная запись и права формируются на основании данных внешней системы             |
| Автоматическое         | Ручное          | Пользователь создаётся автоматически, доступами управляет администратор портала    |

| Компонент                   | Назначение                                                                                          |
| --------------------------- | --------------------------------------------------------------------------------------------------- |
| **Identity Provider (IdP)** | Проверяет личность пользователя и подтверждает результат аутентификации                             |
| **User Service**            | Обычно предоставляет сведения о пользователях; иногда совмещён с IdP или взаимодействует с ним      |
| **OpenID Connect (OIDC)**   | Протокол аутентификации, построенный на OAuth 2.0                                                   |
| **OAuth 2.0**               | Протокол делегирования авторизованного доступа, сам по себе не являющийся протоколом аутентификации |
| **JWT**                     | Формат токена с утверждениями (claims), а не самостоятельный протокол входа                         |
| **SCIM**                    | Стандарт управления жизненным циклом учётных записей и групп между системами                        |
