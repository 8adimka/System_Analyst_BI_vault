1) На панели груповых показателей (которая выполнена для этого клиента) мы должны осуществить доработку и добавить новую опциональную кнопку "Как улучшить результат" при нажатии на которую будет выводится список мер реагирования. Важно заметить, что сводная таблица имеет иерархическую структуру. На вкладке "Карточка РПО" в сбодной таблице только два уровня вложенности, а на вкладке "Главный экран РПО" в аналогичной сводной таблице будет три уровня вложенности - по РПО, Нацпроектам и РП. Для того, чтобы выводить правильные данные из общей таблицы с сырыми данными применяется логика ROW_LEVEL.
Аналогичную логику понадобится прописать, чтобы брать правильные данные по мерам реагирования в зависимости от уровня вложенности.

Примерная логика ROW_LEVEL:
CASE
WHEN !ROW_LEVEL! = '"Ответственный РПО"' THEN (max(case
  when "ИКУП_Регион" = -1 then NULL::numeric
  when "ИКУП_Регион" = 0 then round("ИКУП_Регион", 2)
  when "ИКУП_Регион" >= "ИКУП_СР_Регион" then round("ИКУП_Регион", 2)
  else round("ИКУП_Регион", 2)
end))
WHEN !ROW_LEVEL! = '"Наименование НП"' THEN (max(case
  when "ИКУП_НП" = -1 then NULL::numeric
  when "ИКУП_НП" = 0 then round("ИКУП_НП", 2)
  when "ИКУП_НП" >= "ИКУП_СР_НП" then round("ИКУП_НП", 2)
    else round("ИКУП_НП", 2)
end))
WHEN !ROW_LEVEL! = '"Наименование РП"' THEN (max(case
  when "ИКУП_РП" = -1 then NULL::numeric
  when "ИКУП_РП" = 0 then round("ИКУП_РП", 2)
  when "ИКУП_РП" >= "ИКУП_СР_РП" then round("ИКУП_РП", 2)
  else round("ИКУП_РП", 2)
end))
ELSE 999999 END
